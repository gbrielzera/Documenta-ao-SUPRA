# Contratação de Solucionadores

Caminho: Janelas > Recurso > Contrato > Recurso Aplicado > Contratação de Solucionadores

Grupos de trabalho onde estão lotados os Solucionadores correspondentes ao tipo de recurso do contrato.

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Grupo de Trabalho** | Grupos de trabalho onde estão lotados os Solucionadores correspondentes ao tipo de recurso do contrato. Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
