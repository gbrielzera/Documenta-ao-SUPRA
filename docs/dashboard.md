# Dashboard

Caminho: Guia para Solucionadores > Dashboard

O Dashboard é um "painel de indicadores" que fornece informações sobre o desempenho dos negócios em toda a empresa de forma gráfica e fácil leitura e interpretação.

Para saber mais sobre como realizar a criação de novos dashboards, acesse o tópico [Criando um Dashboard Simples](criando_um_dashboard).
