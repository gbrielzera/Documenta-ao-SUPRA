# TipoAtividade

Caminho: Customização > Modelo de objetos > Processo > Enumerações > TipoAtividade

Tipo de Atividade

| **Valor** | **Descrição** |
|---|---|
| **Tarefa** | Tarefa manual ou automatizada |
| **EventoInicial** | Inicializador manual para processos. Iniciadores manuais estão sujeitos a regras de autorização para clientes, solucionadores e sujeitos a regras de visualização no Autoatendimento e Workspace |
| **EventoFinal** | Finalizador simples de processo |
| **LinkFinal** | Evento Final que remete o processo/Subprocesso a um novo Subprocesso |
| **LinkInicial** | Evento inicial de um Processo/Subprocesso que é iniciado por outro Processo |
| **Processo** | Processo |
| **SubProcesso** | Chamada de Subprocesso |
| **FimCancelamento** | Cancela uma ocorrência |
| **EventoIntermediarioRegra** | Evento Intermediário baseado em Regra |
| **EventoInicialRegra** | Inicia um processo a partir de um temporizador com ciclo configurado |
| **EventoInicialTimer** | Inicia um processo a partir de uma fórmula que é avaliada pela máquina de processos |
| **EventoIntermediarioTimer** | Evento Intermediário Temporal |
| **EventoIntermediarioMensagem** | Evento de processo que gera mensagens |
| **EventoInicialMensagem** | Inicia uma ocorrência a partir de um email ou mensagem webservice recebida. |
