# Componente Serviço

Caminho: Janelas > Processo > Serviço > Componente Serviço

Item de Configuração Componente de Serviço

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Item Configuração** | Item de Configuração componente Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
|---|---|
| **Impacto em falhas e mudanças** | Impacto na disponibilização do Serviço em caso de falhas ou mudanças. Este impacto é utilizado no cálculo de Análise de Impacto e determinará se o componente tornará o serviço indisponível. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna IMPACTO_PAR_INC da tabela [COMP_SERVICO](dados_comp_servico). |
