# LimiteSuperiorCalculo

Caminho: Customização > Modelo de objetos > Processo > GrauPrioridade > LimiteSuperiorCalculo

Limite superior para determinar seleção do Grau de Prioridade a partir do valor retornado pela Expressão de Cálculo do Método de Priorização. Para determinar o Grau de Prioridade é realizado primeiramente a ordenação dos Graus existentes com base no campo sequência. Em seguida os Graus são comparados com o Limite Superior e é selecionado aquele que apresentar o Limite Superior maior ou igual que o cálculo base.
