# Receptor

Caminho: Customização > Modelo de objetos > Processo > Receptor

Atividade de entrada em um Gateway

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **Atividade** | Uma Atividade de Processo corresponde a Tarefas, Subprocessos e Eventos de Processos. | [Atividade](objetos_atividade) |
| **AtividadeId** | Número sequencial gerado automaticamente pelo sistema para Identificar uma Atividade | Inteiro |
| **GatewayEntrada** | Representa uma Decisão ou Merge a ser tomado durante a execução do Processo | [Gateway](objetos_gateway) |
| **GatewayEntradaId** | Gateway de entrada. | Inteiro |
| **GatewayId** | Número sequencial gerado automaticamente pelo sistema para Identificar um Gateway | Inteiro |
| **Id** | Número sequencial gerado automaticamente pelo sistema para Identificar um Receptor | Inteiro |
