# Localizar Classe Apontamento

Caminho: Localizar Classe Apontamento

Para localizar um registro de Classe Apontamento basta clicar no botão Localizar da tela de listagem de registros (Veja figura abaixo) ou pressionar a tecla de atalho **Ctrl + F**.

Botão para localização de registros

Ao acionar o comando de localização é exibida uma área contendo os controles disponíveis para digitação dos critérios de filtro denominado "Filtro padrão" do cadastro. Veja abaixo o conteúdo do filtro padrão para o cadastro Classes de Apontamentos:

Filtro padrão

Após preencher o critério de filtro clique em **Filtrar agora **para executar a consulta. Como resultado a tela de listagem é atualizada contendo apenas os registros que atendam o filtro fornecido. Se o número de registros recuperados for superior ao limite de visualização então utilize os comandos de paginação de registros.

Para reestabelecer a exibição de todos os registros clique no botão **Exibir todos.**
