# Gráfico

Caminho: Guia para Administradores > Editor de Dashboard > Tipos de visualização de indicadores > Gráfico

A forma mais comum de apresentação de dados. Com este tipo de forma é possível criar gráficos de barra, ponto, linha, área, alcance, bolha e financeiros. Representação ideal para distribuição de dados em um plano cartesiano (eixos X/Y).

Sobre as seções de dados, os Argumentos representam o eixo X. Os valores representam o eixo Y e as séries podem variar de acordo com o tipo de gráfico, agrupando-os sempre pelos argumentos.
