# Grid

Caminho: Guia para Administradores > Configurando Processos > Editor de Processos > Toolbox e elementos do BPMN > Data Objects > Entrada de Dados > Criação de Campos Customizados > Tipos de Controle > Grid

O controle de Listagem de Registros permite a criação de uma listagem contendo vários campos. Dentro desta, é possível a configuração de diversas colunas, assim como a criação de múltiplas linhas contendo valores inseridos pelo usuário. Para este controle, utilize valores do tipo Listagem de Registros.

Aparência do controle na Edição da Ordem de Serviço

A configuração do layout dos campos dentro da listagem é realizada através das configurações de colunas no [Entrada de Dados](data_obj_entrada_de_dados) durante a edição do fluxo do processo.

Configurações de listagem de registros

Outra possibilidade é configurar a forma de edição destes campos. Esta configuração é realizada na seguinte propriedade:

Formato de edição

- **No Formulário** - Abre um formulário para preenchimento dos campos, é o valor padrão da configuração da listagem;
- **Na Própria Linha** - Exibe um campo de edição de valores na própria linha;
