# Desvios

Caminho: Guia para Administradores > Configurando Processos > Editor de Processos > Toolbox e elementos do BPMN > Desvios

Também conhecidos no BPMN como Gateways, são desvios que podem divergir um fluxo de processo. O Supravizio implementa quatro tipos de desvios:

| [](pergunta_e_resposta) | Desvio por Evento Baseadas em perguntas e respostas exibidas para o usuário no Assistente de Processos |
|---|---|
| [](por_formula) | Desvio Exclusivo Baseado em Dados onde o Analista de Processos configura no fluxo uma expressão IronPython para tomada de decisão automática. |
| [](desvio_inclusivo) | Desvio Inclusivo Baseado em Dados onde o Analista de Processos configura nas alternativas expressões IronPython para tomada de decisão automática de quais alterantivas serão seguidas. |
| [](paralelo) | **Desvio Paralelo** ** ** Divide uma solicitação em fluxos para cada fluxo de saida do elemento. |
