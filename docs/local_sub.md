# Local

Caminho: Janelas > Recurso > Unidade Negocio > Prédio > Local

Um Local pode representar um andar, sala ou outra unidade de um Prédio. Também são utilizados para definir localização de Clientes e Ativos (Itens de Configuração).

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Identificador** | Número sequencial gerado automaticamente pelo sistema para Identificar um Local Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna ID_LOCAL da tabela [LOCAL](dados_local). |
|---|---|
| **Complemento (sala ou andar)** | Complemento (sala ou andar) que identifica o Local Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna COMPLEMENTO da tabela [LOCAL](dados_local). |
| **Ativo** | Indica que o Local está ativo no sistema. Quando inativo o local passa a não ser exibido na aplicação de Autoatendimento. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna ATIVO da tabela [LOCAL](dados_local). |
