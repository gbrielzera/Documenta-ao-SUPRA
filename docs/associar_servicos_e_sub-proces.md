# Associar Serviços e Subprocessos

Caminho: Guia para Administradores > Configurando Processos > Tutoriais > Tutorial 2: Configuração de Serviços > Associar Serviços e Subprocessos

Nesta etapa vamos associar o Subprocesso Adquirir suprimentos com os possíveis Serviços que, no nosso exemplo, serão apenas **Suprimentos para informática** e **Suprimentos para escritório em geral**.

1. Acesse o cadastro de Tipos de Subprocessos utilizando as opções do menu **Processos | Processos | Tipos de Subprocessos**

Opções de menu para acessar o cadastro de Tipos de Subprocessos

### 2. Localize o registro Adquirir suprimentos e dê um duplo clique para visualizar a tela de edição

Seleção do registro Adquirir suprimentos

### 3. Na tela de edição de Adquirir Suprimentos e depois selecione a aba Serviços disponíveis

Aba onde são listados os Serviços

### 4. Clique no botão Novo, localizado dentro da aba Serviços disponíveis, preencha o novo diálogo com os dados abaixo e clique em Confirmar

Associação do serviço de Suprimentos para escritório em geral com o subprocesso Adquirir suprimentos

### 5. Repita o passo anterior informando Suprimentos para informática no campo Serviço do novo diálogo
