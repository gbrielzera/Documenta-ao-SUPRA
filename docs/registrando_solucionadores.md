# Registrando Solucionadores

Caminho: Guia para Administradores > Roteiro de implantação > Realizando cadastros > Registrando Solucionadores

Vamos agora organizar os solucionadores nesta estrutura. Para cadastrá-los, acesse o cadastro de Pessoas (**Recurso | Pessoas**):

Acessando o cadastro de Pessoas

No cadastro da pessoa que queremos tornar solucionadora, basta clicarmos no comando "**Configurar Solucionador**":

Cadastrando um Usuário para uma Pessoa

Ao clicar no comando, um novo diálogo de edição de usuário será exibido:

Configurações de um usuário.

Nesse novo diálogo é possível adicionar ou remover [Perfis de acesso](cadastrar_perfis_acesso) para este usuário (pode ser adicionado um ou mais, neste caso, são acumulativos), definir o Grupo de Trabalho, definir uma senha e até mesmo associar um calendário ao solucionador (opcional).

**Observação:**

Para finalizar o novo cadastro clique no botão **OK **e depois Salve as alterações do cadastro de pessoas.

**Informações importantes:**

- Caso o Supravizio esteja integrado com o [Serviço de Diretório](servico_de_diretorio) de sua rede, não será necessário a configuração da** Senha** do Solucionador. Através desta configuração assume-se as credenciais de rede do usuário de rede do solucionador.
- Uma Pessoa só pode estar **ativa** como solucionadora** apenas em um Grupo de Trabalho**. Não é permitida a permanência ativa de uma Pessoa em mais de um Grupo de Trabalho.
- Para modificar o Grupo de Trabalho do solucionador neste cadastro você deve estar conectado no Supravizio com uma conta de solucionador que possua perfil de Administrador ou que tenha um perfil de acesso com autorização à transação **Grupos de Trabalho** e para modificar os campos "Senha", "Confirmar Senha" e "Perfis de Acesso" é necessária autorização de aceso à transação **Usuários**.
