# Workspace

Caminho: Guia para Solucionadores > Workspace

O Workspace é a principal tela utilizada pelo usuário solucionador para atendimento de Ordens de Serviço. Nesta tela o usuário pode também consultar a Base de Conhecimento, realizar apontamentos e configurar opções pessoais.

O Workspace é exibido automaticamente assim que é realizado a conexão. Ele também pode ser acessado utilizando as opções do menu Processo | Workspace conforme a figura abaixo:

Opção de menu para acesso ao Workspace

Na figura abaixo podemos observar o layout do Workspace que exibe inicialmente a listagem de Ordens de Serviço sob responsabilidade do usuário conectado.

Tela Workspace

No canto esquerdo podemos observar os botões Ordens de Serviço, Base de Conhecimento e Opções. Estes botões podem ser utilizados para modificar o modo de exibição da tela acessando conjuntos variados de funcionalidades.
