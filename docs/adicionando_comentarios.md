# Como adicionar comentários

Caminho: Guia para Solucionadores > Worklist > Visualizando detalhes de Ordens de Serviço > Como adicionar comentários

Também podemos visualizar e inserir comentários nas Ordens de Serviço através do Worklist. Para isso, há um agrupamento localizado logo abaixo dos campos para preenchimento.

Comentários da Ordem de Serviço

Para adicionar um comentário, clique com o botão direito do mouse sobre a listagem e será aberto um menu conforme a ilustração abaixo:

Opções disponíveis

Para adicionar um comentário, clique na primeira opção **Adicionar um comentário **e será aberto um popup com ao campo para preenchimento. Terminado o preenchimento, clique em **OK** para confirmar.

Campo para preenchimento do comentário

Como indicado na figura acima, há a opção de publicar ou não o comentário no Portal de Processos. No entanto, caso deseje alterar esta opção após inserido o comentário, basta clicar em **Publicar o comentário no portal de Autoatendimento** para publicá-lo ou em **Cancelar publicação do comentário **para que não esteja mais visível.
