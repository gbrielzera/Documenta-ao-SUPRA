# FatorPrioridadeId

Caminho: Customização > Modelo de objetos > Recurso > Pessoa > FatorPrioridadeId

Identificador do Fator de Prioridade utilizado em cálculos de Prioridade.

**Exemplo 1: modificação da propriedade FatorPrioridadeId**

```
# carrega objeto Pessoa de identificador 1
pessoa = Pessoa.Carrega(1)
# modifica a propriedade FatorPrioridadeId
pessoa.FatorPrioridadeId = 1;
# salva modificação da propriedade FatorPrioridadeId
Pessoa.Salva(pessoa)
```
