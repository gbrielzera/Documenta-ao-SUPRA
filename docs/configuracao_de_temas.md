# Configurando um tema

Caminho: Guia para Administradores > Portal de Processos > Customizações de aparência > Configurando um tema

O tema condiz à aparência dos menus e botões presentes no Portal. Este tema é definido no Supravizio Web, sendo que no Portal, esta opção apenas replicará a escolha realizada anteriormente na aplicação.

Para definir um tema, é necessário entrar no Supravizio Web no caminho **Utilitários | Configurações | Aba Utilitários**. Nesta tela, irá aparecer a opção Estilo, onde serão listadas as opções disponíveis:

Configuração de Temas no Supravizio Web
