# Tutorial 10: Macroprocessos e Tipos de solicitação

Caminho: Guia para Administradores > Configurando Processos > Tutoriais > Tutorial 10: Macroprocessos e Tipos de solicitação

Neste tutorial vamos entender como funciona o cadastro de Macro-Processos disponibilizado no Editor de Processos que possibilita que o Supravizio atenda à diversas áreas de negócio.

Criaremos um Macroprocesso chamado Administrativo e explicaremos como utilizar a regra de autorização para criação de Ordens de Serviço com base no critério de áreas proprietárias de subprocessos.

Inicialmente criaremos um Macroprocesso chamado Administrativo. Neste novo Macroprocesso vamos adicionar um subprocesso chamado Faturamento.

Após a criação deste Macroprocesso criaremos Tipos de Solicitação que são disponibilizados no Portal.

E ensinaremos como utilizar o comando de preview para tela de abertura de Ordens de Serviço do Portal.
