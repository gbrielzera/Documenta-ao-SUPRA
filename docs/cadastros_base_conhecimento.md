# Base de Conhecimento

Caminho: Guia para Solucionadores > Base de Conhecimento

O Supravizio permite a criação de artigos e oferece recursos manuais e automáticos para recuperação destes artigos e também Ordens de Serviço.

Os artigos fazem parte do módulo de Ativos e são uma especialização do conceito de Itens de Configuração. Como itens de configuração são gerados ou associados em Ordens de Serviço, podemos então elaborar processos para criação e manutenção deste tipo de conteúdo.

Neste tópico vamos entender como estes artigos podem ser cadastrados. No tópico [Pesquisar Publicações](pesquisar_publicacoes) é possível entender como é feita a recuperação dos artigos ou Ordens de Serviço que compõem a base de conhecimento.

Há também a possibilidade de restringir o acesso aos artigos da base de conhecimento através dos papéis. Para mais informações, veja o tópico [Restrição de Acesso aos Artigos da Base de Conhecimento](restricao_de_acesso_aos_artigo).
