# PessoaItemPapel

Caminho: Customização > Modelo de objetos > Processo > Enumerações > PessoaItemPapel

Critério para recuperação de pessoas a partir de itens de configuração anexados em uma ocorrência.

| **Valor** | **Descrição** |
|---|---|
| **Usuario** | Recupera uma pessoa que seja relacionada como usuária do item de configuração anexado em uma ocorrência. |
| **Responsavel** | Recupera a pessoa que é responsável por um item de configuração anexado na ocorrência. |
| **ResponsavelUsuario** | Recupera a pessoa responsável e usuários de um item de configuração anexado na ocorrência. |
