# ModuleId

Caminho: Customização > Modelo de objetos > Utilitários > Class > ModuleId

Identificador do Módulo Associado

**Exemplo 1: modificação da propriedade ModuleId**

```
# carrega objeto Class de identificador 1
class = Class.Carrega(1)
# modifica a propriedade ModuleId
class.ModuleId = 1;
# salva modificação da propriedade ModuleId
Class.Salva(class)
```
