# Height

Caminho: Customização > Modelo de objetos > Utilitários > PropertyLayout > Height

Altura em pixels do Controle

**Exemplo 1: modificação da propriedade Height**

```
# carrega objeto PropertyLayout de identificador 1
propertyLayout = PropertyLayout.Carrega(1)
# modifica a propriedade Height
propertyLayout.Height = 1;
# salva modificação da propriedade Height
PropertyLayout.Salva(propertyLayout)
```
