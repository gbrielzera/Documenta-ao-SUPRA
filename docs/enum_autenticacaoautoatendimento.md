# AutenticacaoAutoAtendimento

Caminho: Customização > Modelo de objetos > Processo > Enumerações > AutenticacaoAutoAtendimento

Forma de autenticação de usuários do Autoatendimento

| **Valor** | **Descrição** |
|---|---|
| **ServicoDiretorio** | O usuário e senha são validados no Serviço de Diretório |
| **CadastroPessoas** | O usuário é validado pela senha registrada no cadastro de Pessoas |
