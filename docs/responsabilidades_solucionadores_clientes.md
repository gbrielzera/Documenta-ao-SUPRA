# Responsabilidades de Solucionadores e Clientes

Caminho: Relatórios > Responsabilidades de Solucionadores e Clientes

O relatório de Responsabilidades de Solucionadores e Clientes tem por objetivo apresentar um resumo detalhado das responsabilidades em Cadastros do Supravizio de solucionadores e clientes.

Parâmetros

Na figura abaixo podemos observar a tela de parâmetros para este relatório:

Parâmetros do relatório

| **Pessoa** | Este parâmetro filtra os registros de acordo com o responsável pelo cadastro corrente. Se não for informado este critério é desconsiderado na recuperação. |
|---|---|
| **Consultar pessoas inativas** | Este parâmetros tem como objetivo gerar o relatório de pessoas inativas e suas responsabilidades. Este campos não trabalha em conjunto com o parâmetro Pessoa, então deve-se marcá-la e manter o campo Pessoa vazio para obter o relatório de pessoas inativas. |
| **Grupo de Trabalho** | Filtra os registros cujo responsável seja do grupo informado. Se não for informado este critério é desconsiderado na recuperação. |
| **Incluir sub-grupos** | Este parâmetro é utilizado em conjunto com o de Grupo de Trabalho. Se estiver marcado incluirá os sub-grupos do grupo selecionado no campo anterior. |

## Saídas

Após informar os parâmetros de recuperação clique no botão **Consultar** para visualizar o conteúdo do relatório.

Na saída deste relatório são apresentadas informações, agrupadas por pessoas, identificando responsabilidades associadas a solucionadores e clientes. São exibidas todas as responsabilidades associadas em cadastros como por exemplo os Grupos de trabalho que estão na responsabilidade de uma pessoa, o Área onde a pessoa selecionada é gestora, papeis associados como responsabilidades, e vários outros cadastros onde a pessoa selecionada está cadastrada como responsável.
