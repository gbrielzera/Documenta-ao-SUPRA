# Módulo de Conteúdo HTML

Caminho: Guia para Administradores > Portal de Processos > Módulos > Módulo de Conteúdo HTML

O módulo de Conteúdo HTML permite a inserção de páginas dentro do módulo, sendo assim, possibilitando criar páginas de redirecionamento, inserir imagens, vídeos, integrar com redes sociais etc.

Disponível nos modos: Tablet, Clássico e Mobile
