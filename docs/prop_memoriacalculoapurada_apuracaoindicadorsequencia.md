# Propriedade ApuracaoIndicadorSequencia

Caminho: Propriedade ApuracaoIndicadorSequencia

Identificador do(a) ApuracaoIndicador associado(a)

**Exemplo 1: modificação da propriedade ApuracaoIndicadorSequencia**

```
# carrega objeto MemoriaCalculoApurada de identificador 1
memoriaCalculoApurada = MemoriaCalculoApurada.Carrega(1)
# modifica a propriedade ApuracaoIndicadorSequencia
memoriaCalculoApurada.ApuracaoIndicadorSequencia = 1;
# salva modificação da propriedade ApuracaoIndicadorSequencia
MemoriaCalculoApurada.Salva(memoriaCalculoApurada)
```
