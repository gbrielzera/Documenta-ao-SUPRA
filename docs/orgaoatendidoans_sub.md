# Órgão atendido por ANS

Caminho: Janelas > Recurso > Acordo de Nível de Serviço > Órgão atendido por ANS

Órgão atendido por um ANS

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Órgão atendido** | Órgão atendido pelo ANS Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
|---|---|
| **Inclui sub-áreas** | Indica que o acordo é estendido para sub-áreas. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna INCLUI_SUBAREAS da tabela [ORGAO_SLA](dados_orgao_sla). |
