# Exportação e importação

Caminho: Guia para Administradores > Editor de Dashboard > Exportação e importação

O Supravizio permite realizar importações e exportações de dashboards.

## Exportando um Dashboard

Para realizar a exportação, entre no **Editor de Dashboard **e acesse o respectivo registro que deseja exportar.

Dentre as opções do dashboard, haverá uma chamada **Exportar**, conforme indicado na figura abaixo:

Localização do botão

Será aberta uma janela para seleção do local onde se deseja salvar o arquivo.

Local do arquivo

Selecionado o local destino, clique em **Salvar**.

Verifique que o arquivo foi criado um novo arquivo na respectiva pasta. Este arquivo contém as informações do dashboard e poderá ser utilizado futuramente para importações.

Arquivo salvo

## Importação de dashboard

Para importar um dashboard, entre no **Editor de Dashboard **e acesse o respectivo registro no qual deseja realizar a importação.

Dentre as opções do dashboard, haverá uma chamada **Importar**, conforme indicado na figura abaixo:

Localização do botão

Ao clicar neste botão, será aberta uma janela para seleção do arquivo, o qual deseja importar.

Seleção de arquivo

Após selecionar o arquivo, clique em **Abrir**. Logo, o conteúdo contido no arquivo será importado para o dashboard em edição.

Dashboard importado
