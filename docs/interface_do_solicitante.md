# Interface com o Usuário  > Interface do Solicitante

Caminho: Interface com o Usuário  > Interface do Solicitante

Destinada a tarefas como abertura, consulta e abertura de solicitações, o Supravizio disponibiliza a aplicação chamada Portal de Processos.

Possui uma interface totalmente customizável, permitindo a alteração do layout da página, esquema de cores, conteúdo HTML entre outros.

Além disso, o Portal também permite a que sejam inseridas apenas as funcionalidades desejadas pelo administrador.

Portal da Venki Tecnologia

Esta interface também pode ser visualizada em aparelhos como Tablets e Smartphones.

Para saber mais sobre o Portal, leia o tópico [Portal de Processos](portal_introducao).
