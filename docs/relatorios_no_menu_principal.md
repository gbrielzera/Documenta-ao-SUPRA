# Relatórios no Menu Principal

Caminho: Guia para Administradores > Editor de Relatórios > Publicando Relatórios > Relatórios no Menu Principal

1. Para disponibilizar o relatório para consulta. No cadastro do relatório, clique no comando "Disponibilizar menu".

Na janela de configurações, caso necessário, modifique o nome do relatório que aparecerá no menu. Em seguida, também se necessário, determine um agrupamento onde este relatório será encontrado de forma mais intuitiva. Após isso, indique em quais [perfis de acesso](role_sub) o relatório estará visível.

Observação: Também é possível realizar a criação de Agrupamentos, conforme a necessidade. Para saber mais, leia o tópico [Criando agrupamentos de Relatórios](agrupamento_relatorios)

2. Para visualizarmos o relatório no menu, efetue novamente o logon com o seu próprio usuário de forma que sejam recarregados os itens do menu.

Acesse no menu principal, o item **Relatórios | [Agrupamento indicado no relatório ao disponibilizar, se existir] | [Nome do Relatório]**.

Ao clicar no item do menu, automaticamente o relatório é exibido.
