# Item de Pesquisa

Caminho: Janelas > Processo > Pesquisa > Item de Pesquisa

Item a ser avaliado em uma Pesquisa

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Questão Pesquisa** | Uma Questão de Pesquisa pode ser utilizada na elaboração de Pesquisas de Satisfação enviadas para Clientes após a finalização de uma Ordem de Serviço. Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
|---|---|
| **Escore** | Valor atribuido ao Indicador como resposta a Pesquisa de Satisfação |
