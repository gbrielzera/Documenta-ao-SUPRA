# Realizando aprovação de Comentário

Caminho: Guia para Administradores > Portal de Processos > Módulos > Modulo de Base de Conhecimento > Realizando aprovação de Comentário

A aprovação de comentários deve ser realizada por um solucionador, através do cadastro do artigo da Base de Conhecimento no Supravizio Web.

Para isso, este deve seguir o caminho **Ativos | Base de Conhecimento**:

Tela do Supravizio Web

Entrando no cadastro do artigo, haverá uma aba correspondente aos comentários realizados e na direita, a situação do mesmo.

Aba Comentários

Ao dar um duplo clique ou selecionando o item e depois em Modificar, será exibido o cadastro do Comentário, onde pode ser alterada apenas a Situação do comentário.

O comentário poderá ser visualizado no Portal apenas se estiver 'Aprovado'.
