# ClasseDependencia

Caminho: Customização > Modelo de objetos > Ativos > ClasseDependencia

Tipos de Itens de Configuração que podem ser associados como Dependências

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **ClasseConfiguracaoId** | Número sequencial gerado automaticamente pelo sistema para Identificar um Tipo de Item de Configuração | Inteiro |
| **ClasseDependenciaId** | Identificador do Tipo de Item de Configuração que é utilizada como Dependente | Inteiro |
| **Dependencia** | Tipo de Item de Configuração que pode ser associada em relação de Dependência em Itens de Configuração | [ClasseConfiguracao](objetos_classeconfiguracao) |
