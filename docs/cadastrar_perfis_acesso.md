# Cadastro de Perfis de Acesso

Caminho: Guia para Administradores > Roteiro de implantação > Realizando cadastros > Cadastro de Perfis de Acesso

O Perfis de acesso apresentam as características de um Usuário. No Perfil de acesso podemos definir as transações que o usuário terá acesso.

Para cadastrar perfis de acesso utilize a transação **Perfis acesso** selecionando** Utilitários | Segurança | Perfis de acesso**:

Transação de usuários

Para criar um novo perfil de acesso clique em **Novo.** Adicione o **Nome** do perfil de acesso e em **Referência** adicione os esclarecimentos das funções ou transações do usuário.

Na criação de um novo perfil de acesso, inclua na aba **Autorizações** as transações que serão acessadas pelo usuário que possui este perfil.

Para atribuir transações ao Perfil de acessos clique na em **Novo** na aba de Autorizações que permite a escolha da transação desejada:

Para finalizar clique no botão **Salvar**.
