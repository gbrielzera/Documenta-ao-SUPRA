# Attachment

Caminho: Customização > Modelo de objetos > Utilitários > Attachment

Arquivo anexado na mensagem para envio.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **ContentId** | Contend Id de anexos inseridos na mensagem | String |
| **DeleteAfterSent** | O arquivo deve ser removido após o envil do email. | Booleano |
| **Deleted** | Indica que o arquivo foi removido na pasta de arquivos anexados que é mantido no servidor de arquivos. | Booleano |
| **FileName** | Nome completo do arquivo incluindo caminho onde está localizado. IMPORTATE: este arquivo deve estar disponível no instante em que a mensagem for enviada. | String |
| **MessageId** | Identificador da Mensagem proprietária do arquivo anexado. | Inteiro |
| **Picture** | Relacionamento entre Picture e Arquivo | [Picture](objetos_picture) |
| **PictureId** | Identificador do(a) Picture associado(a) | Inteiro |
