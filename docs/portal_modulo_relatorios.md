# Módulo de Publicação de Relatórios

Caminho: Guia para Administradores > Portal de Processos > Módulos > Módulo de Publicação de Relatórios

O módulo de Publicação de Relatórios permite ao usuário consultar, salvar, exportar ou imprimir relatórios. Também é possível realizar a inserção de parâmetros para a consulta manualmente ou ser pré-definida pelo administrador.

Disponível nos modos: Tablet, Clássico e Mobile
