# Editor de Relatórios

Caminho: Guia para Administradores > Editor de Relatórios

O Supravizio possibilita ao usuário extrair relatórios mais detalhados e que atendam às suas necessidades específicas. Para isso, você poderá utilizar o Editor de Relatórios. Para acessar este recurso, no menu principal, selecione Relatórios | Editor de Relatórios.

Através do Editor de Relatórios o usuário poderá elaborar relatórios que poderão ser publicados em janelas e funcionalidades do Supravizio.
