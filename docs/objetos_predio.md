# Predio

Caminho: Customização > Modelo de objetos > Recurso > Predio

Um Prédio define uma edificação dentro de uma Unidade de Negócio onde estão localizados Clientes ou Ativos (Itens de Configuração).

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **Descricao** | Descrição detalhada do Predio | String |
| **Id** | Número sequencial gerado automaticamente pelo sistema para Identificar um Predio | Inteiro |
| **Locais** | Locais | [Lista de Local](objetos_local) |
| **UnidadeNegocioId** | Identificador da Unidade de Negócio que possui o Prédio | Inteiro |
