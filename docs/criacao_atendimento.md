# Criando e atendendo Ordens de serviço

Caminho: Guia para Administradores > Configurando Processos > Tutoriais > Tutorial 1: Construindo o primeiro Processo > Criando e atendendo Ordens de serviço

Uma vez ativado, o processo fica disponível para Solucionadores e clientes para que estes criem solicitações que são denominadas Ordens de Serviço.

Abra a aplicação do Portal de Processos para que possamos então criar uma solicitação do novo Processo e siga os seguintes passos:

### 1. No passo 1 da abertura confirme todos os dados clicando em :

### Confirmação das informações de contato

### 2. No passo 2 selecione a opção referente ao Tipo de Solicitação do Subprocesso. Neste caso, clique em Selecionar uma solicitação de 'Informática' no próximo passo:

Seleção de Tipo de Solicitação

### 3. Logo, será exibido o Passo 3 onde deverá ser selecionado o novo Subprocesso e depois clique em :

Seleção do novo Subprocesso

### 3. No passo 3 selecione o serviço Financeiro e depois clique em :

Tela do Passo 3 com todos os Serviços

Observação: em um tópico futuro veremos como é possível filtrar itens deste passo 3.

### 4. No passo 4 informe os dados requeridos para iniciar o subprocesso e clique em Concluir Abertura:

Entrada de dados do novo subprocesso

Observe na tela acima que a entrada de dados exibida é a mesma configurada no iniciador do subprocesso:

Fluxo selecionado no Editor de Processos

Após clicar em Finalizar é exibida uma tela com o número da solicitação:

Ordem de Serviço aberta

Para visualizar a Ordem de Serviço na aplicação Windows acesse a tela Workspace e preencha o número 28 no campo de localização presente na barra de ferramentas e depois clique no ícone . Veja a figura abaixo:

Como localizar a Ordem de Serviço 28

Na figura abaixo podemos verificar o conteúdo da Ordem de Serviço gerada:

Ordem de Serviço classificada no novo fluxo

Para iniciar o atendimento desta Ordem de Serviço execute os seguintes passos:

### 1. Execute o logout:

Desconectando

### 2. Execute a conexão com o usuário Maria José:

Tela de conexão do Supravizio

### 3. Na tela Workspace, veja figura abaixo, dê um duplo clique sobre o registro da Ordem de Serviço 28:

Lista de Ordens de Serviço do usuário Maria José

### 4. Na tela de edição que é exibida clique no botão Iniciar:

Tela de edição da Ordem de Serviço
