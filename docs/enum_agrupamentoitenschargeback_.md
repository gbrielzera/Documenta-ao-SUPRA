# AgrupamentoItensChargeBack

Caminho: AgrupamentoItensChargeBack

Agrupamento de Itens de Charge-Back em relatórios apresentados para gestores de áreas

| **Valor** | **Descrição** |
|---|---|
| **PorClasseConfiguracao** | Itens relativos a Ativos são agrupados por Tipos de Itens de Configuração. |
| **PorServico** | Itens relativos a Ativos são agrupados por Serviços (relação de Componentes no cadastro de Serviço) |
