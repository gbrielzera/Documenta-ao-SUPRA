# FatorPrioridade

Caminho: Customização > Modelo de objetos > Processo > FatorPrioridade

Fator utilizado no cálculo de Prioridade

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **Ativo** | Quando inativo o Fator não é utilizado em Expressões para Cálculo e também não é visualizado como opção na configuração de Entidades que possuem suporte a cálculo de Prioridade. | Booleano |
| **Descricao** | Descrição detalhada do FatorPrioridade | String |
| **Id** | Número sequencial gerado automaticamente pelo sistema para Identificar um FatorPrioridade | Inteiro |
| **PriorizacaoEntidadeId** | Número sequencial gerado automaticamente pelo sistema para Identificar uma PriorizacaoEntidade | Inteiro |
| **Sequencial** | Sequencial de apresentação do Fator. | Inteiro |
| **Valor** | Peso atribuído ao fator quando utilizado em cálculo de Prioridade de Ocorrências. | Inteiro |
