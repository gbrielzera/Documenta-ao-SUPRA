# Remoção de registros de cadastros

Caminho: Guia para Administradores > Roteiro de implantação > Realizando cadastros > Telas de Listagem > Remoção de registros de cadastros

Ao selecionar vários registros no grid de uma tela de cadastros e clicar em Apagar, é exibido um diálogo contendo o grid de registros selecionados para remoção. Neste diálogo é apresentado o resultado desta remoção:

No grid de resultados da remoção, é apresentada uma mensagem que indica a situação da remoção. Na primeira coluna é apresentado o registro que está sendo removido e na segunda coluna o resultado desta remoção.

Caso seja bem sucedido, será exibida e mensagem **Sucesso**. Caso contrário, será exibida uma mensagem
