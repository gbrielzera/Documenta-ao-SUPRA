# Data Objects

Caminho: Guia para Administradores > Configurando Processos > Editor de Processos > Toolbox e elementos do BPMN > Data Objects

Data Objects descrevem como entradas e saídas são tratadas por um fluxo de processo. No Supravizio estes elementos são especializados e cada especialização implica em automatismos e regras de negócio específicas.

Os data Objects podem ser divididos em:

1. [Data Objects do tipo Entrada de Dados](data_obj_generico)

2. [Data Objects do tipo Itens de Configuração](data_obj_itens_de_configuracao)

3. [Data Objects do tipo Aprovação](data_obj_aprovacao)

4. [Data Object Genérico](data_obj_generico)

5. [Edição de Data Objects com a Janela de Propriedades](data_obj_edicao_propriedade)
