# Publicação em Locais Públicos

Caminho: Guia para Administradores > Editor de Dashboard > Publicando Dashboards > Publicação em Locais Públicos

Após o painel ser publicado, é possível publicá-lo também para meios internos ou externos, gerando um link para acesso direto. Para isso, basta clicar no ícone , conforme indicado na figura abaixo:

Localização do ícone

Ao clicar no ícone, será aberto um popup, contendo o link gerado. O agrupamento **Dados de compartilhamento em mídias sociais **contém parâmetros a serem utilizados em casos de publicação em redes sociais, para gerar visualizações rápidas da página.

Link gerado para publicação

**Importante**: A opção de realizar a publicação através do Workspace é configurável através das permissões do [Grupo de Trabalho](grupotrabalho_sub) do usuário logado. Para isso, acesse o cadastro do respectivo grupo e selecione quais são os usuários autorizados a realizar tal operação. Por padrão, apenas **Coordenadores e Administradores **possuem tal permissão.

Permissões no cadastro do Grupo de Trabalho
