# PublicacaoApontamentosAutoAtendimento

Caminho: Customização > Modelo de objetos > Processo > Enumerações > PublicacaoApontamentosAutoAtendimento

Enumeração que indica a regra de publicação de apontamentos de horas trabalhadas no Autoatendimento

| **Valor** | **Descrição** |
|---|---|
| **Nunca** | Nunca publicar os apontamentos no Autoatendimento |
| **Sempre** | Sempre publica os apontamentos no Autoatendimento |
| **DefaultPublicar** | Na Ordem de Serviço podemos indicar se serão publicados ou não os apontamentos, com default sempre publicar |
| **DefaultNaoPublicar** | Na Ordem de Serviço podemos indicar se serão publicados ou não os apontamentos, com default nunca publicar |
