# DataRestriction

Caminho: Customização > Modelo de objetos > Utilitários > DataRestriction

Filtra registros para edição em transações de cadastro.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **AuthorizationRoleId** | Identificador do Perfil de acesso proprietário da regra | Inteiro |
| **AuthorizationTransactionId** | Identificador da Transação proprietária da restrição | Inteiro |
| **Property** | Propriedade utilizada na expressão de filtro de registros | [Property](objetos_property) |
| **PropertyId** | Identificador da Propriedade utilizada para comparação nos registros. | Inteiro |
| **ValueFormula** | Fórmula que será computada para formar expressão de filtro. | String |
