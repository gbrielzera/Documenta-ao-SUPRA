# TextBox

Caminho: Guia para Administradores > Roteiro de implantação > Propriedades Customizadas > Criação de Campos Customizados > Tipos de Controle > TextBox

Exibe um campo de edição de texto em uma linha. Para este controle, é possível utilizar valores dos tipos Alfanumérico, Data/hora, Decimal e Inteiro.

Exemplo de controle TextBox

Para controles Textbox, é possível configurar uma máscara de preenchimento, através da propriedade do campo.

Propriedade do campo

Na tela de seleção, podemos realizar o preenchimento da máscara de edição no campo **Máscara de edição **para criar uma máscara personalizada ou selecionar um **Exemplo de configuração **pré-definido. Criada a máscara, é possível fazer um teste logo abaixo, no campo **Testar a máscara**.

Formato da máscara

Assim, ao preencher o campo, este terá o formato definido na propriedade.

Exemplo de máscara

Outra forma de definir uma máscara para um campo é através de scripts, utilizando a propriedade **Mascara** da variavel Formulário no **Script Formulário carregado.**
