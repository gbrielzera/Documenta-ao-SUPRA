# CopiarAnexado

Caminho: Customização > Modelo de objetos > Processo > ClasseAprovacao > CopiarAnexado

Copia para a solicitação de aprovação Itens de Configuração que atendam os critérios de Tipo e Super tipo configurados no Data object de aprovação. Este campo não possui ação quando for configurado no Data Object a cópia de todos os Itens de Configuração associados a Ocorrência.
