# ImpactoParalisacaoIncidente

Caminho: Customização > Modelo de objetos > Processo > ComponenteServico > ImpactoParalisacaoIncidente

Impacto na disponibilização do Serviço em caso de falhas ou mudanças. Este impacto é utilizado no cálculo de Análise de Impacto e determinará se o componente tornará o serviço indisponível.
