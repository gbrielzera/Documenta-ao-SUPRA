# Modelos de Comunicados

Caminho: Guia para Administradores > Configurando Processos > Tutoriais > Tutorial 11: Envio de Comunicados > Modelos de Comunicados

Um modelo de comunicado nada mais é do que um modelo (ou template) de e-mail que pode ser usado, por exemplo, em mensagens disparadas por eventos (Tipos de Eventos) ou em processos (Evento Intermediário por Mensagem).

Os Modelos de Comunicado deverão ser editados exclusivamente pelo Supravizio Web. Caso tente ser editado pelo Supravizio Windows, será exibido um link com redirecionamento para a página de edição Web.

Link para redirecionamento para o Supravizio Web

Para acessar o cadastro de Modelos de Comunicados, no menu principal acesse **Processo | Processos | Modelos de Comunicado**:
