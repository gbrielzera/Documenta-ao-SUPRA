# Tutorial 8: Pré-aprovação de Ordens de Serviço

Caminho: Guia para Administradores > Configurando Processos > Tutoriais > Tutorial 8: Pré-aprovação de Ordens de Serviço

A configuração de pré-aprovação é um recurso do Supravizio que permite agilizar a aprovação de Ordens de Serviço baseado no conhecimento prévio do assunto pelo aprovador, seja por aprovações anteriores realizadas dentro da mesma Ordem de Serviço ou pela abertura da solicitação utilizando a aplicação do Portal de Processos.

Neste tutorial vamos explorar estas duas situações onde são aplicadas a pré-aprovação.
