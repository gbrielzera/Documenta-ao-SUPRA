# Tipo de Item de Configuração

Caminho: Tipo de Item de Configuração

Relação de tipos de Itens de Configuração que serão recuperadaos para cálculo do indicador.

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Super tipo** | Super tipo de Itens de Configuração para Filtro Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna SUPER_CLASSE da tabela [CLASSE_CONF_INDICADOR](dados_classe_conf_indicador). |
|---|---|
| **Tipo de Item de Configuração** | Tipo utilizado para filtro de Itens. Quando não preenchido (campo opcional) são recuperados registros que atendam o critério por Super tipo. Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. |
