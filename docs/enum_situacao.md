# Situacao

Caminho: Customização > Modelo de objetos > Processo > Enumerações > Situacao

Situação

| **Valor** | **Descrição** |
|---|---|
| **Aberto** | Ocorrências em aberto |
| **Cancelada** | A ocorrência foi cancelada |
| **FinalizadaSucesso** | A ocorrência foi finalizada com sucesso |
| **FinalizadaFalha** | A ocorrência foi finalizada como falha |
| **FinalizadaNaoRealizada** | A ocorrência não foi realizada. Possui o mesmo efeito que Cancelada |
| **Agendado** | A ocorrência está agendada com data prevista para retorno a situação Aberto |
