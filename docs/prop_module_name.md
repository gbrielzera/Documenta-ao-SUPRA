# Name

Caminho: Customização > Modelo de objetos > Utilitários > Module > Name

Nome sucinto para o Módulo.

**Exemplo 1: modificação da propriedade Name**

```
# carrega objeto Module de identificador 1
module = Module.Carrega(1)
# modifica a propriedade Name
module.Name = "Nome";
# salva modificação da propriedade Name
Module.Salva(module)
```
