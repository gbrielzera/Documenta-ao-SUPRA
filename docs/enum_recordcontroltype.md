# RecordControlType

Caminho: Customização > Modelo de objetos > Utilitários > Enumerações > RecordControlType

Controles disponíveis para campos em registros

| **Valor** | **Descrição** |
|---|---|
| **TextBox** | TextBox: Caixa de texto |
| **CheckBox** | CheckBox: Caixa de checagem |
| **DropDownList** | Combobox: Caixa de seleção única |
| **DateTimePicker** | DateTimePicker: Caixa de texto para data/hora |
| **DatePicker** | DatePicker: Caixa de texto para data |
