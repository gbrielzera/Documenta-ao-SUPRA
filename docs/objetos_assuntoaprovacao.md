# AssuntoAprovacao

Caminho: Customização > Modelo de objetos > Processo > AssuntoAprovacao

Assunto para Aprovação

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **AcordoInterrupcaoSLA** | Acordo para Interrupção de cronometragem de tempo de atendimento de ocorrências. | [AcordoInterrupcaoSLA](objetos_acordointerrupcaosla) |
| **AcordoNivelServicoId** | Identificador da AcordoInterrupcaoSLA associada | Inteiro |
| **Descricao** | Descricao detalhada | String |
| **Id** | Número sequencial gerado automaticamente pelo sistema para Identificar um AssuntoAprovacao | Inteiro |
| **MotivoInterrupcaoId** | Identificador da AcordoInterrupcaoSLA associada | Inteiro |
| **OcorrenciaId** | Número sequencial gerado automaticamente pelo sistema para Identificar uma Ocorrência | Inteiro |
| **OperacaoAtividade** | Operação de Atividade onde está configurada a operação de Aprovação | [OperacaoAtividade](objetos_operacaoatividade) |
| **OperacaoAtividadeId** | Identificador da Operação Atividade que gerou o Assunto para Aprovação | Inteiro |
| **Versoes** | Versões para Aprovação | [Lista de VersaoAprovacao](objetos_versaoaprovacao) |
