# Gerenciador de Arquivos Anexos em Registros

Caminho: Guia para Administradores > Roteiro de implantação > Realizando cadastros > Telas de Listagem > Telas de cadastros > Gerenciador de Arquivos Anexos em Registros

Existe no Supravizio um recurso de Gerenciador de Arquivos que permite gerenciar arquivos anexos em qualquer registro. Esta opção dispõe ao usuário uma maneira simples de organizar de difundir um conhecimento, seja ele um manual, uma digitalização de um documento, um artigo, etc.

Este tópico apresenta as seguintes ações do Gerenciador de Arquivos:

- [Cadastro de Tipos de Arquivos](cadastro_tipos_arquivos)
- [Anexando arquivos ](manuseando_arquivos_anexos)
- [Acessando o Gerenciador de Arquivos](acessando_gerenciador_arquivos)
