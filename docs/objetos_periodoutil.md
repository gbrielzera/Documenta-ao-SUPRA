# PeriodoUtil

Caminho: Customização > Modelo de objetos > Recurso > PeriodoUtil

Regra que define a disponibilidade de recursos em função dos dias da semana.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **CalendarioId** | Identificador do Calendário proprietário da regra de disponibilidade | Inteiro |
| **DiaSemana** | Dia da semana | [DiaSemana](enum_diasemana) |
| **Disponibilidade** | Validade da regra em função da semana | [DisponibildadeSemana](enum_disponibildadesemana) |
| **HoraFim** | Hora de fim do período de disponibilidade (0 a 23) | Inteiro |
| **HoraInicio** | Hora de início do período de disponibilidade (0 a 23) | Inteiro |
| **Id** | Número sequencial gerado automaticamente pelo sistema para Identificar um PeriodoUtil | Inteiro |
| **MinutoFim** | Minuto fim (0 a 59) | Inteiro |
| **MinutoInicio** | Minuto de início (0 a 59) | Inteiro |
