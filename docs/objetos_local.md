# Local

Caminho: Customização > Modelo de objetos > Recurso > Local

Um Local pode representar um andar, sala ou outra unidade de um Prédio. Também são utilizados para definir localização de Clientes e Ativos (Itens de Configuração).

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **Ativo** | Indica que o Local está ativo no sistema. Quando inativo o local passa a não ser exibido na aplicação de Autoatendimento. | Booleano |
| **Complemento** | Complemento (sala ou andar) que identifica o Local | String |
| **Id** | Número sequencial gerado automaticamente pelo sistema para Identificar um Local | Inteiro |
| **PredioId** | Identificador do Prédio que contém o Local | Inteiro |
