# FormatoExportacaoRelatorio

Caminho: FormatoExportacaoRelatorio

Formato para geração de arquivos a partir de relatórios

| **Valor** | **Descrição** |
|---|---|
| **Excel** | Exporta o relatório para um arquivo no formato Microsoft Excel |
| **PDF** | Exporta o relatório para um arquivo do tipo Portable Document Format (PDF). |
| **Excel2007** | Exporta no formato Excel 2007 |
| **Image** | Exporta uma figura PNG |
| **RTF** | Exporta como texto formatado que pode ser aberto no Microsoft Word |
| **Texto** | Exporta para um arquivo texto |
| **CSV** | Arquivo texto com colunas separadas por ponto e vírgula |
