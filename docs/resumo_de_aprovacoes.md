# Resumo de Aprovações

Caminho: Relatórios > Resumo de Aprovações

O relatório de Resumo de Aprovação tem por objetivo apresentar um histórico das Ordens de Serviços que foram submetidas à aprovação para cada solucionador. Com este relatório é possível analisar o desempenho dos aprovadores de Ordens de Serviço.

## Parâmetros

Na figura abaixo podemos observar a tela de parâmetros para este relatório:

Parâmetros do relatório

| **Pessoa** | Este parâmetro filtra os registros de acordo com o responsável pelo cadastro corrente. Se não for informado este critério é desconsiderado na recuperação (todos são recuperados). |
|---|---|
| **Consultar pessoas inativas** | Este parâmetros filtra os registros de pessoas inativas e é utilizado em conjunto com o parâmetro de Pessoa. Ao marcar este parâmetro será permitido a visualização de registros de pessoas inativas. |

## Saídas

Após informar os parâmetros de recuperação caso seja necessário, clique no botão **Consultar** para visualizar o conteúdo do relatório.

O relatório exibe o **histórico de aprovações** por aprovador. São apresentados os dados relativos a cada aprovação para o aprovador.
