# FieldRestrictionAction

Caminho: Customização > Modelo de objetos > Utilitários > Enumerações > FieldRestrictionAction

Ação aplicada em restrição de acesso de campo

| **Valor** | **Descrição** |
|---|---|
| **Hide** | O campo não será exibido para o usuário. |
| **Disable** | O campo será exibido em modo somente-leitura. |
