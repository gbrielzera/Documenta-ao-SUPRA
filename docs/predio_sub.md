# Prédio

Caminho: Janelas > Recurso > Unidade Negocio > Prédio

Um Prédio define uma edificação dentro de uma Unidade de Negócio onde estão localizados Clientes ou Ativos (Itens de Configuração).

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Identificador** | Número sequencial gerado automaticamente pelo sistema para Identificar um Predio Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna ID_PREDIO da tabela [PREDIO](dados_predio). |
|---|---|
| **Descrição** | Descrição detalhada do Predio Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna DESCRICAO da tabela [PREDIO](dados_predio). |

| **Locais** | Locais Todos os registros desta coleção de dados são mantidos na tabela [LOCAL](dados_local). |
|---|---|
