# TipoApuracaoPesquisa

Caminho: Customização > Modelo de objetos > Processo > Enumerações > TipoApuracaoPesquisa

Tipo de Apuração para Pesquisas de Satisfação

| **Valor** | **Descrição** |
|---|---|
| **Pesquisa** | Realiza a Apuração da Pesquisa. É possível para o usuário computar o Escore Geral da Pesquisa. |
| **Resposta** | Todas as Resposas são Apuradas. É possível para o usuário computar o Escore de cada Questão. |
