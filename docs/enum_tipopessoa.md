# TipoPessoa

Caminho: Customização > Modelo de objetos > Recurso > Enumerações > TipoPessoa

Tipo de Pessoa

| **Valor** | **Descrição** |
|---|---|
| **Cliente** | Pessoa que está habilitada a solicitar serviços. Somente pessoas do tipo Cliente podem acessar a aplicação de Autoatendimento. |
| **Fila** | Representa uma fila de Grupo de Trabalho para a qual é possível enviar Ordens de Serviço. |
