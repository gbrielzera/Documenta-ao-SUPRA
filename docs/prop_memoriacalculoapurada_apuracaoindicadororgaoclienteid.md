# Propriedade ApuracaoIndicadorOrgaoClienteId

Caminho: Propriedade ApuracaoIndicadorOrgaoClienteId

Identificador do órgão cliente

**Exemplo 1: modificação da propriedade ApuracaoIndicadorOrgaoClienteId**

```
# carrega objeto MemoriaCalculoApurada de identificador 1
memoriaCalculoApurada = MemoriaCalculoApurada.Carrega(1)
# modifica a propriedade ApuracaoIndicadorOrgaoClienteId
memoriaCalculoApurada.ApuracaoIndicadorOrgaoClienteId = 1;
# salva modificação da propriedade ApuracaoIndicadorOrgaoClienteId
MemoriaCalculoApurada.Salva(memoriaCalculoApurada)
```
