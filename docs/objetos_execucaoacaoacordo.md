# ExecucaoAcaoAcordo

Caminho: Customização > Modelo de objetos > Processo > ExecucaoAcaoAcordo

Execução de Ação prevista em Acordo

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **AcaoAcordo** | Ação configurada em um Acordo de Nível Operacional | [AcaoAcordo](objetos_acaoacordo) |
| **AcaoAcordoId** | Identificador da Ação executada | Inteiro |
| **DataHoraExecucao** | Data e hora em que foi executada a ação. | Data/hora |
| **OcorrenciaId** | Número sequencial gerado automaticamente pelo sistema para Identificar um Ocorrência | Inteiro |
