# Escore Questão

Caminho: Janelas > Processo > Grupo Questões > Escore Questão

Escore de Questão

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Sequencial** | Define a sequência de apresentação da opção de resposta. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna SEQUENCIAL da tabela [ESCORE_QUESTAO](dados_escore_questao). |
|---|---|
| **Rótulo** | Descritivo apresentado para o usuário como opção. Exemplos: Ótimo, Péssimo, Bom. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna ROTULO da tabela [ESCORE_QUESTAO](dados_escore_questao). |
| **Valor** | Valor atribuído a opção de resposta. Este valor pode ser comparado em fórmulas de cálculo de Indicadores de Desempenho. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna VALOR da tabela [ESCORE_QUESTAO](dados_escore_questao). |
