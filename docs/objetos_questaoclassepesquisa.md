# QuestaoClassePesquisa

Caminho: Customização > Modelo de objetos > Processo > QuestaoClassePesquisa

Questões de Classes de Pesquisa

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **ClassePesquisaSatisfacaoId** | Número sequencial gerado automaticamente pelo sistema para Identificar uma ClassePesquisaSatisfacao | Inteiro |
| **QuestaoPesquisa** | Questão que será incluída na Pesquisa de Satisfação | [QuestaoPesquisa](objetos_questaopesquisa) |
| **QuestaoPesquisaId** | Identificador da QuestaoPesquisa associada | Inteiro |
