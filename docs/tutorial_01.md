# Tutorial 1: Construindo o primeiro Processo

Caminho: Guia para Administradores > Configurando Processos > Tutoriais > Tutorial 1: Construindo o primeiro Processo

O objetivo deste tutorial é demonstrar a criação de um processo contendo um fluxo de baixa complexidade.

Inicialmente criaremos um novo Processo denominado [Administrativo](criando_um_processo). Neste novo processo vamos adicionar um Subprocesso [Adquirir Suprimento](criando_um_sub-processo) e editar o seu fluxo no Editor de Processos BPMN. Durante a modelagem do fluxo serão configurados os [papéis de processo](criando_fluxos_de_processos). Estes papéis definirão as responsabilidades do fluxo. Assim que finalizarmos o fluxo vamos verificar a consistência do subprocesso Adquirir Suprimentos e em seguida [ativá-lo](ativando_processo). Após a ativação será criada uma Ordem de Serviço com o objetivo de ilustrar a [execução do processo](criacao_atendimento) no Supravizio.

**Neste Tutorial encontraremos os seguintes tópicos:**

- [Criar um Processo](criando_um_processo)
- [Criar um Subprocesso](criando_um_sub-processo)
- [Desenho do fluxo](criando_fluxos_de_processos)
- [Ativar um Processo](ativando_processo)
- [Criando e atendendo Ordens de serviço](criacao_atendimento)
