# OpcaoOperacao

Caminho: OpcaoOperacao

Opção na configuração de Operações.

| **Valor** | **Descrição** |
|---|---|
| **Obrigatorio** | O item é obrigatório |
| **OpcionalRecomendado** | O item é opcional e recomendado pela mantenedor do processo. Quando não for preenchido o valor a rotina de Validação gerará um aviso. |
| **Opcional** | O item é opcional |
