# Janelas

Caminho: Janelas

Este capítulo possui documentação de referência sobre todas as Telas que compõem o sistema Supravizio.

Para cada tela, denominada também transação, existe documentação das operações básicas de inclusão, modificação e remoção de registros.

Também faz parte da documentação de cada tela o descritivo de cada campo apresentado na interface.
