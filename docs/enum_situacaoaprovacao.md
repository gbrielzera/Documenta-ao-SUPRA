# SituacaoAprovacao

Caminho: Customização > Modelo de objetos > Processo > Enumerações > SituacaoAprovacao

Situação Aprovação

| **Valor** | **Descrição** |
|---|---|
| **Elaboracao** | A solicitação ainda está em edição e só será enviada para o aprovador após executar o comando Iniciar |
| **Pendente** | A solicitação foi iniciada e aguarda aprovação ou reprovação |
| **Aprovado** | A solicitação foi aprovada com sucesso |
| **Reprovado** | A solicitação foi reprovada |
| **Cancelado** | A solicitação foi cancelada pelo usuário responsável pela ocorrência |
