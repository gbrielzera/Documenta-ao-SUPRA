# OrgaoAtendidoANS

Caminho: Customização > Modelo de objetos > Recurso > OrgaoAtendidoANS

Órgão atendido por um ANS

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **AcordoNivelServicoId** | Identificador do AcordoNivelServico associado | Inteiro |
| **IncluiSubAreas** | Indica que o acordo é extendido para sub-áreas. | Booleano |
| **Orgao** | Órgão atendido pelo ANS | [Orgao](objetos_orgao) |
| **OrgaoId** | Identificador do Orgao associado | Inteiro |
