# Propriedades

Caminho: Janelas > Utilitários > Classes de Negócio > Propriedades

Propriedades nativas de uma Classe de Negócio.

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Nome** | Nome da Propriedade Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna NAME da tabela [SV_PROPERTY](dados_sv_property). |
|---|---|
| **Descrição resumida** | Descrição resumida da Propriedade. Este texto é utilizado como rótulo para a propriedades em telas cadastro (CRUD) Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna TEXT da tabela [SV_PROPERTY](dados_sv_property). |
| **Descrição** | Descrição completa da Propriedade. Este descritivo é utilizado para documentação de telas de cadastro. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna DESCRIPTION da tabela [SV_PROPERTY](dados_sv_property). |
| **Tipo** | Tipo de dados da Propriedade conforme biblioteca de tipos da tecnologia Microsoft .NET Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna TYPE da tabela [SV_PROPERTY](dados_sv_property). |
| **Length** | Tamanho de campos do tipo string. |
| **Chave primária** | Indica que o campo faz parte da chave primária da tabela de banco de dados Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna PRIMARY_KEY da tabela [SV_PROPERTY](dados_sv_property). |
| **Representação textual** | Indica que a propriedade identifica textualmente uma classe Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna IS_TEXTUAL_REPRES da tabela [SV_PROPERTY](dados_sv_property). |
| **Char Case** | Caixa baixa, caixa alta, normal ou entrada de senha Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna CHAR_CASE da tabela [SV_PROPERTY](dados_sv_property). |
| **Coluna de Tabela** | Coluna de tabela que mantém a propriedade. Válido apenas para Classes de Entidade. |
| **Descrição resumida Original** | Descrição resumida Original da Propriedade Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna ORIGINAL_TEXT da tabela [SV_PROPERTY](dados_sv_property). |
| **Descrição original** | Descrição completa Original da Propriedade Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna ORIGINAL_DESCRIPTION da tabela [SV_PROPERTY](dados_sv_property). |
