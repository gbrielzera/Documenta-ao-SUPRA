# Editor de Dashboard

Caminho: Guia para Administradores > Editor de Dashboard

O Supravizio possibilita ao usuário realizar a criação de Dashboards, indicadores de desempenho que fornecem informações imediatas sobre o desempenho dos negócios em toda a empresa.

Para isso, você poderá utilizar o Editor de Dashboard. Para acessar este recurso, no menu principal, selecione **Relatórios** |** Editor de Dashboard**.

Através do Editor de Dashboard o usuário poderá elaborar painéis de indicadores customizados, conforme necessidades dos usuários.
