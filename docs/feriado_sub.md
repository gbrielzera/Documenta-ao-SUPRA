# Feriado

Caminho: Janelas > Recurso > Calendário > Feriado

Um Feriado constitui uma data especial onde considerada, a princípio, dia não-útil.

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Data** | Dia, mês e ano do feriado Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna DATA da tabela [FERIADO](dados_feriado). |
|---|---|
| **Descrição** | Descrição detalhada do Feriado Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna DESCRICAO da tabela [FERIADO](dados_feriado). |
