# GatilhoAssociacao

Caminho: Customização > Modelo de objetos > Processo > GatilhoAssociacao

Gatilhos disparados na ocorrência de um Evento

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **AssociacaoId** | Identificador da Associação | Inteiro |
| **Script** | Script que é executado como resposta do Gatilho | String |
| **TipoEvento** | Tipo de Evento que dispara o Gatilho | [TipoEvento](objetos_tipoevento) |
| **TipoEventoId** | Identificador do Tipo de Evento associado ao Gatilho | Inteiro |
