# Anexando arquivos

Caminho: Guia para Administradores > Roteiro de implantação > Realizando cadastros > Telas de Listagem > Telas de cadastros > Gerenciador de Arquivos Anexos em Registros > Anexando arquivos

Para anexar um arquivo, siga o passo a passo abaixo:

1. Na janela do cadastro que deseja anexar o arquivo, acesse o gerenciador de arquivos através da opção **Mais Ações** e clique em **Adicionar ou Remover arquivos**:

2. Será aberto uma caixa de diálogo com um Gerenciador de Arquivos de anexos. Para anexar um arquivo, basta clicar em **Adicionar Anexo**:

3. Será aberta um novo popup para adicionar o anexo. Selecione o Tipo de Arquivo que deseja anexar:

3. Clique em **Browse**, busque o arquivo que deseja anexar, digite um comentário e clique em **Enviar** para confirmar:
