# Demostrativo de uso de licenças

Caminho: Relatórios > Demostrativo de uso de licenças

O relatório de Demonstrativo de Uso de Licenças tem por objetivo apresentar um resumo quantitativo dos usuários que utilizam o sistema. Com este relatório é possível analisar a quantidade de usuários conectados no sistema simultaneamente e a quantidade de vezes que ocorreu esta conexão simultânea.

## Parâmetros

Na figura abaixo podemos observar a tela de parâmetros para este relatório:

Parâmetros do relatório

| **Data Início** | Data de início para recuperação do quantitativo de usuários. Este parâmetro recupera os valores cuja data de referência seja maior ou igual ao valor informado. |
|---|---|
| **Data Fim** | Data limite fim para recuperação do quantitativo de usuários. Este parâmetro recupera os valores cuja data de referência seja menor ou igual ao valor informado. |

## Saídas

Na saída deste relatório é apresentado um gráfico e uma listagem que mostram a quantidade de usuários conectados simultaneamente pela quantidade de vezes que ocorreu esta conexão simultânea.
