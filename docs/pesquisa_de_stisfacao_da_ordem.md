# Pesquisa de Satisfação da Ordem de Serviço

Caminho: Guia para Solucionadores > Workspace  > Workspace Ordens de Serviço > Pesquisa de Satisfação da Ordem de Serviço

No Supravizio, é possível visualizar a Pesquisa de Satisfação de uma Ordem de Serviço a partir do Workspace.

Primeiramente, é necessário alterar o modo de exibição das Ordens de Serviços no Workspace para apresentar apenas as **finalizadas com sucesso**, pois uma Pesquisa de Satisfação só é solicitada que o Avaliador responda no momento que a Ordem de Serviço é finalizada com sucesso.

Selecionando as Ordens de Serviço Finalizadas com Sucesso

Podemos observar que ao ser exibida ao Ordens de Serviços finalizadas, na última coluna, foi apresentado o resultado da Pesquisa de Satisfação respondida pelo Avaliador:

Satisfação do Avaliador

O resultado da Pesquisa de Satisfação é baseado conforme o Grupo de Questões de uma pergunta da Pesquisa, através dos valores do Escore do Grupo de Questões definido.

|  | ** Valor do Escore** | **Significado do Resultado** |
|---|---|---|
|  | N/A | A Pesquisa de Satisfação não foi respondida. |
|  | Positivo | No resultado geral da Pesquisa de Satisfação, todas as respostas foram positivas. |
|  | 0 (Zero) | No resultado geral da Pesquisa de Satisfação, pelo menos uma resposta foi média, de valor do escore zero, e nenhuma foi negativa. |
|  | Negativo | No resultado geral da Pesquisa de Satisfação, pelo menos uma reposta foi negativa. |

Para visualizar o relatório da Pesquisa de Satisfação temos que abrir a Ordem de Serviço que desejamos analisar.

Na região superior da tela de Ordem de Serviço, há um botão de Pesquisa de Satisfação.

Botão Pesquisa de Satisfação

Clicando no botão, é aberto um relatório da Pesquisa de Satisfação referente àquela Ordem de Serviço:

Relatório de Pesquisa de Satisfação

Podemos observar os dados que são exibidos:

- O Número da OS e o seu assunto;
- O tipo de Pesquisa;
- Sua Situação;
- A data de criação;
- A data de resposta;
- O nome do Avaliador;
- O nome do Responsável Final - o responsável pela última atividade do Processo;
- As perguntas contidas na Pesquisa e suas respostas:

- As respostas do Avaliador;

- Nas respostas mais comuns temos as respostas mais frequentes conforme:

- O Avaliador;

- A Equipe - conforme a equipe do Responsável Final;

- O Subprocesso;

- Padrão de respostas do Avaliador - Um gráfico de setores com uma média das respostas do Avaliador;
- Padrão de respostas para o solucionador final - Um gráfico de setores com uma média das respostas do solucionador final.

## Reenvio de Pesquisas

Podem haver situações em que seja necessário realizar o reenvio de Pesquisas de Satisfação em Ordens de Serviço.

Para estes casos, basta selecionar as Ordens de Serviço na Tela de Listagem do Workspace e em seguida, em **Mais Ações | Reenviar Pesquisa de Satisfação.**
