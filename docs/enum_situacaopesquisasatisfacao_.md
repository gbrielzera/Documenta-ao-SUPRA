# SituacaoPesquisaSatisfacao

Caminho: SituacaoPesquisaSatisfacao

Situação em que se encontra uma Pesquisa de Satisfação

| **Valor** | **Descrição** |
|---|---|
| **Andamento** | A Pesquisa de Satisfação encontra-se em Andamento. |
| **Concluida** | A Pesquisa de Satisfação foi concluída. Todos os Avaliadores responderam ao questionário. |
| **Cancelada** | A Pesquisa de Satisfação foi Cancelada |
| **Elaboracao** | A Pesquisa encontra-se em Elaboração pelo usuário. |
