# FiguraAtividadeEventoIntermediario

Caminho: Customização > Modelo de objetos > Processo > FiguraAtividadeEventoIntermediario

Relacionamento de Figuras de atividades com eventos intermediários

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **FiguraEventoIntermediario** | Evento intermediário proprietário do fluxo | [Figura](objetos_figura) |
| **FiguraEventoIntermediarioId** | Identificador da figura de evento intermediário | Inteiro |
| **FiguraId** | Número sequencial gerado automaticamente pelo sistema para Identificar uma Figura | Inteiro |
| **Id** | Número sequencial gerado automaticamente pelo sistema para Identificar uma FiguraAtividadeEventoIntermediario | Inteiro |
