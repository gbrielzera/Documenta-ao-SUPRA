# Exportação de Dashboards

Caminho: Guia para Solucionadores > Workspace  > Workspace Dashboard > Exportação de Dashboards

Outra possibilidade é a exportação dos painéis exibidos, para que possam ser utilizados como arquivo ou impressos.

Para exportar um dashboard, clique no ícone do canto superior direito na tela e serão abertos os formatos disponíveis:

Ícone para exportação

É possível realizar a exportação para arquivos nas seguintes extensões:

- Pdf
- Png
