# TipoAprovador

Caminho: Customização > Modelo de objetos > Processo > Enumerações > TipoAprovador

Tipo de aprovador

| **Valor** | **Descrição** |
|---|---|
| **Unico** | A aprovação é realizada em uma única etapa. |
| **HierarquiaInicial** | A aprovação é realizada por hierarquia e este aprovador é o incial na sequência. |
| **HierarquiaFinal** | A aprovaçáo é realizada por hierarquia e este aprovador representa aquele de cargo mais elevado |
