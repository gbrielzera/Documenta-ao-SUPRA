# SituacaoTimeSheet

Caminho: Customização > Modelo de objetos > Processo > Enumerações > SituacaoTimeSheet

Indica se o apontamento está aprovado, apropriado ou simplesmente apontado

| **Valor** | **Descrição** |
|---|---|
| **Apontado** | Situação inicial de um apontamento |
| **Apropriado** | Indica se o apontamento pertence a alguma apropriação de horas. |
| **Aprovado** | Indica se o apontamento está aprovado. |
