# CriterioChargeBack

Caminho: Customização > Modelo de objetos > Ativos > Enumerações > CriterioChargeBack

Critério de apuração de Charge-back que define o destinatário do custo. O valor Item indica que o critério será delegado ao Item de Configuração desta classe.

| **Valor** | **Descrição** |
|---|---|
| **Usuario** | Utiliza a relação de usuário de um Item de Configuração para endereçar o custo. |
| **Responsavel** | Utiliza a relação de responsabilidade de um Item de Configuração para endereçar o custo. |
| **Item** | Delega critério de charge-back para cadastro do Item de Configuração. |
