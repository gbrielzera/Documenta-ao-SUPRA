# Cadastro de Pessoas

Caminho: Guia para Administradores > Roteiro de implantação > Realizando cadastros > Cadastro de Pessoas

Uma Pessoa pode representar um Cliente, um Solucionador ou uma fila de atendimento. Um registro do tipo Pessoa deve obrigatoriamente estar associado a um Órgão, e por meio desta associação é possível determinar seu gestor. No cadastro de uma Ordem de Serviço encontramos os campos Cliente e Responsável que representam a pessoa que solicitou e a responsável pelo atendimento respectivamente.

Para incluir um novo registro neste cadastro, acesse o caminho **Recurso | Pessoas**:

Caminho para acesso a tela

Na tela que abrir, clicando no botão Novo será exibido o diálogo de edição para preenchimento do novo registro.

Botão 'Novo'

O cadastro da Empresa terá os seguintes campos:

Cadastro de Pessoa

Caso hajam dúvidas a respeito destes campos, leia o tópico sobre [Pessoas](pessoa_sub).

Assim que finalizada a edição clique no botão **Salvar** para gravar os dados ou **Salvar e Voltar** para gravar e voltar para a tela anterior.
