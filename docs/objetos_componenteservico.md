# ComponenteServico

Caminho: Customização > Modelo de objetos > Processo > ComponenteServico

Item de Configuração Componente de Serviço

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **ImpactoParalisacaoIncidente** | Impacto na disponibilização do Serviço em caso de falhas ou mudanças. Este impacto é utilizado no cálculo de Análise de Impacto e determinará se o componente tornará o serviço indisponível. | [ImpactoParalisacaoIncidente](enum_impactoparalisacaoincidente) |
| **ItemConfiguracao** | Item de Configuração componente | [ItemConfiguracao](objetos_itemconfiguracao) |
| **ItemConfiguracaoId** | Identificador do ItemConfiguracao associado | Inteiro |
| **ServicoId** | Identificador do Serviço | Inteiro |
