# Tipos de Subprocesso para recuperação

Caminho: Janelas > Processo > Indicador > Tipos de Subprocesso para recuperação

Tipos de Subprocessos que serão utilizados como filtro das ocorrências utilizados no cálculo do indicador

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Tipo de Subprocesso** | Um Tipo de Subprocesso mantém características de um fluxo que são invariáveis entre suas diversas versões. Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
