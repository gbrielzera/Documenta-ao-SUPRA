# Importando mais informações

Caminho: Guia para Administradores > Roteiro de implantação > Importando Dados > Rotina de Importação de Dados de Recursos Humanos > Importando mais informações

Através do recurso de importação, é possível importar informações adicionais nos cadastros. Para isso, utilizamos o recurso de [Campos Customizados](campos_customizados) e a inclusão de colunas nas fontes de dados relacionadas. A importação de campos adicionais pode ser utilizada para a importação de dados de Empresas, Pessoas, Áreas e Fornecedores.

Neste tópico, iremos citar como exemplo a importação de uma coluna na Fonte de Dados de Pessoas, para o campo customizado CPF. Inicialmente, criamos o campo no cadastro conforme explicamos anteriormente no tópico [Criando uma Propriedade Customizada](criando_propriedade_customizada).

Configuração da Propriedade Customizada

**Importante:** A propriedade customizada deve ter o mesmo nome e tipo de dados da coluna adicional da fonte de dados.
