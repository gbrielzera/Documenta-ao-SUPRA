# Acessando o Portal

Caminho: Guia para Administradores > Portal de Processos > Primeiro acesso ao Portal > Acessando o Portal

O acesso ao Portal, que pode ser realizado de duas maneiras:

### Ícone no menu do Supravizio Web

Caso o usuário seja Solucionador, no Supravizio Web, haverá um ícone no menu, o qual redirecionará para o site do Portal.

Ícone possui o formato de um globo
