# RiscoAfirmacao

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **AfirmacaoFinanceira** | Afirmação financeira associada com o Controle. | [AfirmacaoFinanceira](objetos_afirmacaofinanceira) |
| **AfirmacaoFinanceiraId** | Identificador da AfirmacaoFinanceira associada | Inteiro |
