# Layout de Painéis

Caminho: Guia para Administradores > Editor de Dashboard > Criando Dashboards > Layout de Painéis

O Editor de Dashboard permite o ajuste do layout durante a criação do painel de uma maneira simples.

## Posicionamento de Itens

Para alterar a posição de um item no painel, basta clicar sobre o título do mesmo e arrastá-lo para o local desejado. Quando houver um local o qual será permitido o reposicionamento, aparecerá um espaço em azul.

Em alguns casos, quando o gráfico não tiver título, aparecerá um ícone que permite a seleção do item.

## Redimensionando itens

Para redimensionar um item no painel, passe o mouse sobre a borda do lado no qual se deseja realizar o redimensionamento e arraste até o tamanho desejado.

## Excluindo itens

Para excluir um item do painel, basta clicar sobre o mesmo com o botão direito do mouse e em seguida, na opção **Delete**.

## Renomeando rótulos

Todos os títulos e rótulos apresentados no gráfico podem ser customizados conforme necessidade do cliente. Para isso, clique com o botão direito sobre o gráfico e depois, na opção **Edit Names...**

Logo, será aberta uma janela contendo todos os itens disponíveis no gráfico que podem ser renomeados.
