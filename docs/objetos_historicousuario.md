# HistoricoUsuario

Caminho: Customização > Modelo de objetos > Recurso > HistoricoUsuario

Histórico de usuários para um Item de Configuração. Este histórico é gerado pela rotina de charge-back para rastreabilidade da base de cálculo.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **HistoricoItemChargeBackId** | Identificador da apuração de Charge-back que gerou o histórico | Inteiro |
| **HistoricoItemItemConfiguracaoId** | Identificador do Item de Configuração proprietário do histórico | Inteiro |
| **Usuario** | Usuário do item de configuração na ocasição da apuração de Charge-back. | [Pessoa](objetos_pessoa) |
| **UsuarioId** | Identificador da Pessoa usuária do Item de Configuração na ocasião da apuração de Charge-Back | Inteiro |
