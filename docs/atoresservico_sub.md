# Atores de Serviço

Caminho: Janelas > Processo > Serviço > Atores de Serviço

Atores

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Papel para redefinição** | Papel de Processo que é alvo de redefinição no Serviço. Para um Serviço é possível criar diversas redefinições de Papel. Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
|---|---|
| **Papel para redirecionamento** | Papel de Classe de Negócio utilizado como redirecionamento no instante de cálculo de Atores. Se este campo for preenchido o sistema automaticamente limpa o conteúdo do campo 'Pessoa'. Somente um destes campos pode ser preenchido. IMPORTANTE: Este recurso demanda cuidado especial com a criação de redefinições recursivas de Papeis. Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. |
| **Pessoa para redirecionamento** | Indica a Pessoa selecionada como Ator para o Papel configurado. Se este campo for preenchido então o sistema automaticamente limpa o campo 'Papel para redirecionamento'. Somente um destes campos pode ser preenchido. Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. |
