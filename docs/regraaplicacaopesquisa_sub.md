# Regra Aplicação Pesquisa

Caminho: Regra Aplicação Pesquisa

Regra de Aplicação de Pesquisa de Satisfação. Em uma regra é possível redefinir a configuração de Percentual de Envio por Contrato de Fornecedor (esta configuração é originalmente definida na própria Classe de Pesquisa de Satisfação).

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Contrato** | Contrato de Prestação de Serviços alvo da redefinição de Percentual de Envio Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
|---|---|
| **Percentual envio** | Número percentual entre 0 e 100 que indica a probabilidade de envio de Pesquisa de Satisfação. O valor 0 indica que nenhuma Pesquisa será enviada enquanto 100 estabelece que sempre será enviada Pesquisa de Satisfação Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna PERCENTUAL_ENVIO da tabela [REGRA_APLIC_PESQ](dados_regra_aplic_pesq). |
