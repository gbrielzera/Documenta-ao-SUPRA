# MotivoApontamento

Caminho: Customização > Modelo de objetos > Processo > MotivoApontamento

Motivo Apontamento

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **ApontamentoId** | Número sequencial gerado automaticamente pelo sistema para Identificar um Apontamento | Inteiro |
| **Codigo** | Código do motivo | String |
| **Descricao** | Descrição | String |
| **Sequencial** | Sequencial gerado para identificar um Motivo de Apontamento | Inteiro |
