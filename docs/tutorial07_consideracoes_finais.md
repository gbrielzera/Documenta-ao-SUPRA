# Considerações finais

Caminho: Guia para Administradores > Configurando Processos > Tutoriais > Tutorial 7: Inclusão e remoção de usuários em Itens de Configuração > Considerações finais

Utilizando a mesma técnica apresentada neste tutorial podemos também realizar a operação de remoção de usuários a partir de um Item de Configuração associado na Ordem de Serviço. Na figura abaixo podemos observar o subprocesso de Remoção de Acesso configurada para remover o usuário favorecido de um Item de Configuração do tipo Perfil de acesso.

Remoção de usuários em Itens de Configuração

A modificação dos usuários, inclusão ou remoção, pode ocorrer na finalização, conforme exemplos apresentados neste tutorial, ou após a finalização da atividade que ocorre quando avançamos no assistente de processos. É importante observar que a reabertura de uma Ordem de Serviço ou a execução do comando Voltar do assistente de processos não desfazem a inclusão ou remoção de usuários.
