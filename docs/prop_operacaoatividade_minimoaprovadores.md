# MinimoAprovadores

Caminho: Customização > Modelo de objetos > Processo > OperacaoAtividade > MinimoAprovadores

Quantidade mínima de aprovações para aprovação total da solicitação. A reprovação ocorre quando o número mínimo de aprovadores não pode ser atingido. Se este campo não for preenchido então a solicitação só é totalmente aprovada quando Todos aprovarem.
