# Filtros

Caminho: Guia para Administradores > Editor de Dashboard > Criando Dashboards > Interatividade > Filtros

O Dashboard permite que sejam utilizados qualquer item do mesmo para realizar um filtro geral em todo o painel. Assim, o usuário pode selecionar campos individualmente em um item para filtrar dados em todo o restante do painel.

Opções de utilização do filtro

Para fazer com que um item atue como um filtro, utilize a opção da Barra de Menus. Caso já haja um filtro e seja necessário removê-lo, clique no ícone .

Assim como o Drill-Down, podemos permitir uma interação do usuário com os dados apresentados, utilizando as opções: e para filtro nas seções de dados Series e Arguments, respectivamente.

Quando é utilizada mais de uma Fonte de Dados em um mesmo painel, é possível realizar um filtro mestre que será aplicada em todas. Clicando no ícone , será habilitada a opção que vai permitir tal filtragem, levando em consideração o nome correspondente selecionado no gráfico.

Também podemos fazer com que determinado gráfico ignore quaisquer filtros realizados em outro item do painel, utilizando o botão .
