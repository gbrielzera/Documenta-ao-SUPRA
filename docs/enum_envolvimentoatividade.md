# EnvolvimentoAtividade

Caminho: Customização > Modelo de objetos > Processo > Enumerações > EnvolvimentoAtividade

Tipo de envolvimento em atividade utilizado para recuperação de solucionadores no cálculo de papéis

| **Valor** | **Descrição** |
|---|---|
| **Inicial** | Solucionador indicado como primeiro responsável pela execução da atividade |
| **Final** | Solucionador indicado como finalizador na execução da atividade |
| **ResponsavelANO** | Solucionador identificado como responsável final pelo ANO. Esta opção é aplicável a atividade que possuem configuração de ANO. |
