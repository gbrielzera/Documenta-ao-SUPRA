# ResponsavelCancelamentoId

Caminho: Customização > Modelo de objetos > Processo > Pesquisa > ResponsavelCancelamentoId

Identificador da Pessoa associada

**Exemplo 1: modificação da propriedade ResponsavelCancelamentoId**

```
# carrega objeto Pesquisa de identificador 1
pesquisa = Pesquisa.Carrega(1)
# modifica a propriedade ResponsavelCancelamentoId
pesquisa.ResponsavelCancelamentoId = 1;
# salva modificação da propriedade ResponsavelCancelamentoId
Pesquisa.Salva(pesquisa)
```
