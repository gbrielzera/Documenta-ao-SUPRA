# PassagemItens

Caminho: Customização > Modelo de objetos > Processo > PassagemItens

Configura uma regra de passagem de Itens de Configuração para Ordens de Serviço invocadas como Subprocessos ou link final.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **AtividadeId** | Identificador da Atividade | Inteiro |
| **ClasseConfiguracao** | Tipo Item de Configuração | [ClasseConfiguracao](objetos_classeconfiguracao) |
| **ClasseConfiguracaoId** | Identificador do Tipo de Item de Configuração que terá itens passados como parâmetros para a rotina chamada. | Inteiro |
| **Id** | Número sequencial gerado automaticamente pelo sistema para Identificar um PassagemItens | Inteiro |
