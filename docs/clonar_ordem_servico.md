# Clonar uma Ordem de Serviço

Caminho: Guia para Solucionadores > Workspace  > Workspace Ordens de Serviço > Clonar uma Ordem de Serviço

A funcionalidade de clonar uma Ordem de Serviço consiste em copiar as características de uma Ordem de Serviço para um diálogo de criação de nova Ordem de Serviço. Isto facilita a criação de uma nova Ordem de Serviço pois será clonado os dados principais, mantendo a associação de processo, subprocesso e serviço e a até mesmo com itens de configuração anexados.

Existem duas formas de clonar Ordens de Serviço. A primeira forma é no menu da tela de Edição de Ordens de Serviço:

1. Abra a Ordem de Serviço que deseja Clonar e na tela de Edição de Ordens de Serviço selecione no menu a opção Mais Ações e clique em Clonar:

Opção Clonar no menu da tela de Edição de Ordens de Serviços

2. Ao clicar em Clonar será aberto uma nova tela de Edição de Ordens de Serviço, com os dados principais já preenchidos (de acordo com a Ordem de Serviço clonada), associada ao mesmo processo, subprocesso, serviço e itens de configuração se existirem:

Diálogo aberto após clonar Ordem de Serviço

3. Com os campos da aba Dados Principais já clonados da Ordem de Serviço anterior é possível realizar modificações se necessário e salvar a Nova Ordem de Serviço:

Nova Ordem de Serviço

A segunda forma de clonar Ordens de Serviço é feita através da tabela de Ordens de Serviço no Workspace:

1. Selecione uma Ordem de Serviço na tabela do Workspace, clique com o botão direito e selecione Clonar nova:

Clonando nova Ordem de Serviço

Após clicar em Clonar nova ocorrerá o mesmo processo da primeira opção de clonar Ordens de Serviço.
