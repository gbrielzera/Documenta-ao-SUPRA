# Workspace  > Workspace Opções

Caminho: Guia para Solucionadores > Workspace  > Workspace Opções

A tela de **Opções** do Workspace possibilita ao usuário realizar registros de ausências temporárias e substituições:

Ao Salvar a ausência desejada na tela de Opções, é possível identificar na árvore da tela de Ordens de Serviço que o Substituído se torna um sub-item do Substituto.

O coordenador de um Grupo de trabalho tem permissão para definir ausências para toda a sua equipe, basta escolher em Ausência corrente o usuário que deseja ausentar e preencher o período de ausência, motivo da ausência e o seu substituto. Já um usuário que não é nomeado como coordenador tem permissão para gerenciar somente suas ausências:

Se ocorrer de um determinado usuário necessitar se ausentar e não definir na tela de Opções do Supravizio o seu substituto, somente Coordenador da Equipe ou Administrador poderão realizar esta substituição.

O coordenador da equipe pode ser identificado na tela de Grupo de trabalho:

São apresentadas três opções de permissões para o substituto:

- Permitir que o Substituto modifique todas as Ordens de Serviço no período de ausência.

Esta opção permite que o substituto possa gerenciar todas as Ordens de Serviço do substituído:

- Redirecionar encaminhamentos para o Substituto.

Ao ativar esta opção é redirecionado todos os encaminhamentos de Ordens de Serviço do Substituído para o Substituto.

- Permitir que o Substituto realize aprovações em seu nome.

Esta opção permite o Substituto realizar as aprovações do Substituído. É importante observar que selecionando esta opção, o campo de Substituto para aprovações no cadastro de Pessoas será preenchido.

Em Pessoa Substituída é possível visualizar os dados abaixo:

| **Campo** | **Descrição** |
|---|---|
| **Data início** | Data início de validade para a regra de Ausência Temporária. |
| **Retorno** | Data para Previsão de retorno do ausente. |
| **Substituído** | Pessoa ausente temporariamente. |
| **Registro** | Registro de ausência. |
| **Permite Modificar** | Permitir que o Substituto modifique todas as Ordens de Serviço no período de ausência do Substituído. |
| **Encaminhar** | Permissão de encaminhamento. |

Para visualizar Pessoas Substituídas é necessário que em Ausência Corrente selecionar o técnico Substituto:

É possível também visualizar o Histórico das ausências realizadas. Para isso é necessário que selecionar em Ausência Corrente o técnico Substituído.
