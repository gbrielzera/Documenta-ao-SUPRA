# Configurar o Tipo de Item de Configuração

Caminho: Guia para Administradores > Configurando Processos > Tutoriais > Tutorial 9: Manipulação de Arquivos Anexos > Configurar o Tipo de Item de Configuração

Um Artefato que possui como fonte de dados o sistema de arquivos pode ser configurado para compartilhar o arquivo na rede ou realizar transferência da estação servidora para a estação cliente.

Neste tópico vamos configurar um Tipo de Item de Configuração para ser acessado por Compartilhamento.

### 1. Acessando a configuração do Tipo de Item de Configuração

Para acessar a configuração de um Tipo de Item de Configuração é necessário acessar a lista de cadastros, para isso acesse a opção do menu **Ativos | Tipos de Itens de Configuração** conforme a Figura abaixo.

Acesso a lista de Tipos de Itens de Configuração

Para localizar o **Tipo de Item de Configuração** utilizado no Subprocesso do tutorial [Manipulação de Arquivos Anexos](tutorial_10_manipulacao_de_arq) basta realizar uma pesquisa na lista de Tipos cadastrados. Neste exemplo estamos utilizando **Especificação Técnica**.

Pesquisando por Especificação

### 2. Configurar a Forma de Acesso da Especificação Técnica

A próxima tarefa é configurar a Forma de Acesso do tipo selecionado, para isso na tela de cadastro selecione a Aba **Artefatos** conforme Figura abaixo.

Configurando a Forma de Acesso

Ao final **salve** a configuração.
