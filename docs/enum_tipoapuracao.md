# TipoApuracao

Caminho: Customização > Modelo de objetos > Processo > Enumerações > TipoApuracao

Tipo de informação Apurada para Indicadores de Desempenho

| **Valor** | **Descrição** |
|---|---|
| **TotalFinalizado** | Os valores se referem a um período finalizado |
| **ParcialGrupoTrabalho** | Totais Parciais para um Grupo de Trabalho. |
| **ParcialTecnico** | Resultado parcial associado a uma Pessoa que realiza o papel de Solucionador |
