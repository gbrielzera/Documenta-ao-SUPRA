# Visão geral

Caminho: Apresentação > Visão geral

### O Supravizio é um sistema para gerenciamento de processos que contempla todos os passos do ciclo PDCA.

Em uma única ferramenta você será capaz de modelar graficamente um processo de negócio, automatizar o workflow e realizar a gestão por relatórios e indicadores. Com ele você contará com recursos que facilitarão a prática da melhoria continuada de processos e a geração de evidências para auditorias.

## Plan: Editor Gráfico de Processos

O editor gráfico de processos permite a utilização da notação BPMN para definir tarefas, formulários, aprovações e responsabilidades. Todas as regras configuradas são utilizadas para geração dos formulários eletrônicos e controlar o fluxo de trabalho.

O editor de processos é uma ferramenta totalmente integrada aos demais módulos incluindo interfaces web para todos os usuários, máquina de processos, documentação e relatórios.

**Editor de Processos**

## Do: Formulário Eletrônico e Máquina de Processos

Após desenhar e configurar os fluxos no editor gráfico é feita a ativação do processo, que pode ser iniciado de diversas formas:

- Manualmente pelo preenchimento de formulários
- Por temporizador (diário, semanal, mensal, anual etc)
- Por Webservices
- Por comandos SQL (consulta de banco de dados)
- Recebimento de emails e outras formas via customização

Portal de Processos

Solicitações de um determinado processo são encaminhadas para usuários Solucionadores, que serão orientados pelo sistema para o cumprimento de todas as atividades previstas no processo. Em qualquer momento do processo, inclusive imediatamente após a abertura, é possível incluir aprovações com flexibilidade de configuração.

Workspace

Ao atender uma solicitação o Solucionador conta com um Assistente de Processos, que o guiará em todas as atividades do workflow. Este assistente também exigirá do usuário o fornecimento de todas as evidências necessárias em auditorias por meio de preenchimento de formulários, vinculação de arquivo, envio de comunicados etc.

Edição de Ordem de Serviço

Para cada processo e tarefa existirão prazos de execução com a possibilidade de alarmes (Exemplo: ao atingir 50% do prazo de uma tarefa enviar email para seu gerente, ao atingir 80% do prazo da mesma tarefa escalonar para o coordenador imediato etc).

A qualquer momento é possível visualizar graficamente a situação de uma solicitação e todo o caminho percorrido no workflow até o momento. O software permite recuperar tempos de execução, histórico de responsabilidades, apontamentos de horas trabalhadas, comunicados gerados e recebidos, detalhes sobre o Acordo de Nível de Serviço e Acordo de Nível Operacional etc.

Informações sobre o Processo

O produto permite execução de tarefas automáticas e integradas com sistemas de informação via Webservices e acesso direto a base de dados.
