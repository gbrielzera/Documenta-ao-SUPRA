# Publicando um aviso no Mural

Caminho: Guia para Solucionadores > Workspace  > Workspace Ordens de Serviço > Publicando um aviso no Mural

O Mural de Avisos exibe mensagens publicadas por solucionadores através do Workspace do Supravizio.

Aviso publicado

Neste tópico, explicaremos sobre a criação de avisos no Mural.

Inicialmente, é necessário verificarmos se o usuário logado está alocado em um Grupo de Trabalho que possa realizar tal operação. Para mais informações sobre a configuração deste permissionamento, leia o tópico [Restringindo Ações para Grupos de Trabalho](workspace_restricao_grupos).

O atalho para criação está localizado na Barra de Ferramentas, conforme indicado na figura abaixo:

Botão Gerar Aviso

Ao clicar neste botão, será aberta a seguinte tela:

Gerenciar Mural

Ao clicar para adicionar um novo aviso, será aberta a seguinte tela:

Novo Aviso

A tela possui os seguintes parâmetros:

- **Mensagem** - Mensagem a ser exibida no Mural de Avisos;
- **Mensagem Portal** - Sobrepõe a mensagem preenchida no campo anterior durante a exibição no Portal. Caso este campo não seja preenchido, será exibido o campo Mensagem;
- **Data Início** - Data inicial em que o aviso estará visível;
- **Data Limite** - Data limite para visibilidade do aviso. Caso não seja preenchido, o aviso não terá limite de temporalidade;
- **Visível no Portal** - Indica a visibilidade do aviso no portal. Caso contrário, será exibido apenas no Workspace;
- **Desativar** - Caso seja marcado, o aviso não é mais exibido, porém, ainda não deletado. Portanto, poderá ser reativado quando for necessário apenas desmarcando esta opção;
- **Grupos de Trabalho Destinatários** - Este campo vai indicar quais grupos de trabalho no Workspace vão visualizar este aviso. No caso do Portal, não atende a esta regra, pois sempre estará visível a todos.

Também é possível realizar a publicação de um aviso em associação a uma Ordem de Serviço, através do seguinte comando:

Localização do botão

Caso possua uma associação, ao clicar no aviso, a página será redirecionada para a Ordem de Serviço que o gerou:

Ordem de Serviço que gerou o aviso

**Importante**: Também é possível gerar novos avisos no mural associados à artigos da Base de Conhecimento. Para saber mais sobre esta associação, leia o tópico [Itens de Configuração](data_obj_itens_de_configuracao).
