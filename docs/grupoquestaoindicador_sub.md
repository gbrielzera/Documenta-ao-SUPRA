# Grupo Questão Indicador

Caminho: Janelas > Processo > Indicador > Grupo Questão Indicador

Grupos de Questões para Filtro durante a Apuração de Pesquisas de Satisfação.

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Grupo Questão** | Recupera apenas respostas de um determinado grupo. Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
|---|---|
| **Questão** | Questão para filtro Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. |
