# Propriedade Sequencia

Caminho: Propriedade Sequencia

Sequencia de memória gerada pela rotina de Apuração

**Exemplo 1: modificação da propriedade Sequencia**

```
# carrega objeto MemoriaCalculoApurada de identificador 1
memoriaCalculoApurada = MemoriaCalculoApurada.Carrega(1)
# modifica a propriedade Sequencia
memoriaCalculoApurada.Sequencia = 1;
# salva modificação da propriedade Sequencia
MemoriaCalculoApurada.Salva(memoriaCalculoApurada)
```
