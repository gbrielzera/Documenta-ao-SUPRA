# ObrigatoriedadePreenchimentoAprovacao

Caminho: Customização > Modelo de objetos > Processo > Enumerações > ObrigatoriedadePreenchimentoAprovacao

Indica a obrigatoriedade de preenchimento para um campo de preenchimento de aprovação, se para Aprovações, Reprovações, Todas ou Nenhuma obrigatoriedade.

| **Valor** | **Descrição** |
|---|---|
| **Aprovacao** | Indica que o preenchimento é obrigatório para uma Aprovação |
| **Reprovacao** | Indica que o preenchimento é obrigatório para uma Reprovação |
| **Todas** | Indica que o preenchimento é obrigatório para uma Aprovação ou Reprovação |
| **Nenhuma** | Indica que o preenchimento não é obrigatório |
