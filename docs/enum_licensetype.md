# LicenseType

Caminho: Customização > Modelo de objetos > Utilitários > Enumerações > LicenseType

Tipo de licenciamento do Supravizio

| **Valor** | **Descrição** |
|---|---|
| **ConcurrentUsers** | Licenciamento por usuários concorrentes. O sistema bloqueia o login de um determinado usuário se o número máximo de Sessões de Usuários. |
| **NamedUsers** | Licenciamento por Usuários nomeados. |
