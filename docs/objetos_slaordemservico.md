# SLAOrdemServico

Caminho: Customização > Modelo de objetos > Processo > SLAOrdemServico

Acordo de Nível de Serviço selecionado para Ordem de Serviço

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **NivelSLA** | Nível ANS | [NivelSLA](objetos_nivelsla) |
| **NivelSLAId** | Identificador da NivelSLA associada | Inteiro |
| **OrdemServicoId** | Identificador da Ordem de Serviço | Inteiro |
| **Referencia** | Referência sobre o cálculo do Nível de Serviço | String |
| **Tempo** | Tempo em minutos para Nível de Serviço | Inteiro |
