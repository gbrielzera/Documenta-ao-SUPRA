# RecordType

Caminho: Customização > Modelo de objetos > Utilitários > Enumerações > RecordType

Tipo de dados para colunas em registros

| **Valor** | **Descrição** |
|---|---|
| **Boolean** | Verdadeiro ou Falso |
| **DateTime** | Data e hora |
| **Decimal** | Números decimais ponto fixo |
| **Integer** | Números inteiros |
| **String** | Caracteres alfanuméricos |
