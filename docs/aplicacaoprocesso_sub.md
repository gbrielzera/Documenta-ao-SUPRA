# Aplicação em Processos

Caminho: Janelas > Recurso > Acordo de Nível de Serviço > Aplicação em Processos

Relação de subprocessos onde o Acordo de Nível de Serviço pode ser aplicado.

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Tipo de Subprocesso** | Um Tipo de Subprocesso mantém atributos de um fluxo de processo que são invariáveis em suas diversas versões. Tipos de Subprocessos podem definir rotinas internas para a área ou solicitações disponíveis para os Clientes. Também podem representar Subprocessos de rotinas de grande complexidade. Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
