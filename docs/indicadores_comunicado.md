# Acompanhando respostas de Comunicados

Caminho: Guia para Solucionadores > Workspace  > Workspace Ordens de Serviço > Comunicados em Ordens de Serviço > Acompanhando respostas de Comunicados

Podemos visualizar diretamente no grid se foi enviado um comunicado na Ordem de Serviço e se este foi respondido. Utilizando este indicador, é possível acompanhar em tempo real o envio e recebimento de mensagens referentes à Ordem de Serviço.

Cada ícone é apresentado conforme a situação. Iremos apresentá-los a seguir:

### Ícone verde apontando à direita

Este ícone será exibido quando um comunicado for enviado manualmente.

Conforme a imagem a seguir:

Ícone verde

### Ícone azul apontando à esquerda

Este ícone será exibido quando o comunicado for respondido por um solucionador do grupo responsável pela Ordem de Serviço.

Conforme a imagem a seguir:

Ícone azul

### Ícone vermelho apontando à esquerda

Este ícone será exibido quando o comunicado for respondido por um usuário que não é solucionador do grupo.

Conforme a imagem a seguir:

Ícone vermelho

### Retirando o ícone do indicador

Para que o indicador não seja mais exibido no grid, basta clicar com o botão direito sobre a Ordem de Serviço e selecionar a opção "Marcar como Lida".
