# ApuracaoIndicadorItemConfiguracao

Caminho: Customização > Modelo de objetos > Processo > ApuracaoIndicadorItemConfiguracao

Apuração de Indicador de Desempenho que tenha como fonte de dados banco de Itens de Configuração.

Este tipo herda atributos e funcionalidades do ancestral [ApuracaoIndicador](objetos_apuracaoindicador)

Operações:

| **Nome** | **Descrição** | **Assinatura** |
|---|---|---|
| **Carrega** | Recupera do banco de dados o objeto com a chave de busca fornecida como parâmetro. | ApuracaoIndicadorItemConfiguracao Carrega(string nomePropriedade, object valorPropriedade); |
