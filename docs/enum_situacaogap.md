# SituacaoGap

Caminho: Customização > Modelo de objetos > Processo > Enumerações > SituacaoGap

Siguação de um Gap encontrado durante o processo de Teste de Controles de Atividades

| **Valor** | **Descrição** |
|---|---|
| **Analisado** | O Gap foi analisado |
| **Cancelado** | O Gap foi cancelado por um Coordenador de Grupo de Trabalho. |
| **Levantado** | O Gap foi levantado |
