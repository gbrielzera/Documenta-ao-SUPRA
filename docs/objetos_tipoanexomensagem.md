# TipoAnexoMensagem

Caminho: Customização > Modelo de objetos > Processo > TipoAnexoMensagem

Tipos de arquivos que serão anexados no comunicado gerado pelo evento

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **AtividadeId** | Identificador do evento intermediário que gerará o comunicado | Inteiro |
| **ClasseConfiguracao** | Tipo de arquivo que será anexado no comunicado | [ClasseConfiguracao](objetos_classeconfiguracao) |
| **ClasseConfiguracaoId** | Identificador do tipo de arquivo que será anexado no comunicado | Inteiro |
