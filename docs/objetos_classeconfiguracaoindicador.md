# ClasseConfiguracaoIndicador

Caminho: Customização > Modelo de objetos > Processo > ClasseConfiguracaoIndicador

Relação de tipos de Itens de Configuração que serão recuperadaos para cálculo do indicador.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **ClasseConfiguracao** | Tipo utilizado para filtro de Itens. Quando não preenchido (campo opcional) são recuperados registros que atendam o critério por Super tipo. | [ClasseConfiguracao](objetos_classeconfiguracao) |
| **ClasseConfiguracaoId** | Identificador do Tipo de Item de Configuração associado | Inteiro |
| **IndicadorId** | Número sequencial gerado automaticamente pelo sistema para Identificar um Indicador | Inteiro |
| **Sequencial** | Sequencial | Inteiro |
