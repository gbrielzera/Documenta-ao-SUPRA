# TempoANORealizado

Caminho: Customização > Modelo de objetos > Processo > ExecucaoAtividade > TempoANORealizado

Tempo realizado (em minutos) do Acordo de Nível de Serviço considerando disponibilidade de recursos configurada no calendário. Este tempo é gravado pelo sistema no instante em que a atividade é finalizada.
