# GrupoTrabalhoAutorizado

Caminho: GrupoTrabalhoAutorizado

Grupos de Trabalho que estão autorizados a visualizar o resultado da apuração de indicadores.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **GrupoTrabalho** | Grupo Trabalho | [GrupoTrabalho](objetos_grupotrabalho) |
| **GrupoTrabalhoId** | Identificador do GrupoTrabalho associado | Inteiro |
| **IncluiSubGrupos** | Permite que sub-grupos acessem o Plano de Gestão. | Booleano |
| **PlanoGestaoId** | Número sequencial gerado automaticamente pelo sistema para Identificar um PlanoGestao | Inteiro |
