# Restrições de campos

Caminho: Janelas > Utilitários > Perfil de acesso > Autorização de Perfil > Restrições de campos

Desabilita ou oculta campos em transações de cadastro.

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Propriedade** | Propriedade que será utilizada na expressão de filtro de registros. Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
|---|---|
| **Ação** | Ação aplicada na restrição de visualização de campo Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna ACTION da tabela [FIELD_REST](dados_field_rest). |
