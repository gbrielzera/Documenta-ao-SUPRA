# ClasseCopia

Caminho: Customização > Modelo de objetos > Ativos > ClasseCopia

Tipos de Itens de Configuração que podem ser utilizadas como redundâncias.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **ClasseConfiguracaoId** | Número sequencial gerado automaticamente pelo sistema para Identificar um Tipo de Item de Configuração | Inteiro |
| **ClasseCopiaId** | Identificador do Tipo de Item de Configuração que é utilizada como Cópia | Inteiro |
| **Copia** | Um Tipo de Item de Configuração é utilizado para classificar Itens de Configuração, que são ativos sujeitos a alteração (como entrada ou saída) em processos de negócio. | [ClasseConfiguracao](objetos_classeconfiguracao) |
