# RiscoGap

Caminho: Customização > Modelo de objetos > Processo > RiscoGap

Riscos adicionais do Gap

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **GapOcorrenciaId** | Número sequencial gerado automaticamente pelo sistema para Identificar um Ocorrência | Inteiro |
| **GapSequencial** | Número sequencia utilizado para identificar um Gap dentro de uma Ordem de Serviço de teste de Controle. | Inteiro |
| **Risco** | Risco no Processo | [RiscoProcesso](objetos_riscoprocesso) |
| **RiscoProcessoRiscoId** | Identificador do RiscoProcesso associado | Inteiro |
| **RiscoProcessoSubProcessoId** | Identificador do RiscoProcesso associado | Inteiro |
