# Email do Sistema

Caminho: Guia para Administradores > Configurações do Sistema > Configuração de Email > Email do Sistema

O Supravizio possui um usuário denominado "Sistema". Este usuário deve possuir uma conta de email cadastrada para que o sistema envie e receba os comunicados.

Esse email é importante pois, para uma Ordem de Serviço que possui ANS, quando é realizado o envio de um comunicado é iniciada uma interrupção. No momento que o Cliente da Ordem de Serviço responde o comunicado, e o email do Sistema está como um remetente, a interrupção irá parar.

A configuração do email do Sistema está disponível apenas no Supravizio Web. Para a tal configuração, devemos acessar no Menu Principal | Utilitários | Configurações, na aba "Utilitários" em "Geral" temos o campo "Conta de Email do Sistema":
