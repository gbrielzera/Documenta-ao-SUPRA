# Portal de Processos

Caminho: Guia para Administradores > Portal de Processos

O Portal de Processos é uma aplicação que permite a realização de diversos serviços dentro de uma única página. Ele tem como alvo a usuários que possuem um perfil de solicitante, que necessitam realizar aprovações e fazer o acompanhamento da execução do seu processo.

Por ser uma aplicação Web, tem vantagens como poder ser acessado de qualquer local, inclusive através de dispositivos móveis e não necessitar instalação na máquina do cliente, apenas um navegador compatível.

O Portal possui uma estrutura modular, que permite ao administrador do sistema compor as páginas conforme sua necessidade.

## Interfaces disponíveis para visualização

### Clássico

Interface destinada a equipamentos como desktops e notebooks. Pode ser acessada de qualquer navegador compatível independente do Sistema Operacional.

Modo Clássico

### Tablet

Interface destinada a tablets com Sistemas Operacionais Android e iOS.

Modo Tablet

### Mobile

Interface destinada a dispositivos móveis como celulares e smartphones. Atualmente, estão homologados navegadores nativos dos sistemas Android (versão 1.6 ou superior), Blackberry (versão 6 ou superior) e iOS.

Modo Mobile
