# ApropriacaoAprovacao

Caminho: Customização > Modelo de objetos > Processo > ApropriacaoAprovacao

Apropriação em uma Aprovação

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **Apropriacao** | Apropriação da Aprovação | [Apropriacao](objetos_apropriacao) |
| **ApropriacaoId** | Identificador do Apropriacao associado | Inteiro |
| **AssuntoAprovacaoId** | Número sequencial gerado automaticamente pelo sistema para Identificar um AssuntoAprovacao | Inteiro |
| **Versao** | Sequencial gerado automaticamente pelo sistema para cada Assunto de uma determinada Ordem de Serviço | Inteiro |
