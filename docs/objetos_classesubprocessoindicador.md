# ClasseSubProcessoIndicador

Caminho: Customização > Modelo de objetos > Processo > ClasseSubProcessoIndicador

Tipos de Subprocessos que serão utilizados como filtro das ocorrências utilizados no cálculo do indicador

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **ClasseSubProcesso** | Um Tipo de Subprocesso mantém características de um fluxo que são invariáveis entre suas diversas versões. | [ClasseSubProcesso](objetos_classesubprocesso) |
| **ClasseSubProcessoId** | Identificador do Tipo de Subprocesso associado | Inteiro |
| **IndicadorId** | Número sequencial gerado automaticamente pelo sistema para Identificar um Indicador | Inteiro |
