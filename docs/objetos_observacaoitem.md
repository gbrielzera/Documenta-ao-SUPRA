# ObservacaoItem

Caminho: Customização > Modelo de objetos > Ativos > ObservacaoItem

Observações a respeito do Item de Configuração

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **Comentario** | Comentário fornecido por Solucionador ou Gestor | String |
| **DataHoraComentario** | Data/hora comentário | Data/hora |
| **ItemConfiguracaoId** | Número sequencial gerado automaticamente para Identificar um Item de Configuração | Inteiro |
| **Pessoa** | Autor do comentário | [Pessoa](objetos_pessoa) |
| **PessoaId** | Identificador do Solucionador autor do comentário. | Inteiro |
