# Visualização em tela cheia

Caminho: Guia para Solucionadores > Workspace  > Workspace Dashboard > Visualização em tela cheia

Para melhorar a exibição dos painéis, é possível realizar a visualização destes em tela cheia.

Ao lado esquerdo, abaixo da listagem de dashboards, haverá o ícone que permite a alteração no modo de visualização:

Localização do ícone

Clicando neste ícone, será aberta uma nova aba contendo apenas o conteúdo do painel.
