# Propriedade ClassId

Caminho: Propriedade ClassId

Identificador do(a) Class associado(a)

**Exemplo 1: modificação da propriedade ClassId**

```
# carrega objeto MemoriaCalculoApurada de identificador 1
memoriaCalculoApurada = MemoriaCalculoApurada.Carrega(1)
# modifica a propriedade ClassId
memoriaCalculoApurada.ClassId = 1;
# salva modificação da propriedade ClassId
MemoriaCalculoApurada.Salva(memoriaCalculoApurada)
```
