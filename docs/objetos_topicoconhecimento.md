# TopicoConhecimento

Caminho: Customização > Modelo de objetos > Ativos > TopicoConhecimento

Tópico que deve ser preenchido na elaboração de um artigo da base de conhecimento. Quando um artigo é criado todos os tópicos são preenchidos conforme o template definido por este registro.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **ClasseConfiguracaoId** | Identificador do Tipo de Item de Configuração proprietária do template de tópico para artigos da base de conheicmento | Inteiro |
| **Id** | Número sequencial gerado automaticamente pelo sistema para Identificar um TopicoConhecimento | Inteiro |
| **Sequencia** | Sequencial utilizado para ordenar (ordenação ascendente) tópicos de um determinado artigo. | Inteiro |
| **SubTitulo** | Sub-título do tópico | String |
