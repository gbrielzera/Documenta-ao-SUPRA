# Cadastro de Tipos de Arquivos

Caminho: Guia para Administradores > Roteiro de implantação > Realizando cadastros > Telas de Listagem > Telas de cadastros > Gerenciador de Arquivos Anexos em Registros > Cadastro de Tipos de Arquivos

Antes de anexar um arquivo para um determinado cadastro utilizando o **Gerenciador de Arquivos**, é necessário cadastrar o **Tipo de Arquivo**. Os tipos de arquivos cadastrados são exibidos na tela de **Adicionar Arquivos**:

Tipos de Arquivos cadastrados

Para cadastrar Tipos de Arquivos, siga o passo a passo abaixo:

1. Para acessar a tela de cadastro de Tipos de Arquivos, onde são cadastrados os Tipos de Arquivos que estão disponíveis na tela acima, acesse no menu Utilitários | Tipos de Arquivos conforme figura abaixo:

**Acessando a lista de Tipos de Arquivos**

A lista de **Tipos de Arquivos** existentes será exibida:

**Lista de Tipos de Arquivos**

2. Para criar um novo Tipo de Arquivo, selecione o botão Novo. Será exibida a tela abaixo:

**Cadastro de Tipo de Arquivo**

3. Para cadastrar preencha a descrição para o tipo de arquivo.

**Importante**: Caso seja marcado o campo de Comentário Obrigatório o comentário será requerido quando o usuário anexar um arquivo.

A opção de Arquivo público permite que qualquer usuário com ou sem permissão na transação acesse o arquivo, caso seja desmarcado somente o usuário que tem permissão para acessar a transação poderá ter acesso ao arquivo.

Após descrever o Tipo de Arquivo e marcar as opções desejadas clique em Salvar e voltar.
