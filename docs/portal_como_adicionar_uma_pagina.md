# Incluindo uma página

Caminho: Guia para Administradores > Portal de Processos > Primeiro acesso ao Portal > Configurando o Portal > Incluindo uma página

Assim como qualquer site da Web, o Portal pode possuir várias páginas. Neste tutorial, vamos realizar a criação de uma página no Modo Clássico.

Para os outros modos, o processo de criação é semelhante, seguindo os mesmos passos citados.

## Criando uma nova Página
