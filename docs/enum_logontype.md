# LogonType

Caminho: Customização > Modelo de objetos > Utilitários > Enumerações > LogonType

Tipo de logon realizado

| **Valor** | **Descrição** |
|---|---|
| **System** | Logon realizado por sistema para tarefas de manutenção ou processamento de jobs |
| **User** | Logon realizado por usuário |
