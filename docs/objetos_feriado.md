# Feriado

Caminho: Customização > Modelo de objetos > Recurso > Feriado

Um Feriado constitui uma data especial onde considerada, a princípio, dia não-útil.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **CalendarioId** | Identificador do Calendário | Inteiro |
| **Data** | Dia, mês e ano do feriado | Data/hora |
| **Descricao** | Descrição detalhada do Feriado | String |
