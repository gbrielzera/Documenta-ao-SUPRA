# Workspace  > Workspace Base de Conhecimento

Caminho: Guia para Solucionadores > Workspace  > Workspace Base de Conhecimento

Podemos definir uma Base de Conhecimento como uma biblioteca de soluções de problemas, ou seja, um repositório contendo os problemas e dúvidas apresentados pelos usuários, bem como as soluções anteriormente utilizadas.

Em ambientes que utilizam uma Base de Conhecimento, a busca por soluções é mais ágil e os conhecimentos adquiridos são compartilhados para os demais membros.

Listamos abaixo os principais benefícios de uma Base de Conhecimento bem escrita e sempre alimentada:

- Agilidade na solução otimizando o fechamento dos chamados;
- O conhecimento permanece na empresa em caso de ausências de colaboradores;
- Facilidade de treinamento de novos colaboradores do setor;

Neste tópico apresentaremos a ferramenta de Base de Conhecimento do Supravizio. Esta ferramenta permite que o conhecimento seja registrado e compartilhado acelerando o atendimento das ocorrências e a produtividade dos colaboradores.
