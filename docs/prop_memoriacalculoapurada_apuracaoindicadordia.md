# Propriedade ApuracaoIndicadorDia

Caminho: Propriedade ApuracaoIndicadorDia

Dia referência da apuração

**Exemplo 1: modificação da propriedade ApuracaoIndicadorDia**

```
# carrega objeto MemoriaCalculoApurada de identificador 1
memoriaCalculoApurada = MemoriaCalculoApurada.Carrega(1)
# modifica a propriedade ApuracaoIndicadorDia
memoriaCalculoApurada.ApuracaoIndicadorDia = 1;
# salva modificação da propriedade ApuracaoIndicadorDia
MemoriaCalculoApurada.Salva(memoriaCalculoApurada)
```
