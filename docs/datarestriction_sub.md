# Restrições de registros

Caminho: Janelas > Utilitários > Perfil de acesso > Autorização de Perfil > Restrições de registros

Filtra registros para edição em transações de cadastro.

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Propriedade** | Propriedade utilizada na expressão de filtro de registros Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
|---|---|
| **Operador** | Operador utilizado para montar a expressão utilizada como critério de filtro Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna OPERATOR da tabela [DATA_REST](dados_data_rest). |
| **Fórmula** | Fórmula que será computada para formar expressão de filtro. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna VALUE_FORMULA da tabela [DATA_REST](dados_data_rest). |
