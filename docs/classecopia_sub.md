# Tipo redundância

Caminho: Janelas > Ativos > Tipo Item Configuração > Tipo redundância

Tipos de Itens de Configuração que podem ser utilizadas como redundâncias.

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Classe Cópia** | Um Tipo de Item de Configuração é utilizado para classificar Itens de Configuração, que são ativos sujeitos a alteração (como entrada ou saída) em processos de negócio. Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
