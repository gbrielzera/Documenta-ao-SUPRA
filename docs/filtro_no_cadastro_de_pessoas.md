# Filtro no Cadastro de Pessoas

Caminho: Guia para Administradores > Configurando Processos > Editor de Processos > Papéis e responsabilidades > Tipos de Papéis > Filtro no Cadastro de Pessoas

Você poderá também definir atores baseado nos campos do cadastro de Pessoas. É possível utilizarmos campos nativos do cadastro, como por exemplo, Cargo, Órgãos, por registro Ativo, por Tipo de Colaborador, dentre outros.

### Filtro no cadastro de pessoas

### Podemos filtrar pessoas também através de [campos customizados](campos_customizados) definidos para esta classe. Conforme observado no exemplo acima, é possível filtrar utilizando os campos Nível, Conhecimentos e Projeto atual.
