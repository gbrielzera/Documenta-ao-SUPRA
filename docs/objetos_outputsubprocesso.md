# OutputSubProcesso

Caminho: Customização > Modelo de objetos > Processo > OutputSubProcesso

Parâmetros de Saída de Subprocesso

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **CustomProperty** | Propriedade criada por customização do Software. Se preenchida anula o campo Propriedade | [CustomProperty](objetos_customproperty) |
| **CustomPropertyId** | Identificador do(a) CustomProperty associado(a) | Inteiro |
| **Id** | Número sequencial gerado automaticamente pelo sistema para Identificar um OutputSubProcesso | Inteiro |
| **Property** | Propriedade da Ocorrência. Se prenchida anula Propriedade Customizada | [Property](objetos_property) |
| **PropertyId** | Identificador do(a) Property associado(a) | Inteiro |
| **SubProcessoId** | Identificador do Subprocesso proprietário do Output | Inteiro |
