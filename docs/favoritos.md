# Acesso rápido utilizando Favoritos

Caminho: Guia para Solucionadores > Workspace  > Workspace Ordens de Serviço > Acesso rápido utilizando Favoritos

O recurso Favoritos permite facilitar o acesso às últimas Ordens de Serviço acessadas pelo usuário.

Para utilizar este acesso rápido, há o botão Favoritos dentre os existentes na barra de comandos do [Workspace Ordens de Serviço](workspace_ordemservico), que acumula as Ordens de Serviço que foram acessado por último pela Solucionador logado no Workspace.
