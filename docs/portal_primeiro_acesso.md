# Primeiro acesso ao Portal

Caminho: Guia para Administradores > Portal de Processos > Primeiro acesso ao Portal

O Portal é uma aplicação amplamente customizável, sendo que é o próprio cliente quem constrói sua estrutura.

Ao acessá-lo pela primeira vez, pode-se estranhar ao visualizar uma página sem conteúdo. Porém, basta adicionarmos módulos dentro desta página para que possamos descobrir suas funcionalidades.
