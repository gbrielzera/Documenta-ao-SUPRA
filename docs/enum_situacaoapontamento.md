# SituacaoApontamento

Caminho: Customização > Modelo de objetos > Processo > Enumerações > SituacaoApontamento

Situação de Apontamento

| **Valor** | **Descrição** |
|---|---|
| **Cancelado** | Apontamento Cancelado. Apontamentos Cancelados NÃO são visíveis em scripts. |
| **Confirmado** | Apontamento Confirmado pelo usuário. Somente Apontamentos Confirmados são visíveis em scripts |
