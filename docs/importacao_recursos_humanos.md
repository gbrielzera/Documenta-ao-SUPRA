# Rotina de Importação de Dados de Recursos Humanos

Caminho: Guia para Administradores > Roteiro de implantação > Importando Dados > Rotina de Importação de Dados de Recursos Humanos

O Supravizio também possibilita a importação de cadastros de Recursos Humanos (Pessoas, Empresas, Áreas, etc) a partir de fontes de dados externas que podem ser tabelas ou views de banco de dados.

Apresentaremos nos próximos tópicos o como cadastrar ou remover uma rotina de Importação de dados Recursos Humanos, Layouts para Fonte de Dados e o detalhamento de cada etapa para a Importação de dados de Recursos Humanos.
