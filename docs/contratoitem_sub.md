# Contratação de Item de Configuração

Caminho: Janelas > Recurso > Contrato > Contratação de Item de Configuração

Relaciona Itens de Configuração com o Contrato e define valor mensal para manutenção.

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Item de Configuração** | Item de Configuração mantido pelo Contrato Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
|---|---|
| **Valor mensal** | Valor mensal para manutenção do Item de Configuração Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna VALOR_MENSAL da tabela [CONTRATO_ITEM](dados_contrato_item). |
