# ChangeItem

Caminho: Customização > Modelo de objetos > Utilitários > ChangeItem

Modificação de Propriedades

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **ChangeLogId** | Identificador da Modificação | Decimal |
| **IsCustom** | Indica que corresponde a uma propriedade customizada pelo Usuário. | Booleano |
| **NewLargePropertyValue** | Novo valor em formato longo | String |
| **NewPropertyValue** | Novo valor da Propriedade | String |
| **OldLargePropertyValue** | Valor antigo em formato longo | String |
| **OldPropertyValue** | Valor anterior da Propriedade | String |
| **PropertyName** | Nome da Propriedade modificada | String |
