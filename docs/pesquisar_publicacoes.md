# Pesquisar Publicações

Caminho: Guia para Solucionadores > Workspace  > Workspace Base de Conhecimento > Pesquisar Publicações

## Tela de Base de Conhecimento no Workspace

Em determinados momentos, para a resolução ou conhecimento do problema enfrentado é necessário saber qual a produção técnica já foi desenvolvida para a necessidade do usuário.

**Consulta de Conhecimento**

Na nova janela encontramos três campos que utilizamos para realizar pesquisa:

- **Palavras Chaves:** Realiza busca pelos campos Palavras Chaves da base de conhecimento e/ou os campos Assunto, Descrição detalhada e Sintoma analisado de Ordens de Serviço cuja Tipo de Subprocesso este configurada para servir de fonte de base de conhecimento;
- **Serviço:** O serviço associado à necessidade do usuário;
- **Incluir Base de Conhecimento/Incluir Ordens de Serviço:** A pesquisa pelo conhecimento pode retornar informações destas duas bases de informações.

Ao realizar uma busca, são apresentados os resultados e o devido Grau de Relevância do artigo com o termo procurado.

Na tabela acima temos as seguintes colunas:

**Descritivo**: Descritivo do conhecimento;

**Tipo**: Tipo de conhecimento, pode ser um Problema Conhecido, Tutorial, Subprocesso etc. Depende da base de dados;

**Origem**: Indica se o conhecimento vem de uma Ordem de Serviço ou de um Conhecimento;

Relevância: Grau de relevância do artigo em relação aos termos inseridos.

Caso a lista seja longa, pode-se utilizar Ordenação por Colunas, conforme a imagem abaixo.

**Filtro na coluna Tipo**

Encontrado um possível artigo ou uma Ordem de Serviço, basta clicar sobre o Descritivo ou dar um duplo clique sobre o mesmo.

**Visualizado de Artigos**

O usuário pode salvar este arquivo ou imprimir.

Caso seja escolhido um conhecimento proveniente de uma Ordem de Serviço, será aberto a tela de edição de Ordem de Serviço, na qual o usuário pode consultar o ocorrido naquele atendimento.

**Edição Ordem Serviço**

## Conhecimento na tela de Edição de Ordem de Serviço

Assim como podemos criar um conhecimento durante a execução de uma Ordem de Serviço, o usuário também pode consultar artigos da Base de Conhecimento e anexar estes artigos na Ordem de Serviço.

Para isso na tela de edição de Ordem de serviço clique em **Conhecimento** conforme imagem abaixo.

**Acesso a pesquisa de conhecimento**

Ao visualizar a tela de Edição de uma determinada Ordem de Serviço, o botão **Conhecimento** pode aparecer piscando na cor verde. Quando isto acontece significa que foi realizada uma busca automática através dos termos que foram preenchidos nos campos **Assunto, Descrição Detalhada **e** Sintoma Analisado **da Ordem de Serviço e comparados com o campo[ Palavras chaves](cadastros_base_conhecimento) dos artigos da base de conhecimento. **Importante: Ordens de Serviço não são consideradas na recuperação automática.**.

Ao clicarmos em **Conhecimento** podemos observar que os campos **Assunto, Descrição Detalhada **e** Sintoma Analisado **ficam disponíveis como critério de busca na tela de Procura em Base do Conhecimento.

Podemos também adicionar novas palavras e selecionar serviços na tela de Procura em Base do Conhecimento:

**Painel de Pesquisa**

Com um artigo aberto, podemos utilizar o artigo anexando na Ordem de Serviço.

**Opções para o Artigo**

Caso o artigo seja utilizado, ele é anexado na Ordem de Serviço e ficará disponível junto a exibição de Ativos.
