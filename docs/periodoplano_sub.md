# Período de Plano de Gestão

Caminho: Janelas > Processo > Plano Gestão > Indicador de Plano de Gestão > Período de Plano de Gestão

Período de Plano de Gestão

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Mês** | Mês Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório - O campo 'Mês' deve ser maior ou igual a 1 - O campo 'Mês' deve ser menor ou igual a 12 Este campo é mantido na coluna MES da tabela [PERIODO_PLANO](dados_periodo_plano). |
|---|---|
| **Ano** | Ano Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna ANO da tabela [PERIODO_PLANO](dados_periodo_plano). |
| **Meta** | Meta estabelecida para o Indicador no mês e ano do período. Pode ser atualizado automaticamente quando for modificada a Meta geral do Indicador (atualizado somente se a Meta do período for igual a Meta anterior do Indicador). Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna META da tabela [PERIODO_PLANO](dados_periodo_plano). |
| **Desafio** | Valor acima da meta definido desafio no plano de metas da gestão. No painel de Indicadores do Executive Dashboard períodos que atingirem este valor são exibidos na cor azul. Assim como no campo Metas o Desafio pode ser redefinido nos diversos períodos do Plano de Gestão. |
| **Valor apurado** | Valor apurado para Indicadores de Desempenho cujo provedor de dados for igual a Lançamento Manual. |

| **Geral** | Anotação geral sobre dados apurados para o Indicador no Período. |
|---|---|
| **Causa** | Anotação sobre causa |
| **Providência** | Providência tomada sobre apuração do Indicador no Período |
| **Perspectiva** | Perspectiva observada para valor apurado do Indicador no Período |
