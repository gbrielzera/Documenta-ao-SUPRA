# Tutorial 12: Abertura de Ordem de Serviço por email

Caminho: Guia para Administradores > Configurando Processos > Tutoriais > Tutorial 12: Abertura de Ordem de Serviço por email

A abertura de Ordem de Serviço por email é importante para facilitar a integração do Supravizio com usuários que utilizam email.

O objetivo deste tópico é de demonstrar como que é realizada a abertura de Ordem de Serviço via email.
