# ParentClassId

Caminho: Customização > Modelo de objetos > Utilitários > Class > ParentClassId

Identificador da Classe Pai

**Exemplo 1: modificação da propriedade ParentClassId**

```
# carrega objeto Class de identificador 1
class = Class.Carrega(1)
# modifica a propriedade ParentClassId
class.ParentClassId = 1;
# salva modificação da propriedade ParentClassId
Class.Salva(class)
```
