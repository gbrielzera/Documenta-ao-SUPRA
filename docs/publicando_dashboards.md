# Publicando Dashboards

Caminho: Guia para Administradores > Editor de Dashboard > Publicando Dashboards

Criado um Dashboard, temos a opção **Publicar Dashboard **para publicar um painel no Supravizio Web, conforme indicado na ilustração abaixo:

Localização do botão

Será aberta uma nova janela para seleção dos Grupos de Trabalho os quais se deseja realizar a publicação.

Tela de seleção de Grupos de Trabalho

Após selecionar o Grupo de Trabalho, clique em **Adicionar **para adicioná-lo na lista, que se encontra abaixo da parte de seleção.

Inseridos os grupos desejados, clique em **Confirmar** para salvar as alterações.

Ao abrir o Supravizio Web, com um usuário de um **Grupo de Trabalho** presente na lista anterior e clicar para abertura da tela de **Dashboard**, o item publicado estará disponível para visualização.
