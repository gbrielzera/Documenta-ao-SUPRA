# GrupoQuestaoIndicador

Caminho: Customização > Modelo de objetos > Processo > GrupoQuestaoIndicador

Grupos de Questões para Filtro durante a Apuração de Pesquisas de Satisfação.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **GrupoQuestao** | Recupera apenas respostas de um determinado grupo. | [GrupoQuestao](objetos_grupoquestao) |
| **GrupoQuestaoId** | Identificador do GrupoQuestao associado | Inteiro |
| **IndicadorId** | Número sequencial gerado automaticamente pelo sistema para Identificar um Indicador | Inteiro |
| **QuestaoPesquisa** | Questão para filtro | [QuestaoPesquisa](objetos_questaopesquisa) |
| **QuestaoPesquisaId** | Identificador da QuestaoPesquisa associada | Inteiro |
