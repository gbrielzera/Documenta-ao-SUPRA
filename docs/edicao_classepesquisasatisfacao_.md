# Modificar Classe Pesquisa Satisfação

Caminho: Modificar Classe Pesquisa Satisfação

Para modificar um(a) Classe Pesquisa Satisfação acesse a transação **Classes de Pesquisa de Satisfação** preenchendo o código **PR27** no campo de localização de transações (veja campo em destaque na figura abaixo). Em seguida ao preenchimento do código tecle ENTER ou clique no botão

Ao executar o comando acima é exibida uma tela contendo a listagem de registros disponíveis para edição conforme a figura abaixo:

Para realizar uma modificação basta selecionar o registro desejado e clicar em . Em seguida é exibida uma nova tela onde é possível modificar campos de Classe Pesquisa Satisfação. Veja a figura abaixo:

Para mais detalhes no preenchimento dos campos apresentados na figura acima veja [Classe Pesquisa Satisfação.](classepesquisasatisfacao_sub)

Após modificar os campos desejados clique em Salvar para gravar as modificações em banco de dados. Se a gravação ocorrer com sucesso será exibida uma mensagem na barra de informações da janela principal.
