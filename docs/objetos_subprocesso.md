# SubProcesso

Caminho: Customização > Modelo de objetos > Processo > SubProcesso

Subprocesso

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **Atividades** | Uma Atividade de Processo corresponde a Tarefas, Subprocessos e Eventos de Processos. | [Lista de Atividade](objetos_atividade) |
| **ClasseSubProcesso** | Tipo de Subprocesso da Ocorrência, que define o fluxo de atividades de decisões do processo. | [ClasseSubProcesso](objetos_classesubprocesso) |
| **ClasseSubProcessoId** | Identificador do Tipo de Subprocesso associado | Inteiro |
| **Controles** | Controles utilizados para mitigar os Riscos de um Subprocesso. | [Lista de Controle](objetos_controle) |
| **DesenhoProcessoId** | Número sequencial gerado automaticamente pelo sistema para Identificar um DesenhoProcesso | Inteiro |
| **Gateways** | Representa uma Decisão ou Merge a ser tomado durante a execução do Processo | [Lista de Gateway](objetos_gateway) |
| **Id** | Identificador do Tipo de Subprocesso | Inteiro |
| **Outputs** | Parâmetros de Saída de Subprocesso | [Lista de OutputSubProcesso](objetos_outputsubprocesso) |
| **Riscos** | Riscos endereçados no Subprocesso. Estes riscos devem ser tratados pelo fluxo e são validados com controles estabelecidos. | [Lista de RiscoProcesso](objetos_riscoprocesso) |
