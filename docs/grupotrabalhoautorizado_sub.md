# Grupo de Trabalho Autorizado

Caminho: Janelas > Processo > Plano Gestão > Grupo de Trabalho Autorizado

Grupos de Trabalho que estão autorizados a visualizar o resultado da apuração de indicadores.

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Grupo de Trabalho** | Grupo Trabalho Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
|---|---|
| **Inclui Sub-niveis** | Permite que sub-grupos acessem o Plano de Gestão. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna INCLUI_SUB_NIVEIS da tabela [GRUPO_TRABALHO_AUTORIZADO](dados_grupo_trabalho_autorizado_). |
