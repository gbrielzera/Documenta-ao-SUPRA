# Configurando o Módulo

Caminho: Guia para Administradores > Portal de Processos > Módulos > Módulo de Abertura > Configurando o Módulo

Neste tópico, serão apresentados os parâmetros que podem ser configurados para este módulo.

### Aba Mensagem de Abertura

Iniciaremos tratando sobre a aba Mensagem de Abertura, por ser genérica aos tópicos subsequentes.

Aba Mensagem de Abertura

Nesta aba, é possível definir a mensagem a ser exibida para confirmação de abertura da Ordem de Serviço. No local indicado na imagem acima, é possível inserir campos dinâmicos, como o número da Ordem de Serviço, nome do usuário conectado ou um link para acompanhar seu andamento.

Aba Geral

Neste módulo podemos realizar a configuração para o formato de abertura da Ordem de Serviço, através da seleção do campo Tipo de Abertura.

Aba Geral

A abertura poderá ser realizada das seguintes maneiras:

- Abertura por Assistente
- Abertura por Formulário Direto

### Aba Imagens

Nesta aba, é possível customizar as imagens exibidas no módulo, como os botões **Início** e **Concluir Abertura**.

Aba Imagens

Nos campos disponíveis para preenchimento, deve-se inserir os respectivos endereços das imagens, lembrando que estes caminhos deverão estar acessíveis às estações que acessarão a página do Portal de Processos.

Ao lado dos títulos, há o tamanho especificado (em pixels) da figura. Caso esta seja de um tamanho diferente, esta será redimensionada para o padrão informado.
