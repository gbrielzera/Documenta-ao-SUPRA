# Criando Apontamentos

Caminho: Guia para Solucionadores > Workspace  > Workspace Ordens de Serviço > Apontamentos > Criando Apontamentos

É possível criar apontamentos a partir da tela de Edição de Ordens de Serviço.

Para criar este Apontamento o Solucionador poderá selecionar o horário desejado na listagem de apontamentos e clicar com o botão direito do mouse selecionando as opções **Novo** ou **Novo – a partir do anterior**:

**Novo apontamento**

**Novo:** se o apontamento for por período, ao clicar nesta opção, será exibida uma tela de edição com os horários de início e fim já preenchidos obedecendo a seleção do usuário:

**Novo apontamento em edição**

**Novo - A partir do anterior:** neste caso a hora inicial do novo apontamento é preenchida com a hora final do apontamento anterior à seleção. Caso não existam apontamentos para o dia selecionado, é admitido o início do dia como hora inicial do novo apontamento. Esta é uma opção que facilita no preenchimento de novos apontamentos, para casos de trabalhos com apontamentos sempre sequenciais:

**Novo apontamento a partir do anterior**

Na tela **Novo apontamento **está disponível a opção de **Ordem de Serviço, Atividade e Tipo.**

Através da opção **Ordem de Serviço** da tela de **Novo apontamento** é possível selecionar as Ordens de Serviços disponíveis para o Solucionador apontar as horas trabalhadas:

Através da opção Atividade exibida na tela **Novo apontamento** é possível selecionar uma [Atividade do Processo](toolbox) da Ordem de Serviço em questão para realizar o Apontamento.

Para entender a opção **Tipo**, disponível na tela **Novo apontamento **clique no link [Cadastro de Tipo de Apontamento](tipos_de_apontamento).

É possível visualizar em relatório com os Apontamentos realizados. Para aprender a visualizar um relatório de Apontamentos clique no link [Relatório de Apontamentos](relatorios_apontamentos).
