# ClasseSubProcesso

Caminho: Customização > Modelo de objetos > Recurso > AplicacaoProcesso > ClasseSubProcesso

Um Tipo de Subprocesso mantém atributos de um fluxo de processo que são invariáveis em suas diversas versões. Tipos de Subprocessos podem definir rotinas internas para a área ou solicitações disponíveis para os Clientes. Também podem representar Subprocessos de rotinas de grande complexidade.
