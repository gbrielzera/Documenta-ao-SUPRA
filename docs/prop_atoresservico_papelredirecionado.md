# PapelRedirecionado

Caminho: Customização > Modelo de objetos > Processo > AtoresServico > PapelRedirecionado

Papel de Classe de Negócio utilizado como redirecionamento no instante de cálculo de Atores. Se este campo for preenchido o sistema automaticamente limpa o conteúdo do campo 'Pessoa'. Somente um destes campos pode ser preenchido. IMPORTANTE: Este recurso demanda cuidado especial com a criação de redefinições recursivas de Papeis.
