# Reenvio de Mensagem

Caminho: Guia para Solucionadores > Workspace  > Workspace Ordens de Serviço > Comunicados em Ordens de Serviço > Reenvio de Mensagem

Para a versão Web do Supravizio, é possível ser feito o reenvio de mensagens, acessando o menu **Utilitários | Mensagens.**

**Reenvio de Mensagem**

Nesta tela, pode-se selecionar a mensagem que deseja enviar novamente logo em seguida clicar no botão **Enviar Novamente**, para que a mensagem seja reenviada para o mesmo remetente.
