# Apontamentos

Caminho: Guia para Solucionadores > Workspace  > Workspace Ordens de Serviço > Apontamentos

Acompanhar o tempo dos colaboradores nunca foi tão simples. O Supravizio conta com uma poderosa ferramenta gráfica de apontamentos de horas que permite de apontar e consultar as horas trabalhadas. Neste tópico ensinaremos como utilizar esta ferramenta.
