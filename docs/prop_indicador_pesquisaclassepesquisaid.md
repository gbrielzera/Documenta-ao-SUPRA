# PesquisaClassePesquisaId

Caminho: Customização > Modelo de objetos > Processo > Indicador > PesquisaClassePesquisaId

Identificador do ClassePesquisaSatisfacao associado

**Exemplo 1: modificação da propriedade PesquisaClassePesquisaId**

```
# carrega objeto Indicador de identificador 1
indicador = Indicador.Carrega(1)
# modifica a propriedade PesquisaClassePesquisaId
indicador.PesquisaClassePesquisaId = 1;
# salva modificação da propriedade PesquisaClassePesquisaId
Indicador.Salva(indicador)
```
