# TipoPapel

Caminho: Customização > Modelo de objetos > Processo > Enumerações > TipoPapel

Forma de recuperação de pessoas utilizada no cálculo do papel de processo

| **Valor** | **Descrição** |
|---|---|
| **RelacaoPessoas** | O papel é definido por uma relação de pessoas |
| **RelacaoOrgaos** | Permite recuperar pessoas a partir de Órgãos da Empresa |
| **RelacaoGrupos** | Permite recuperar solucionadores a partir de Grupos de Trabalho |
| **Script** | Permite customizar a recuperação de pessoas via script |
| **Filtro** | Permite filtrar pessoas do cadastro de Pessoas |
| **PessoaOrdemServico** | Permite a recuperação de pessoas relacionadas com uma Ordem de Serviço (a própria ocorrência, o Serviço ou Tipo de Subprocesso) |
| **Composto** | O papel será composto pela união de outros papéis |
| **ItemConfiguracao** | Recupera pessoas responsáveis ou usuárias por itens anexados na ocorrência de processo. |
| **ExecucaoAtividade** | Solucionador envolvido em alguma atividade do processo |
