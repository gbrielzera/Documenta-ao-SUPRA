| **Código** | Código Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório - Todos os caracteres preenchidos são convertidos automaticamente para minúsculo - Não é permitida duplicidade de valores |

| **Fonte** | Fonte Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
