Uma característica muito importante do novo fluxo pode ser observada quando tentamos acessar o subprocesso utilizando o botão **Nova** da tela Workspace. Como pode ser visto na figura abaixo o novo fluxo não está disponível para criação pois não possui um iniciador manual.

Criação de novas Ordens de Serviço do processo Administrativo

No caso de iniciadores por timer as Ordens de Serviço são necessariamente criadas de forma automática por um componente do software denominado **Máquina de Processos**. Para acessarmos este componente utilize as opções de menu **Utilitários | Gerenciamento de Ambiente**.
