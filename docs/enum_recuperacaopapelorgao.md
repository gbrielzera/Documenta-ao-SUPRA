# RecuperacaoPapelOrgao

Caminho: Customização > Modelo de objetos > Processo > Enumerações > RecuperacaoPapelOrgao

Regra de recuperação de pessoas na definição de um papel por relação de órgãos

| **Valor** | **Descrição** |
|---|---|
| **Gestor** | Somente o gestor |
| **ColaboradoresExcetoGestor** | Recupera todos os colaboradores lotados no órgão exceto o próprio gestor |
| **Colaboradores** | Recupera todos os colaboradores lotados no órgão inclusive o próprio gestor |
