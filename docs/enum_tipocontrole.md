# TipoControle

Caminho: Customização > Modelo de objetos > Processo > Enumerações > TipoControle

Tipo de Controle

| **Valor** | **Descrição** |
|---|---|
| **Preventivo** | São os controles utilizados para prevenir a ocorrência de erros ou falhas de processo |
| **Detectivos** | São os controles utilizados para detectar possíveis falhas que podem ter ocorrido após a operação |
