# Módulo de Mural de Avisos

Caminho: Guia para Administradores > Portal de Processos > Módulos > Módulo de Mural de Avisos

O módulo de Mural de Avisos permite a visualização de avisos publicados por solucionadores no Supravizio Web.

Disponível no modo: Clássico

Este módulo apresentará as mensagens todos os avisos que tiverem sido publicados e que tenham visibilidade no Portal habilitada:
