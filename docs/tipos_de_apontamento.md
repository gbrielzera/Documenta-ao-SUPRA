# Cadastrar Tipos de Apontamento

Caminho: Guia para Administradores > Roteiro de implantação > Realizando cadastros > Cadastros Adicionais > Cadastrar Tipos de Apontamento

O Supravizio também possibilita a criação de apontamentos de diferentes tipos. Um apontamento pode assumir um determinado valor dado o seu tipo de apontamento. Por exemplo, o solucionador pode criar um apontamento do tipo “Hora Trabalhada”, um apontamento do tipo “Treinamento”, um apontamento do tipo “Deslocamento”, etc. Para cada tipo de apontamento, pode haver um valor diferenciado, de acordo com o que é definido no [Contrato](contrato_sub) associado à Ordem de Serviço associada ao apontamento.

Tipos de apontamento em contrato

Para criar tipos de apontamento, selecione no menu principal as opções** [Recurso | Tipos de Apontamento](tipoapontamento_sub)**:

**Cadastrando um Tipo de Apontamento**

Após cadastrar os nomes dos tipos de apontamento adotados, o usuário deve incluí-los no [Contrato](contrato_sub) desejado. Para isso, selecione **Recurso | Contrato**, selecionando o [Contrato](contrato_sub) na listagem e clique na aba **Apontamentos**. Nesta aba é possível incluir os tipos de apontamentos desejados e cadastrar uma **Variação**. Esta Variação é um percentual do Valor/Hora contratado de um determinado Recurso Aplicado.

**Tipo de apontamento em um contrato**

Para cadastrar um **Recurso Aplicado**, clique na aba **Recursos Aplicados**, preencha a Descrição do Recurso, o Valor mensal, o Valor da hora, a Quantidade de horas contratadas por mês e a Validade do saldo restante do mês (em meses) que é a quantidade de meses para validade das horas que não forem utilizadas no mês apurado e se este último campo não for preenchido ou for preenchido com valor 0 significará que as horas devem ser consumidas no mesmo mês, se for uma quantidade de meses igual ou superior ao restante dos meses do contrato significará que as horas formarão um banco de horas:
