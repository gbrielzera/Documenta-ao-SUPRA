# AtorGrupoTrabalho

Caminho: Customização > Modelo de objetos > Processo > Enumerações > AtorGrupoTrabalho

Tipo de Ator em Grupo de Trabalho

| **Valor** | **Descrição** |
|---|---|
| **MembroMenorCarga** | Seleciona um Solucinador Membro do Grupo de Trabalho considerando o critério de menor quantidade de Itens abertos no momento. Somente Solucionadores ativos serão considerados na seleção. |
| **MembroFila** | Recupera um Solucionador Membro do Grupo de Trabalho considerando o critério de Fila de atendimento. Somente Solucionadores ativos serão considerados na seleção. |
| **TodosMembros** | São recuperadas todas as pessoas identificadas pela regra do papel |
| **Coordenador** | Coordenador |
