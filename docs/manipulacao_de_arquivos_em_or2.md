# Manipulação de Arquivos em Ordens de Serviço

Caminho: Guia para Administradores > Configurando Processos > Tutoriais > Tutorial 9: Manipulação de Arquivos Anexos > Manipulação de Arquivos em Ordens de Serviço

Com o Processo e o Tipo de Item de Configuração configurados, vamos entender como funciona o esquema de Compartilhamento de arquivos partindo do exemplo de seu uso.

### 1. Crie uma Ordem de Serviço a partir do Subprocesso Especificação de Necessidade

Abra o Workspace, no botão Nova selecione o Subprocesso **Especificar Necessidade** no Processo **Gerenciamento de Projetos**, conforme Figura abaixo.

### 3. Anexar um Arquivo

Quando clicamos no Link Anexar documento Especificação Tecnica, o sistema automaticamente carregou a tela Procura Artefato. Basta clicar no botão Procurar e na janela de busca de arquivos do Windows encontrar o arquivo.

Localizando um arquivo

Após localizar o arquivo e selecionar, basta clicar no botão OK para concluir o processo de busca.

Finalizando a busca por um arquivo

Até este ponto o comportamento é similar tanto para Transferência quanto para Compartilhamento, porem as particularidades entre as duas começam a ser notadas após o envio do arquivo.

Esquema de Compartilhamento de Arquivos

O arquivo é copiado diretamente para o servidor, para isso o servidor disponibiliza uma pasta na rede com permissão de acesso.

### 4. Alterar o Arquivo

Para alterar o conteúdo de um arquivo basta na Ordem de Serviço selecionar o arquivo, abrir o conteúdo do arquivo e editá-lo. Para enviar as modificações, clique no botão . Logo, será aberta uma nova caixa de seleção para enviar a nova versão do arquivo.
