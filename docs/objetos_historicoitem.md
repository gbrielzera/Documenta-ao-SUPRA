# HistoricoItem

Caminho: Customização > Modelo de objetos > Ativos > HistoricoItem

Histórico de alterações no arquivo anexo

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **Comentario** | Comentário feito pelo usuário responsável pela alteração | String |
| **DataAlteracao** | Data e hora de atualização do arquivo | Data/hora |
| **Id** | Número sequencial gerado automaticamente para Identificar um Item de Configuração | Inteiro |
| **ItemConfiguracaoId** | Número sequencial gerado automaticamente para Identificar um Item de Configuração | Inteiro |
| **Pessoa** | Pessoa que realizou a modificação no arquivo. | [Pessoa](objetos_pessoa) |
| **PessoaId** | Identificador do autor da mudança no documento | Inteiro |
