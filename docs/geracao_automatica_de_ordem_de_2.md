# Geração automática de Documentação de Processos

Caminho: Guia para Administradores > Configurando Processos > Editor de Processos > Geração automática de Documentação de Processos

No Supravizio, temos a funcionalidade de Geração automática de Documentação de Processos, que está disponível no **Editor de Processos**.

Para gerá-la, selecione o processo que deseja gerar a documentação e pressione o botão direito do mouse (ou clique no ícone, conforme apontado abaixo):

Tela do Process Explorer

Ao clicar, abrirá uma janela solicitando o local para o armazenamento do arquivo da documentação:

Seleção do local para armazenamento dos arquivos

Serão salvos um arquivo referente à documentação e uma pasta para o armazenamento de imagens.

Arquivos salvos pelo Supravizio

**Importante**: Caso o arquivo seja movido, sempre é necessário mover a pasta com as imagens para o mesmo local do arquivo principal.

O arquivo da documentação pode ser aberto com qualquer Navegador Web instalado em sua máquina.

Abrindo o arquivo, note que a descrição das configurações de preenchimento de campo, aprovação e anexo de arquivos são realizadas automaticamente:
