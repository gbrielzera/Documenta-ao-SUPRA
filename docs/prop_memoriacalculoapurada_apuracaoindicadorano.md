# Propriedade ApuracaoIndicadorAno

Caminho: Propriedade ApuracaoIndicadorAno

Ano referência da apuração

**Exemplo 1: modificação da propriedade ApuracaoIndicadorAno**

```
# carrega objeto MemoriaCalculoApurada de identificador 1
memoriaCalculoApurada = MemoriaCalculoApurada.Carrega(1)
# modifica a propriedade ApuracaoIndicadorAno
memoriaCalculoApurada.ApuracaoIndicadorAno = 1;
# salva modificação da propriedade ApuracaoIndicadorAno
MemoriaCalculoApurada.Salva(memoriaCalculoApurada)
```
