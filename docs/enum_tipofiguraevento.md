# TipoFiguraEvento

Caminho: Customização > Modelo de objetos > Processo > Enumerações > TipoFiguraEvento

Tipo de evento de figura

| **Valor** | **Descrição** |
|---|---|
| **Cancel** | Cancelamento |
| **Start** | Início |
| **StartRule** | Início por regra |
| **StartTimer** | Início por timer |
| **StartLink** | Início por link |
| **IntermediateRule** | Intermediário por regra |
| **IntermediateTimer** | Intermediário por Timer |
| **End** | Fim |
| **EndLink** | Link final |
| **IntermediateMessage** | Evento intermediário que dispara uma mensagem |
| **StartMessage** | Inicia um subprocesso pelo recebimento de email ou mensagem via webservice |
