# Composto por outros Papéis

Caminho: Guia para Administradores > Configurando Processos > Editor de Processos > Papéis e responsabilidades > Tipos de Papéis > Composto por outros Papéis

O tipo Composto por outros Papéis seleciona os atores a partir de uma lista de outros papéis. Para adicionar papéis na composição clique em Composição:
