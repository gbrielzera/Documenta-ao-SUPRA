# Edição da Janela de Propriedades

Caminho: Guia para Administradores > Configurando Processos > Editor de Processos > Toolbox e elementos do BPMN > Data Objects > Edição da Janela de Propriedades

Como foi possível perceber nos exemplos apresentados anteriormente sempre que selecionamentos um Data Object no diagrama a janela de propriedades é automaticamente atualizada com os atributos do item em questão. Desta forma podemos configurar o elemento de acordo com a nossa necessidade.
