# CustomPropertyType

Caminho: Customização > Modelo de objetos > Utilitários > Enumerações > CustomPropertyType

Tipo de Propriedade Customizada

| **Valor** | **Descrição** |
|---|---|
| **String** | Caracteres alfanuméricos |
| **Integer** | Números inteiros |
| **Decimal** | Números decimais ponto fixo |
| **Boolean** | Verdadeiro ou Falso |
| **DateTime** | Data e hora |
| **List** | Listagem de Objetos. Requer definição da Classe dos Objetos |
| **RecordList** | Lista de registros compostos por campos de diferentes tipos |
