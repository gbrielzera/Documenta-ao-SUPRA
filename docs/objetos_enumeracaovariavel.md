# EnumeracaoVariavel

Caminho: Customização > Modelo de objetos > Processo > EnumeracaoVariavel

Enumeração de valores para Variável. Quando não existir então o campo é numérico de livre digitação.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **Descricao** | Descritivo da opção | String |
| **MetodoPriorizacaoId** | Número sequencial gerado automaticamente pelo sistema para Identificar um Método de Priorização de Ocorrências. | Inteiro |
| **Nome** | Nome da Variável. Este nome pode ser referenciado pela Expressão que calcula o Grau de Prioridade. | String |
| **Sequencial** | Sequencia de apresentação da opção. | Inteiro |
| **Valor** | Valor para a opção | Inteiro |
