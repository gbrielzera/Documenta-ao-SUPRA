# Tutorial 14: Integração de Instalações Supravizio via WebService

Caminho: Guia para Administradores > Configurando Processos > Tutoriais > Tutorial 14: Integração de Instalações Supravizio via WebService

Este tutorial tem como objetivo demonstrar como pode ser feita a integração entre duas instâncias de Supravizio Server diferentes através de WebServices.

Para o exemplo utilizaremos a seguinte arquitetura: o SV1 se comunicará com o SV2 através de um WebService iniciando uma OS no SV2, quando a OS for finalizada o SV1 será avisado e a OS do SV1 prosseguirá.
