# Aprovador

Caminho: Customização > Modelo de objetos > Processo > Aprovador

Aprovadores

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **Hierarquia** | Hierarquia | [TipoAprovador](enum_tipoaprovador) |
| **Obrigatorio** | Indica que o Aprovador é obrigatório ou opcional. | Booleano |
| **OperacaoAtividadeId** | Número sequencial gerado automaticamente pelo sistema para Identificar uma OperacaoAtividade | Inteiro |
| **PapelAprovador** | Papel de Processo responsável pela Aprovação | [PapelProcesso](objetos_papelprocesso) |
| **PapelAprovadorId** | Identificador do Papel em Processo de Aprovação responsável pela Aprovação | Inteiro |
