# CustomPropertyScope

Caminho: Customização > Modelo de objetos > Utilitários > CustomPropertyScope

Escopo para Propriedades Customizadas. Se não for cadastrada restrição de Escopo então a Propriedade Customizada vale para todos os objetos da Classe associada

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **CustomPropertyId** | Identificador da Propriedade Customizada | Inteiro |
| **Property** | Propriedade com tipo de dados primitivo (inteiro, string, data/hora etc) que será utilizada para filtro e definição do escopo. | [Property](objetos_property) |
| **PropertyId** | Identificador da Propriedade | Inteiro |
| **Value** | Valor da Propriedade para habilitar a Propriedade Customizada | String |
