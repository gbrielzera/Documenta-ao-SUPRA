# Roteiro de implantação

Caminho: Guia para Administradores > Roteiro de implantação

Esta seção apresentaremos as principais configurações necessárias a implantação do Supravizio.

## Primeiro Acesso

O Supravizio possui um usuário administrador principal do sistema, o usuário Admin. É um usuário nativo do sistema e possui permissão total a todos os cadastros e não é possível removê-lo.

Para efetuar o primeiro acesso ao Supravizio e realizar a tarefa seguinte deste roteiro de implantação, que é a [importação de licenças](registrando_licenca), basta efetuar o logon com os seguintes dados:

**Usuário: admin**

**Senha: x**

Tela de logon do Supravizio

**Importante: **Por se tratar de um usuário utilizado apenas para o gerenciamento de cadastros, ele **não é utilizado como solucionador**, não sendo possível utilizá-lo no [Workspace](workspace).

A **senha** deste usuário **deverá** ser alterada posteriormente através do cadastro de Usuários (**Utilitários | Segurança | Usuários**):
