# Enumerações

Caminho: Customização > Modelo de objetos > Ativos > Enumerações

Enumerações do módulo Ativos

| **Tipo** | **Descrição** |
|---|---|
| SuperClasse | Super tipo para Itens de Configuração |
| UnidadeCusto | Unidade de Medida para definição de Custo |
| FonteDados | Fonte de dados para Itens de Configuração do tipo Artefato |
| CriterioChargeBack | Critério de apuração de Charge-back que define o destinatário do custo. O valor Item indica que o critério será delegado ao Item de Configuração desta classe. |
| CriterioChargeBackItem | Critério de apuração de Charge-back que define o destinatário do custo. |
| AgrupamentoItensChargeBack | Agrupamento de Itens de Charge-Back em relatórios apresentados para gestores de áreas |
| TipoAcesso | Tipo de permissão de Acesso |
