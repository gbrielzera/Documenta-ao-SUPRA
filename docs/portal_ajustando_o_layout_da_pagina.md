# Alterando o layout da página

Caminho: Guia para Administradores > Portal de Processos > Primeiro acesso ao Portal > Configurando o Portal > Alterando o layout da página

**Exceto no Modo Mobile**, podemos realizar a inclusão de mais de um módulo por página, dividindo-a em vários painéis.

Neste exemplo, iremos realizar a divisão de uma Página no Modo Tablet.

|---|---|

Modo de Edição de Layout

| 2. | Clicando nesta opção será exibido um novo menu, onde poderemos dividir ou remover o painel. Neste caso iremos dividir em painéis verticalmente. |
|---|---|

Divisão de Painéis

| 3. | Feita a divisão, note que é possível redimensionarmos o tamanho de cada painel, clicando no item central e arrastando para o devido local: |
