# Cadastro de Áreas

Caminho: Guia para Administradores > Roteiro de implantação > Realizando cadastros > Cadastro de Áreas

Diretoria, Gerência, Departamento ou Área que compõe a estrutura organizacional. Em um Órgão, também denominado Área, podemos associar empregados ou terceiros (lotação). Um Órgão pode possuir uma associação com outro Órgão denominado "Pai". Esta associação "pai-filho" define a hierarquia de órgãos de uma Empresa.

Para incluir um novo registro neste cadastro, acesse o caminho **Recurso | Áreas**:

Caminho para acesso a tela

Na tela que abrir, clicando no botão Novo será exibido o diálogo de edição para preenchimento do novo registro.

Botão 'Novo'

O cadastro da Área terá os seguintes campos:

Cadastro de Área

Caso hajam dúvidas a respeito destes campos, leia o tópico sobre [Áreas](orgao_sub).

Assim que finalizada a edição clique no botão **Salvar** para gravar os dados ou **Salvar e Voltar** para gravar e voltar para a tela anterior.
