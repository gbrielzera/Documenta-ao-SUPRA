# ClasseServico

Caminho: Customização > Modelo de objetos > Processo > RestricaoServico > ClasseServico

Tipo de Serviço que está habilitado para o fluxo. Este campo é preenchido automaticamente quando for atribuído o Serviço. Quando for preenchido apenas o campo Tipo de Serviço então são é possível a abertura de Ordens de Serviço para todos os Serviços do tipo especificada.
