# OpcaoAcaoAcordo

Caminho: Customização > Modelo de objetos > Processo > Enumerações > OpcaoAcaoAcordo

Ações que podem ser configuradas para um determinado Acordo de Nível Operacional

| **Valor** | **Descrição** |
|---|---|
| **Encaminhar** | Encaminha a ocorrência para a fila de uma pessoa ou fila obtida a partir de um papel de processo. |
| **Email** | Envia um email para uma pessoa obtida por um papel de processo |
