# FormaApontamento

Caminho: Customização > Modelo de objetos > Recurso > Enumerações > FormaApontamento

Forma de Apontamento

| **Valor** | **Descrição** |
|---|---|
| **Periodo** | O usuário deve informar uma data/hora de início e uma data/hora de sim do apontamento. |
| **Quantitativo** | O usuário simplesmente informa uma quantidade de horas/minutos para o apontamento. |
