# CriterioChargeBackItem

Caminho: Customização > Modelo de objetos > Ativos > Enumerações > CriterioChargeBackItem

Critério de apuração de Charge-back que define o destinatário do custo.

| **Valor** | **Descrição** |
|---|---|
| **Responsavel** | Utiliza a relação de responsabilidade de um Item de Configuração para endereçar o custo. |
| **Usuario** | Utiliza a relação de usuário de um Item de Configuração para endereçar o custo. |
