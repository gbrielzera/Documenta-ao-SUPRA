# Configuração de Caixas de Mensagens

Caminho: Guia para Administradores > Configurando Processos > Editor de Processos > Toolbox e elementos do BPMN > Eventos Iniciadores > Iniciador por Mensagem > Configuração de Caixas de Mensagens

A configuração de Caixas de mensagens monitoradas pode ser acessada pelo caminho **Processo | Processo | Caixas de Mensagens**:

**Transação Caixas de Mensagens**

Ao entrar na transação, serão exibidas as caixas de mensagem cadastradas no sistema:

Listagem de caixas de mensagem

Para adicionar uma nova caixa de mensagem, é necessário o preenchimento dos seguintes parâmetros:

Parâmetros para preenchimento

| Nome | Nome da caixa de e-mail ao qual o usuário deseja conectar |
|---|---|
| **Senha** | Senha da respectiva caixa preenchida no campo anterior |
| **Servidor POP3** | Endereço do servidor da caixa de e-mails |
| **Porta POP3** | Porta do utilizada pelo Servidor. Caso não seja preenchido, assume-se a porta padrão do protocolo |
| **Utiliza conexão segura (SSL)** | Habilita/Desabilita o uso do protocolo de segurança SSL |
| **Protocolo de recuperação de mensagens** | Protocolo a ser utilizado para recuperação de mensagens, que pode ser selecionado entre as seguintes opções: - POP3 - IMAP4 |
| **Tipo de autenticação do Servidor de e-mail** | Caso seja utilizado algum mecanismo específico de autenticação, estão disponíveis as opções **CRAM5** e **NTLM**. Caso contrário, selecione a opção **Comum** |
