# ContratoItem

Caminho: Customização > Modelo de objetos > Recurso > ContratoItem

Relaciona Itens de Configuração com o Contrato e define valor mensal para manutenção.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **ContratoId** | Número sequencial gerado automaticamente pelo sistema para Identificar um Contrato | Inteiro |
| **ItemConfiguracao** | Item de Configuração mantido pelo Contrato | [ItemConfiguracao](objetos_itemconfiguracao) |
| **ItemConfiguracaoId** | Identificador do Item de Configuração mantido pelo Contrato | Inteiro |
| **ValorMensal** | Valor mensal para manutenção do Item de Configuração | Decimal |
