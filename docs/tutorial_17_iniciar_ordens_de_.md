# Tutorial 15: Iniciar Ordens de Serviço por Arquivos

Caminho: Guia para Administradores > Configurando Processos > Tutoriais > Tutorial 15: Iniciar Ordens de Serviço por Arquivos

Este tutorial tem como objetivo demonstrar no uso de iniciadores por regra e por temporizador a abertura de Ordens de Serviço através da inclusão de arquivos em uma pasta (os arquivos serão anexados na Ordem de Serviço e o original será removido da pasta.

Para esse tutorial é recomendado a leitura prévia do:

- [Tutorial 1: Construindo o primeiro Processo](tutorial_01)

E é necessário que seja reservada uma pasta para que os arquivos que serão anexados na Ordem de Serviço serão colocados.

No caso utilizaremos a pasta "**D:\\temp**".
