# Configurando o layout

Caminho: Guia para Solucionadores > Worklist > Configurando o layout

É possível configurar o grid para que seja realizada a ordenação ou agrupamento por colunas.

Configurações do Grid

Podemos modificar a ordenação dos registros (ascendente ou descendente) e mudar a sequência das colunas. Para modificar a ordenação clique sobre o nome da coluna ou "segure" e arraste o cabeçalho para modificar a ordem de exibição da coluna. O layout da listagem é personálizável por usuário, ou seja, as alterações realizadas serão salvas e recuperadas na próxima vez que este usuário entrar no sistema.
