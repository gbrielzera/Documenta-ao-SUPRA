# Interface com o Usuário  > Interface do Solucionador

Caminho: Interface com o Usuário  > Interface do Solucionador

O Supravizio Web é uma aplicação que tem como alvo solucionadores, focando usuários que realizem o tratamento de Ordens de Serviço abertas pelos solicitantes.

A principal vantagem desta aplicação é que pode ser aberto em qualquer navegador compatível, independente da plataforma do Sistema Operacional utilizado pelo estação do cliente.
