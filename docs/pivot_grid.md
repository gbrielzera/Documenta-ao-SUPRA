## Pivot Grid

Este tipo de modelo apresenta uma tabela dinâmica de dados multidimensional em um formato de fácil leitura.

Modelo Pivot

Através do Pivot Grid é possível computar totalizadores automaticamente:

Existem 3 regiões possíveis para distribuição dos dados: Colunas, Linhas e Valores

Os dados podem ser (opcionalmente) distribuidos em Linhas e Colunas. O Pivot Grid tem como principal característica realizar o cálculo dos valores dada a configuração de dados distribuidos nestas linhas e colunas. Utilizando a região Valores é possível definir a função de cálculo dos valores (Soma, Contagem, Mínimo, Máximo, entre outros).
