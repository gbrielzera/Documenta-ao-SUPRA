# CardinalidadeAssociacao

Caminho: Customização > Modelo de objetos > Processo > Enumerações > CardinalidadeAssociacao

Cardinalidade em um Sentido de Associação.

| **Valor** | **Descrição** |
|---|---|
| **ZeroOrMore** | Permite a associação de diversas ocorrências de Processos |
| **ZeroOrOne** | Permite a associação de uma única Ocorrência. |
