# DatePicker

Caminho: Guia para Administradores > Roteiro de implantação > Propriedades Customizadas > Criação de Campos Customizados > Tipos de Controle > DatePicker

Exibe um controle para edição de datas permitindo a seleção por meio de um calendário. Na aplicação do Portal de Processos o controle é parecido com um Textbox e não existe o recurso de calendário para seleção do dia. Para este controle, utilize valores do tipo Data e Hora.
