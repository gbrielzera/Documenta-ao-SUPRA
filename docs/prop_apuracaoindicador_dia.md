# Propriedade Dia

Caminho: Propriedade Dia

Dia base de cálculo

**Exemplo 1: modificação da propriedade Dia**

```
# carrega objeto ApuracaoIndicador de identificador 1
apuracaoIndicador = ApuracaoIndicador.Carrega(1)
# modifica a propriedade Dia
apuracaoIndicador.Dia = 1;
# salva modificação da propriedade Dia
ApuracaoIndicador.Salva(apuracaoIndicador)
```
