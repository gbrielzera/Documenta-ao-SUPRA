# InstallLog

Caminho: Customização > Modelo de objetos > Utilitários > InstallLog

Mensagens geradas pelas rotinas de instalação. Este log é consultado por uma janela exibida após configuração da camada servidora.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **DateTime** | Data e hora de registro da mensagem | Data/hora |
| **Message** | Mensagem gerada pela rotina de atualização. | String |
| **Routine** | Nome de identificação da rotina executada durante atualização do software | String |
| **Status** | Situação corrente do processamento indicando que: ainda está em execução, foi finalizado com sucesso ou foi finalizado com erros. | String |
