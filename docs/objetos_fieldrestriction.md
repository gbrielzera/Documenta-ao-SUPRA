# FieldRestriction

Caminho: Customização > Modelo de objetos > Utilitários > FieldRestriction

Desabilita ou oculta campos em transações de cadastro.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **Action** | Ação aplicada na restrição de visualização de campo | [FieldRestrictionAction](enum_fieldrestrictionaction) |
| **AuthorizationRoleId** | Identificador do Perfil de acesso proprietário da regra | Inteiro |
| **AuthorizationTransactionId** | Identificador da Transação proprietária da restrição | Inteiro |
| **Property** | Propriedade que será utilizada na expressão de filtro de registros. | [Property](objetos_property) |
| **PropertyId** | Identificador da Propriedade utilizada para modificação de regra de visualização | Inteiro |
