# Skins de páginas

Caminho: Guia para Administradores > Portal de Processos > Customizações de aparência > Skins de páginas

As skins tem o intuito de criar uma identidade visual para o Portal de Processos e compostas de arquivos HTML que permitem a alteração do layout do site na interface Clássica.
