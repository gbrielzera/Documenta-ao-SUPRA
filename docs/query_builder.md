# Query Builder

Caminho: Guia para Administradores > Editor de Relatórios > Query Builder

O Query Builder é uma ferramenta para auxilio na elaboração de consultas mais consistentes.

Ele é composto dos seguintes quadros:

### Lista de Tabelas

Este quadro lista todas as tabelas visíveis disponíveis para a elaboração do relatório desejado. Para incluir uma tabela em uma consulta, basta selecioná-la e dar um duplo clique no mouse.

### Lista de Tabelas e Campos utilizados

Este quadro lista todas as tabelas e campos que estão sendo utilizados na elaboração da consulta.

Visualização de Tabelas

Neste quadro são disponibilizadas as tabelas e relacionamentos de forma visual ao implementador do relatório. Nela você poderá incluir e eliminar tabelas e relacionamentos.

### Configuração de Campos de Consulta

Através deste quadro o implementador poderá ver todos os campos listados, todos os que serão retornados na consulta, quanto aqueles que estão sendo usados para filtrar os dados. É possível também realizar agrupamentos utilizando este recurso.

### Edição de SQL

Neste quadro o implementador poderá acompanhar e editar a consulta que está sendo elaborada.
