# Restrição de Acesso aos Artigos da Base de Conhecimento

Caminho: Guia para Solucionadores > Base de Conhecimento > Restrição de Acesso aos Artigos da Base de Conhecimento

No Supravizio, é possível restringir o acesso aos artigos da Base de Conhecimento para os papéis definidos, conforme explicado no tópico [Tipos de Papéis](tipos_papeis).

Para isso acesse no menu principal **Ativos | Base de Conhecimento** e abra, com um duplo clique, o registro do artigo que deseja-se incluir uma restrição.

Observe a aba "**Restrição de acesso**". Nesta tela são incluídos **somente os papéis que terão acesso** ao documento.

Para isso clique em "**Novo**".

Nesta tela selecione através do campo "Papel" o papel que terá acesso ao artigo.

Obs: Caso não seja incluído nenhum papel, o documento será público,ou seja, visível para todos os papéis sem restrição nenhuma.
