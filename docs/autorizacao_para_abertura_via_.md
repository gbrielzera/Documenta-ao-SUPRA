# Autorização para abertura via email

Caminho: Guia para Administradores > Configurando Processos > Tutoriais > Tutorial 12: Abertura de Ordem de Serviço por email > Autorização para abertura via email

A autorização para abertura via e-mail, é um importante recurso para que o processo possa ser restringido para abertura por apenas certos grupos de pessoas.

No editor de processos, verifique a aba de Clientes autorizados:

Editar Clientes autorizados

Em seguida clique em adicionar para adicionar novos papéis autorizados e selecione o papel desejado:

Adicionar papéis autorizados

Agora no tutorial, iremos testar se tal configuração vigorou. Não esqueça de verificar se a versão na qual você editou está ativa após a edição e de salvar as alterações.

Vamos novamente editar o e-mail de outra pessoa (Simone Santos) como no [tópico anterior](enviar_email_para_mailbox_test) para que possa ser comparado qual das Ordens de Serviço será aberta:
