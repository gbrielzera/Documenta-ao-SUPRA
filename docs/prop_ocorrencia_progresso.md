# Propriedade Progresso

Caminho: Propriedade Progresso

Percentual de progresso no atendimento da Ocorrência.

**Exemplo 1: modificação da propriedade Progresso**

```
# carrega objeto Ocorrencia de identificador 1
ocorrencia = Ocorrencia.Carrega(1)
# modifica a propriedade Progresso
ocorrencia.Progresso = 1;
# salva modificação da propriedade Progresso
Ocorrencia.Salva(ocorrencia)
```
