# Escore

Caminho: Customização > Modelo de objetos > Processo > Escore

Escore de Questão

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **GrupoQuestaoId** | Número sequencial gerado automaticamente pelo sistema para Identificar um GrupoQuestao | Inteiro |
| **Id** | Número sequencial gerado automaticamente pelo sistema para Identificar um Escore | Inteiro |
| **Rotulo** | Descritivo apresentado para o usuário como opção. Exemplos: Ótimo, Péssimo, Bom. | String |
| **Sequencial** | Define a sequência de apresentação da opção de resposta. | Inteiro |
| **Valor** | Valor atribuído a opção de resposta. Este valor pode ser comparado em fórmulas de cálculo de Indicadores de Desempenho. | Inteiro |
