# Propriedade ApuracaoIndicadorPlanoGestaoId

Caminho: Propriedade ApuracaoIndicadorPlanoGestaoId

Identificador do Plano de Gestão

**Exemplo 1: modificação da propriedade ApuracaoIndicadorPlanoGestaoId**

```
# carrega objeto MemoriaCalculoApurada de identificador 1
memoriaCalculoApurada = MemoriaCalculoApurada.Carrega(1)
# modifica a propriedade ApuracaoIndicadorPlanoGestaoId
memoriaCalculoApurada.ApuracaoIndicadorPlanoGestaoId = 1;
# salva modificação da propriedade ApuracaoIndicadorPlanoGestaoId
MemoriaCalculoApurada.Salva(memoriaCalculoApurada)
```
