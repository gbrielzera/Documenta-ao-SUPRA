# ClasseComponente

Caminho: Customização > Modelo de objetos > Ativos > ClasseComponente

Tipos de Itens de Configuração que podem ser utilizadas como Componentes.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **ClasseComponenteId** | Identificador do Tipo de Item de Configuração que é utilizada como Componente | Inteiro |
| **ClasseConfiguracaoId** | Identificador do Tipo de Serviço que é proprietária das Classes relacionadas como Componentes | Inteiro |
| **Componente** | Um Tipo de Item de Configuração é utilizado para classificar Itens de Configuração, que são ativos sujeitos a alteração (como entrada ou saída) em processos de negócio. | [ClasseConfiguracao](objetos_classeconfiguracao) |
