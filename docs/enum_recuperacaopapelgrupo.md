# RecuperacaoPapelGrupo

Caminho: Customização > Modelo de objetos > Processo > Enumerações > RecuperacaoPapelGrupo

Regra de recuperação de pessoas na definição de um papel por relação de grupos de trabalho

| **Valor** | **Descrição** |
|---|---|
| **Solucionadores** | Recupera todos os solucionadores lotados no grupo de trabalho inclusive o próprio coordenador (se este for relacionado como um solucionador no grupo) |
| **Coordenador** | Somente o coordenador |
| **SolucionadoresExcetoCoordenador** |  |
