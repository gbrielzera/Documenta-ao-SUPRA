# CriterioAuxiliarBuscaPessoaAA

Caminho: CriterioAuxiliarBuscaPessoaAA

Campo utilizado como critério de busca auxiliar para Pessoas na aplicação de Auto-atendimento

| **Valor** | **Descrição** |
|---|---|
| **Nenhum** | Nenhum campo é utilizado como critério auxiliar. Neste caso a única forma de busca é por Nome Resumido do Cliente. |
| **Matricula** | O campo de Matricula é utilizado em conjunto com o Nome Resumido para recuperação de Pessoas. |
| **UsuarioRede** | O campo de Usuário de rede é utilizado em conjunto com o Nome Resumido para recuperação de Pessoas. |
