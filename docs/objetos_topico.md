# Topico

Caminho: Customização > Modelo de objetos > Ativos > Topico

Tópico de Artigo

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **ConteudoHTML** | Conteúdo em formato texto mantido automaticamente pelo sistema. | String |
| **ConteudoRTF** | Conteúdo no formato RTF mantido pelo usuário | System.Object |
| **ConteudoTexto** | Conteúdo texto mantido automaticamente pelo sistema | String |
| **ItemConfiguracaoId** | Número sequencial gerado automaticamente pelo sistema para Identificar um Topico | Inteiro |
| **TopicoConhecimento** | Template definido no tipo de artigo que indicará o rótulo e o sequencial de apresentação no documento final. | [TopicoConhecimento](objetos_topicoconhecimento) |
| **TopicoConhecimentoId** | Identificador do template definido para o Tópico. Este template é criado no Tipo de Item de Configuração. | Inteiro |
