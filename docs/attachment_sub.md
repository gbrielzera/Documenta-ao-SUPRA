# Anexo de mensagem

Caminho: Janelas > Utilitários > Mensagens > Anexo de mensagem

Arquivo anexado na mensagem para envio.

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Nome completo do arquivo** | Nome completo do arquivo incluindo caminho onde está localizado. IMPORTATE: este arquivo deve estar disponível no instante em que a mensagem for enviada. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna FILE_NAME da tabela [SV_MESSAGE_ATTACH](dados_sv_message_attach). |
|---|---|
| **Removido** | Indica que o arquivo foi removido na pasta de arquivos anexados que é mantido no servidor de arquivos. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna ATTACH_DELETED da tabela [SV_MESSAGE_ATTACH](dados_sv_message_attach). |
