# ItemPesquisa

Caminho: Customização > Modelo de objetos > Processo > ItemPesquisa

Item a ser avaliado em uma Pesquisa

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **Escore** | Valor atribuido ao Indicador como resposta a Pesquisa de Satisfação | Inteiro |
| **PesquisaId** | Identificador da Pesquisa | Inteiro |
| **QuestaoPesquisa** | Uma Questão de Pesquisa pode ser utilizada na elaboração de Pesquisas de Satisfação enviadas para Clientes após a finalização de uma Ordem de Serviço. | [QuestaoPesquisa](objetos_questaopesquisa) |
| **QuestaoPesquisaId** | Identificador da Questão associada | Inteiro |
