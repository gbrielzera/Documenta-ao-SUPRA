# Períodos úteis

Caminho: Janelas > Recurso > Calendário > Períodos úteis

Regra que define a disponibilidade de recursos em função dos dias da semana.

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Dia semana** | Dia da semana Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna DIA_SEMANA da tabela [PERIODO_UTIL](dados_periodo_util). |
|---|---|
| **Hora início** | Hora de início do período de disponibilidade (0 a 23) Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório - A 'Hora início' deve ser menor ou igual a 23 - A 'Hora início' deve ser maior ou igual a 0 Este campo é mantido na coluna HORA_INICIO da tabela [PERIODO_UTIL](dados_periodo_util). |
| **Minuto início** | Minuto de início (0 a 59) Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório - O 'Minuto início' deve ser menor ou igual a 59 - O 'Minuto início' deve ser maior ou igual a 0 Este campo é mantido na coluna MINUTO_INICIO da tabela [PERIODO_UTIL](dados_periodo_util). |
| **Hora fim** | Hora de fim do período de disponibilidade (0 a 23) Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório - A 'Hora fim' deve ser menor ou igual a 23 - A 'Hora fim' deve maior ou igual a 0 Este campo é mantido na coluna HORA_FIM da tabela [PERIODO_UTIL](dados_periodo_util). |
| **Minuto fim** | Minuto fim (0 a 59) Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório - O 'Minuto fim' deve ser menor ou igual a 59 - O 'Minuto fim' deve ser maior ou igual a 0 Este campo é mantido na coluna MINUTO_FIM da tabela [PERIODO_UTIL](dados_periodo_util). |
| **Validade da regra** | Validade da regra em função da semana Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna DISPONIBILIDADE da tabela [PERIODO_UTIL](dados_periodo_util). |
