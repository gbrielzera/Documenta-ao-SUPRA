# Tópico de Artigo da Base de Conhecimento

Caminho: Janelas > Ativos > Tipo Item Configuração > Tópico de Artigo da Base de Conhecimento

Tópico que deve ser preenchido na elaboração de um artigo da base de conhecimento. Quando um artigo é criado todos os tópicos são preenchidos conforme o template definido por este registro.

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Sequencia** | Sequencial utilizado para ordenar (ordenação ascendente) tópicos de um determinado artigo. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna SEQUENCIA da tabela [TOPICO_CONH](dados_topico_conh). |
|---|---|
| **Sub-Título** | Sub-título do tópico Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna SUB_TITULO da tabela [TOPICO_CONH](dados_topico_conh). |
