# Ativo

Caminho: Customização > Modelo de objetos > Processo > OperacaoAtividade > Ativo

Quando Ativa uma Operação pode ser inicializada automaticamente (geração da solicitação de aprovação por exemplo). A Ativação da Operação também define o comportamento da rotina de Validação de Processo. Se Ativa a Validação é executada caso contrário é ignorada.
