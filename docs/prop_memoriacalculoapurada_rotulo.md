# Propriedade Rotulo

Caminho: Propriedade Rotulo

Rótulo

**Exemplo 1: modificação da propriedade Rotulo**

```
# carrega objeto MemoriaCalculoApurada de identificador 1
memoriaCalculoApurada = MemoriaCalculoApurada.Carrega(1)
# modifica a propriedade Rotulo
memoriaCalculoApurada.Rotulo = "Rótulo";
# salva modificação da propriedade Rotulo
MemoriaCalculoApurada.Salva(memoriaCalculoApurada)
```
