# Drill-Down

Caminho: Guia para Administradores > Editor de Dashboard > Criando Dashboards > Interatividade > Drill-Down

A função de Drill-Down permite ao usuário alterar o nível de dados exibidos nos itens do Dashboard. Este componente permite que o próprio solucionador aprofunde as informações para estudar detalhes, ou generalizar para ter uma visão mais superficial.

Utilizamos como exemplo o modelo Gauges

O ícone da direita possibilita realizar o Drill-Down nos itens da seção Series da Fonte de Dados do Dashboard. Enquanto o ícone permite realizar o Drill-Down nos itens da seção Arguments.

É importante reforçarmos que é possível apenas a realização de um tipo de Drill-Down em cada painel.
