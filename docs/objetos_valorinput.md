# ValorInput

Caminho: Customização > Modelo de objetos > Processo > ValorInput

Valores de Parâmetors de Entrada

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **AtividadeId** | Atividade proprietária do Valor de Parâmetro de Entrada | Inteiro |
| **CustomProperty** | Propriedade criada pelo usuário administrador que será preenchida na ocorrência invocada. Após selecionar uma propriedade é necessário preencher a fórmula que será utilizada para fornecer o valor passado como parâmetro. | [CustomProperty](objetos_customproperty) |
| **CustomPropertyId** | Identificador do(a) CustomProperty associado(a) | Inteiro |
| **ExpressaoValor** | Fórmula para determinar o Valor a ser fornecido como parâmetro. Se não definido é fornecido o mesmo valor do nível invocador. | String |
| **Id** | Número sequencial gerado automaticamente pelo sistema para Identificar um ValorInput | Inteiro |
| **Property** | Propriedade nativa na tabela de Ordens de Serviço que será preenchida na ocorrência invocada. Após selecionar uma propriedade é necessário preencher a fórmula que será utilizada para fornecer o valor passado como parâmetro. | [Property](objetos_property) |
| **PropertyId** | Identificador do InputSubProcesso associado | Inteiro |
