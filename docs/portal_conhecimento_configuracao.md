# Configurando o Módulo

Caminho: Guia para Administradores > Portal de Processos > Módulos > Modulo de Base de Conhecimento > Configurando o Módulo

Para este módulo, podem ser configurados os seguintes parâmetros:

Parâmetros do módulo

Número de Registros por Página

Define o número de artigos que serão exibidos na listagem de resultados na página de busca do módulo. Por padrão, o valor de estar entre 5 e 100.

Restrição de número de registros definido como 25

## Comentário pré-aprovado

Habilitando esta opção, o comentário não passará por aprovação para ser exibido. A situação do comentário será 'Aprovado' e não passará pelo estado 'Pendente.

Quando estiver desabilitada, este será submetido a uma aprovação prévia antes de ser exibido.
