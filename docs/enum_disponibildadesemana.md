# DisponibildadeSemana

Caminho: Customização > Modelo de objetos > Recurso > Enumerações > DisponibildadeSemana

Define a validade da regra em relação a semana

| **Valor** | **Descrição** |
|---|---|
| **Todas** | A regra é válida para todas as semanas |
| **Impar** | A regra é válida somente para semanas ímpares (indexador anual) |
| **Par** | A regra é válida somente para semanas pares (indexador anual) |
