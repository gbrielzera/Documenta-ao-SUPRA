# Tutorial 5: Sincronização de Cancelamentos

Caminho: Guia para Administradores > Configurando Processos > Tutoriais > Tutorial 5: Sincronização de Cancelamentos

O objetivo deste tutorial é apresentar os principais recursos relacionados com cancelamentos de Ordens de Serviço.

Ao término deste tutorial seremos capazes de:

- Cancelar automaticamente uma Ordem de Serviço após uma reprovação;
- Cancelar uma Ordem de Serviço invocada ou chamadora a partir de outra chamadora ou invocada respectivamente.

Nosso tutorial iniciará com a geração de uma nova versão. Em seguida modificaremos o fluxo de Aquisição de suprimentos para utilizar os recursos específicos de cancelamentos. No fim executaremos algumas Ordens de Serviço para constatar as funcionalidades em questão.

**Neste Tutorial encontraremos os seguintes tópicos:**

- [Gerar uma nova versão](tutorial_5_gerar_uma_nova_versao2)
- [Modificar o Subprocesso](tutorial_5_modificando_processos)
- [Cancelando Ordens de Serviço após reprovação](tutorial_5_cancelando_ordens_de_servico)
- [Cancelamento automático entre Ordens de Serviço associadas](tutorial_5_cancelamento_associadas)
