# OpcaoCampoPapel

Caminho: Customização > Modelo de objetos > Processo > Enumerações > OpcaoCampoPapel

Opções para recuperação de pessoas pelo critério de campo da ocorrência ou cadastros associados

| **Valor** | **Descrição** |
|---|---|
| **Pessoa** | Seleciona a própria pessoa configurada no processo. Esta pessoa deve estar ativa. |
| **GestorPessoa** | Seleciona o Gestor da pessoa informada. O gestor deve estar ativo. |
| **GestorOrgao** | Seleciona o Gestor do órgão onde a pessoa selecionada está lotada. O gestor deve estar ativo. |
| **TodosGestoresPessoa** | Seleciona todos os gestores da pessoa considerando a lotação do mesmo até o nível raiz da estrutura de órgãos. São recuperadas apenas pessoas ativas. |
| **GestoresParesOrgao** | Seleciona os gestores de órgãos que possuem o mesmo órgão pai do órgão onde a pessoa está lotada. São recuperadas apenas pessoas ativas. |
