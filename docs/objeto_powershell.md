# Objeto PowerShell

Caminho: Recursos Avançados > Objeto PowerShell

O objeto PowerShell é um objeto que possibilita a execução de comandos do Powershell no servidor.

Este objeto possui os seguintes métodos:

**Funções:**

| **Nome** | **Descrição** |
|---|---|
| **PSExecuteCmdlet**(string command) | Executa um comando PowerShell. |
| **PSExecuteCmdlet**(string command, string parName1, string parValue1, string parName2, string parValue2, string parName3, string parValue3) | Executa um comando PowerShell. |
