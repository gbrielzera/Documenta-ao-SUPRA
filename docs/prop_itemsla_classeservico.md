# ClasseServico

Caminho: Customização > Modelo de objetos > Recurso > ItemSLA > ClasseServico

Classe de Serviços atendidos pelo Acordo de Nível de Serviço. Quando preenchido o campo Serviço a Classe de Serviço é atribuída automaticamente. Se não for preenchido o campo Serviço então são considerados todos os Serviços da Classe selecionada.
