# Gestão por relatórios

Caminho: Guia para Administradores > Inventário de Hardware e Software > Gestão por relatórios

Através do Supravizio não só é possível importar os dados do Inventariado de Hardware e Software, tratar eventos através desta importação. É possível também realizar a gestão destes ativos e seus componentes.

Na tela de Edição de Ordem de Serviço por exemplo, é possível visualizar os dados do hardware diretamente na base de dados do software de inventário clicando no comando abaixo:

Este comando exibirá o relatório **Hardware OCS detalhado**, que é um relatório completo contendo todos os dados relacionados com o hardware:

Este relatório provê informações como softwares instalados:

Monitores, memórias, dispositivos de entrada, unidades de disco, dentre outros:
