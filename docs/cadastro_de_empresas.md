# Cadastro de Empresas

Caminho: Guia para Administradores > Roteiro de implantação > Realizando cadastros > Cadastro de Empresas

Uma Empresa é uma entidade composta por um ou mais órgãos onde estão lotadas pessoas. Uma empresa também pode pertencer a um grupo de empresas. Na aplicação do Portal de Processos empresas são utilizadas para restringir buscas por pessoas. Na tela de substitutos, por exemplo, são listadas apenas as pessoas lotadas na empresa do usuário conectado. Porém, se a empresa do usuário conectado faz parte de um grupo de empresas então são listadas todas as pessoas do mesmo grupo.

Para incluir um novo registro neste cadastro, acesse o caminho **Recurso | Empresas**:

Caminho para acesso a tela

Na tela que abrir, clicando no botão Novo será exibido o diálogo de edição para preenchimento do novo registro.

Botão 'Novo'

O cadastro da Empresa terá os seguintes campos:

Cadastro de Empresa
