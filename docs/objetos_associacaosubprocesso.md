# AssociacaoSubprocesso

Caminho: Customização > Modelo de objetos > Processo > AssociacaoSubprocesso

Indica uma associação entre uma atividade do tipo Link Inicial de um subprocesso específico e uma Associação

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **AssociacaoId** | Identificador do Associacao associado | Inteiro |
| **AssociacaoInicio** | Associação configurada em um iniciador do tipo LinkInicial | [Associacao](objetos_associacao) |
| **AtividadeId** | Número sequencial gerado automaticamente pelo sistema para Identificar uma Atividade | Inteiro |
