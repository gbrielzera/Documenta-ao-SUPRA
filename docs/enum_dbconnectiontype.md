# DBConnectionType

Caminho: Customização > Modelo de objetos > Utilitários > Enumerações > DBConnectionType

Tipo de conexão de banco de dados

| **Valor** | **Descrição** |
|---|---|
| **SystemDataSqlClient** | Conexão SQL Server via biblioteca nativa do Microsoft. Net |
| **SystemDataOracleClient** | Conexão Oracle via biblioteca nativa do Microsoft .Net |
| **SystemDataOdbcClient** | Conexão de banco de dados via biblioteca ODBC |
| **SystemDataOledbClient** | Conexão de banco de dados via biblioteca Microsoft OLE DB |
