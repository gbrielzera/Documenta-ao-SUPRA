# ProvedorIndicador

Caminho: Customização > Modelo de objetos > Processo > Enumerações > ProvedorIndicador

Provedor de Indicadores de Desempenho

| **Valor** | **Descrição** |
|---|---|
| **OrdemServico** | A apuração é realizada a partir de ocorrências de Processos (Ordens de Serviço). |
| **ItemConfiguracao** | A apuração é realizada a partir da base de Itens de Configuração (CMBD). |
| **PesquisaSatisfacao** | A apuração é realizada a partir da base de Pesquisas de Satisfação de Ordens de Serviço |
| **LancamentoManual** | O valor apurado é informado manualmente pelo usuário responsável pelo Indicador. |
