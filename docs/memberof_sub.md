# Associação Usuário/Perfil de acesso

Caminho: Janelas > Utilitários > Usuário > Associação Usuário/Perfil de acesso

Define a associação entre um Usuário e Perfis de Acesso

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Perfil de acesso** | Conjunto de telas autorizadas para um determinado usuário. Importante: um usuário pode acumular diversos perfis e o menu final é formado pela soma de todos os acessos. Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
