# Contato Cliente

Caminho: Guia para Solucionadores > Workspace  > Workspace Ordens de Serviço > Contato Cliente

A tela de registro de contato com o cliente é um importante recurso pois o registro é utilizado no [relatório de Análise de Pesquisa de Satisfação](analise_pesquisa_satisfacao), onde são apresentados dados de contato para cada área com índices de insatisfação:

Relatório de Análise de Pesquisa de Satisfação

Para visualizar a tela de contato com o cliente utilize na barra de ferramenta de uma Ordem de Serviço o botão Mais Ações , Contato Cliente ou utilize o menu de contexto da área de comentários.

**Contato Cliente na Barra de Ferramentas**

**Menu de Contexto da Área de Comentários**

Ao acessar a tela de contato com o cliente, você poderá visualizar a seguinte tela:

Contato com o Cliente

Toda tentativa de contato efetuada fica registrada nos Eventos (Informações sobre Processo) da Ordem de Serviço.

Eventos Registrados

O contato também pode ser exibido na área de comentários da Ordem de Serviço porém o Evento Contato Cliente deve estar configurado como aviso crítico ou Exceção nos [Tipos de Evento](tipoevento_sub).

Para isso, entre em Processo | Processos | Tipos de Eventos e localize o item PR0015 - Contato Cliente:

Exibição Contato Cliente

É possível modificar o Tipo Mensagem para aviso crítico ou exceção para que possa ser visualizado na área de comentários e mensagens.

Tipo Mensagem Contato Cliente

Após tal modificação é possível verificar nos comentários e mensagens os avisos relativos aos contatos com o cliente.

Comentários e mensagens
