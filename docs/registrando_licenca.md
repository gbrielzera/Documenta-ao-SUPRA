# Importando licença

Caminho: Guia para Administradores > Roteiro de implantação > Importando licença

Para registrar as licenças adquiridas do Supravizio, você deve efetuar login no sistema através do usuário **Admin**. Após isso, acesse **Utilitários | Licenciamento** através do menu principal.

Localização da opção Licenciamento

De posse do arquivo de licenças fornecido por [Venki Tecnologia](http://www.venki.com.br), clique em **Importar Licença**. Nesse instante será aberto um diálogo para seleção de arquivo.
