# Propriedade ApuracaoIndicadorIndicadorId

Caminho: Propriedade ApuracaoIndicadorIndicadorId

Identificador do(a) ApuracaoIndicador associado(a)

**Exemplo 1: modificação da propriedade ApuracaoIndicadorIndicadorId**

```
# carrega objeto MemoriaCalculoApurada de identificador 1
memoriaCalculoApurada = MemoriaCalculoApurada.Carrega(1)
# modifica a propriedade ApuracaoIndicadorIndicadorId
memoriaCalculoApurada.ApuracaoIndicadorIndicadorId = 1;
# salva modificação da propriedade ApuracaoIndicadorIndicadorId
MemoriaCalculoApurada.Salva(memoriaCalculoApurada)
```
