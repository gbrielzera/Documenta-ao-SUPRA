# VisibilidadeIniciador

Caminho: Customização > Modelo de objetos > Processo > Enumerações > VisibilidadeIniciador

Tipo de visibilidade que um iniciador de processo pode ter entre as aplicações do sistema.

| **Valor** | **Descrição** |
|---|---|
| **SomenteWorkspace** | O iniciador é visível somente na aplicação Workspace |
| **SomenteAutoAtendimento** | O iniciador é visível somente na aplicação de Autoatendimento |
| **Todos** | O iniciador é visível em todas as aplicações |
