# ValidadeSaldo

Caminho: Customização > Modelo de objetos > Recurso > RecursoAplicado > ValidadeSaldo

Quantidade de meses para validade das horas que não forem utilizadas no mês apurado. Se não for preenchido ou for preenchido com o valor 0 significará que as horas devem ser consumidas no mesmo mês. Se for uma quantidade de meses igual ou superior ao restante de meses do contrato significará que as horas formarão um banco.
