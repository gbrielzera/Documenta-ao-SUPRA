# Configurações do Grid de Ordens de Serviço

Caminho: Guia para Solucionadores > Workspace  > Workspace Ordens de Serviço > Configurações do Grid de Ordens de Serviço

É possível incluir ou remover campos na listagem de Ordens de Serviço, possibilitando utilização de diferentes filtros, clique com o botão direito em qualquer campo e utilize o menu "Selecionar Colunas":

Selecionar Colunas do Grid

Será exibida uma listagem de Colunas para adicionar basta arrastar o campo desejado da janela de customização para o grid:

Adicionar ou remover Colunas do Grid

Caso necessário, também é possível restaurar o grid de Ordens de Serviço para a configuração original, clicando no botão indicado na figura:

Restaurar Colunas do Grid

### Agrupamento de Ordens de Serviço

É possível também **agrupar** as Ordens de Serviço por campo, para realizar o agrupamento basta arrastar as Ordens de Serviço desejadas para o Painel de Agrupamento:

**Agrupamento de colunas**

### Ordenação dos registros

Utilizando o cabeçalho do grid podemos modificar a ordenação dos registros (ascendente ou descendente) e mudar a sequência de colunas. Utilize um clique sobre o cabeçalho para modificar a ordenação ou "segure" e arraste o cabeçalho para modificar a ordem das colunas. Esta configuração é gravada no perfil do usuário conectado, ou seja, quando este acessar novamente a tela encontrará a última configuração preservada.

**Ordenação de Ordens de Serviço**

Para mais detalhes sobre recuperação de Ordens de Serviço no Workspace veja [Filtro avançado de Ordens de Serviço](acessar_ordemservico).

### Ordens de Serviço Associadas

É possível também visualizar Ordens de Serviço associadas pelo grid de Ordens de Serviço. Para visualizar basta clicar em Expandir ou para ocultar as associações clique em Recolher. Veja que são exibidas as Ordens de Serviço associadas:

Também é possível visualizar Ordens de Serviço Associadas através da aba [Associações](workspace_os_associada) da tela de [Edição de Ordem de Serviço](editar_ordemservico).

Aba Ordens de Serviço Associadas

### Campos Disponíveis para seleção

Ao inserir colunas na tela de visualização de Ordens de Serviço, automaticamente serão recuperados os campos nativos do Supravizio e no caso de haverem Campos Customizados, será utilizado um critério de seleção que permite que sejam utilizados apenas os seguintes tipos de dados:

- Alfanumérico
- Data e Hora
- Decimal
- Inteiro
- Lógico

Estas colunas também estão disponíveis para serem incluídas no Grid da aba **Ordens de Serviço Associadas** na tela de Edição de Serviço.
