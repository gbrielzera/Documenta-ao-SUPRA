# Como filtrar a listagem de Ordens de Serviço

Caminho: Guia para Solucionadores > Worklist > Como filtrar a listagem de Ordens de Serviço

O filtro de Ordens de Serviço na listagem do Worklist funciona através dos seguintes controles:

Filtros na listagem do Worklist

Para filtrar as Ordens de Serviço exibidas na listagem, basta digitar o termo a ser buscado, como por exemplo uma palavra contida no Assunto, ou apenas o número da Ordem de Serviço. Após digitado, basta apertar o botão **Enter **para efetuar a filtragem.

Filtro por termo

Para limpar o filtro, basta clicar no ícone e novamente serão exibidos todos os registros.

Limpeza de filtro

No filtro por Situação definimos os estado atual da Ordem de Serviço. Caso o formulário ainda não tenha sido enviado, a situação permanecerá como **Aberta com pendência**. Senão, se já tiver sido enviado o preenchimento dos campos, ficará marcada como **Enviada**.
