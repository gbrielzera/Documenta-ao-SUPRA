# TipoAcesso

Caminho: Customização > Modelo de objetos > Ativos > Enumerações > TipoAcesso

Tipo de permissão de Acesso

| **Valor** | **Descrição** |
|---|---|
| **Compartilhamento** | Arquivos são acessados via compartilhamento em rede |
| **Transferencia** | Arquivos são transferidos para a estação cliente e após finalizar modificações o usuário deve enviar nova versão para o servidor de arquivo via comando apropriado na edição de Ordem de Serviço. |
