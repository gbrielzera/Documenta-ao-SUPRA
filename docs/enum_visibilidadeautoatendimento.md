# VisibilidadeAutoAtendimento

Caminho: Customização > Modelo de objetos > Processo > Enumerações > VisibilidadeAutoAtendimento

Indica o tipo de acesso no Autoatendimento, se visivel somente para o cliente e superiores, para todas as pessoas da mesma empresa, todas as pessoas do mesmo órgão ou visivel para todos.

| **Valor** | **Descrição** |
|---|---|
| **Todos** | Visível para todas as pessoas |
| **Cliente** | Visível apenas se o usuário logado for o cliente (ou favorecido) ou for superior |
| **Empresa** | Visível para pessoas da mesma empresa do usuário logado |
| **Orgao** | Visível para pessoas do mesmo órgão e superiores |
