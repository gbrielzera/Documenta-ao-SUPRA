# RequeridoInicial

Caminho: Customização > Modelo de objetos > Processo > ClasseAnexo > RequeridoInicial

É obrigatória a associação do Item de Configuração para que seja iniciada a atividade. 'Requerido inicialização' e 'Produzido ao término' são campos mutualmente exclusivos, ou seja, habilitando um o outro é automaticamente desmarcado.
