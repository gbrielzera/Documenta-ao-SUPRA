# Propriedade Class

Caminho: Propriedade Class

Classe do objeto apurado

**Exemplo 1: modificação da propriedade Class**

```
# carrega objeto MemoriaCalculoApurada de identificador 85
memoriaCalculoApurada = MemoriaCalculoApurada.Carrega(85)
# modifica a propriedade Class
memoriaCalculoApurada.Class = Class.Carrega(73);
# salva modificação da propriedade Class
MemoriaCalculoApurada.Salva(memoriaCalculoApurada)
```
