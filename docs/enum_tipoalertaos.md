# TipoAlertaOS

Caminho: Customização > Modelo de objetos > Recurso > Enumerações > TipoAlertaOS

Escopo que é exibido o alerta de OS´s com ANS

| **Valor** | **Descrição** |
|---|---|
| **TodosGrupos** | Permite visualização de Todas as Ordens de Serviço visiveis por meio da regra de Autorização definida de forma global ou por tipo de subprocesso |
| **ApenasGrupoTecnico** | Permite visualização somente das ordens de serviço do grupo de trabalho do solucionador logado que são visiveis por meio da regra de Autorização definida de forma global ou por tipo de subprocesso |
| **GrupoTecnicoESubNiveis** | Permite visualização somente das ordens de serviço do grupo de trabalho do solucionador logado incluindo sub-níveis que são visiveis por meio da regra de Autorização definida de forma global ou por tipo de subprocesso |
| **NaoExibir** | Não exibe o Painel de Alertas do Workspace |
