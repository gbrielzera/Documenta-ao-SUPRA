# Descricao

Caminho: Customização > Modelo de objetos > Processo > ClasseAnexo > Descricao

Descrição do Item de Configuração para associação com a ocorrência. Se não for especificado então o sistema assume como descritivo do objeto a listagem de descrições de todos os Tipos e Super Tipos configuradas na listagem 'Escopo de Tipos/Super Tipos'.
