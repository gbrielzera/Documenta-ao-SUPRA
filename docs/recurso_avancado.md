# Recursos Avançados

Caminho: Recursos Avançados

Este tópico contém informações sobre recursos avançados do Supravizio que permitem a automatização de processos. Esta automatização está fortemente centrada no uso de scripts na linguagem Python e sua implementação na plataforma Microsoft .Net denominada Iron Python.

No tópico [Iron Python](ironpython) encontraremos conceitos básicos de sintaxe necessários para elaboração dos scripts.

Em [Webservices](webservices) apresentaremos conceitos básicos sobre esta tecnologia e um exemplo de uso no Supravizio.

Por fim apresentaremos as possibilidades de automatização de produtos com suporte a tecnologia Microsoft [Powershell](objeto_powershell).
