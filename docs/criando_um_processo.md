# Criar um Processo

Caminho: Guia para Administradores > Configurando Processos > Tutoriais > Tutorial 1: Construindo o primeiro Processo > Criar um Processo

O primeiro passo na criação de um Processo é clicar no botão de criação de processo localizado no [Process Explorer](process_explorer) do [Editor de Processos.](editor_de_processo)

Localização do Process Explorer

Ao clicar no botão de novo Processo é exibido um diálogo para preenchimento dos dados do novo Processo.

Criação de um novo processo

Após confirmar a inclusão do novo Processo, o [Process Explorer](process_explorer) é atualizado exibindo uma versão em edição (versão inicial do novo processo):

Novo Processo com versão inicial

Deste ponto em diante, o nosso trabalho será adicionar na versão em edição os [Subprocessos](criando_um_sub-processo) utilizados para modelagem dos fluxos.
