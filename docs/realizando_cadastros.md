# Realizando cadastros

Caminho: Guia para Administradores > Roteiro de implantação > Realizando cadastros

Para que uma **pessoa** seja solicitante ou solucionador em uma solicitação, é necessário que este seja cadastrado no Supravizio. Por sua vez, estes devem estar "lotados" em suas respectivas áreas administrativas, às quais chamamos no Supravizio de **Áreas**. É necessário também indicar para cada uma destas áreas a **Empresa** a qual faz parte. Esta organização hierárquica é importante pois é muito utilizada em tarefas, aprovações, regras de restrição e autorização, envios de comunicados, etc.

Para isso, deve-se realizar estes cadastros seguindo os seguintes tópicos:

| 1. | [Empresas](empresa_sub) |
|---|---|

| 2. | [Áreas](orgao_sub) |
|---|---|

| 3. | [Pessoas](pessoa_sub) |
|---|---|

As páginas de cadastro terão a seguinte aparência, como a que utilizamos no exemplo a de Cadastro de Serviços:

Barra de comandos de cadastro

## Incluindo um registro

Para incluir um registro, basta clicar em **Novo **na barra de comandos presente acima da listagem. Logo, será exibida uma página para inserção dos respectivos dados do Serviço:

Cadastro de Serviço

Preenchidos os campos, haverão três opções

- **Salvar e Voltar** - Confirma a inclusão do registro e volta para a Listagem
- **Salvar** - Confirma a inclusão e permanece na página
- **Cancelar e Voltar** - Cancela as modificações e volta para a tela de Listagem

## Modificando um registro

Para modificar um registro, selecione um item na listagem o qual pretende modificar e após clique na opção **Modificar.**

Também é possível acessar a tela de modificação dando um duplo clique sobre o registro.

Modificar o registro

Na tela de edição do registro, também serão exibidas as mesmas opções que na inclusão. Porém, nesta tela também será possível **Apagar** o respectivo registro.

Dados do registro

## Clonando Registros

Para facilitar o cadastro de itens, também é possível realizar o clone de registros já existentes. Basta selecionar o item a ser clonado e clicar no botão **Clonar **na barra de menus:

Clonando um registro

Clicando no botão, será exibida uma página para inclusão, porém, com os dados já preenchidos de acordo com o registro previamente selecionado.

Tela com dados já preenchidos

## Exclusão de registros

Para excluir um ou mais registros, selecione o registro desejado na listagem e em seguida clique no botão **Apagar**:

Caso deseje excluir mais de um registro, é possível excluir vários ao mesmo tempo. Pressionando a tecla **Shift**, a seleção se estenderá do primeiro registro selecionado até o segundo. Pressionando a tecla **Ctrl**, cada registro clicado será incluído na seleção.

Seleção de vários itens para exclusão

Caso não hajam conflitos, a exclusão será realizada e exibida uma mensagem de confirmação. Caso contrário, serão exibidas mensagens de erro:

Mensagem de erro

## Importando registros

Você também poderá automatizar a manutenção destes e outros cadastros no Supravizio através de cadastros de outros sistemas onde tenha estas informações centralizadas. Para isso, poderá contar com a Rotina de Importação de Recursos Humanos. Para mais informações leia o tópico [Importação de dados de Recursos Humanos](importacao_recursos_humanos).
