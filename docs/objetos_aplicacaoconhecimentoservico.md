# AplicacaoConhecimentoServico

Caminho: Customização > Modelo de objetos > Ativos > AplicacaoConhecimentoServico

Escopo de aplicação de um Artigo da Base de Conhecimento em Serviços.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **ClasseServico** | Tipos de Serviços onde o artigo é aplicado. Esta configuração implicará na recuperação do artigo pelo mecanismo de busca. | [ClasseServico](objetos_classeservico) |
| **ClasseServicoId** | Identificador do ClasseServico associado | Inteiro |
| **Id** | Número sequencial gerado automaticamente pelo sistema para Identificar um AplicacaoConhecimentoServico | Inteiro |
| **ItemConfiguracaoId** | Identificador do Artigo proprietário da aplicação | Inteiro |
| **Servico** | Serviços onde é aplicado o Artigo de Base de Conhecimento. Esta configuração implicará na recuperação do artigo pelo mecanismo de busca. | [Servico](objetos_servico) |
| **ServicoId** | Identificador do Servico associado | Inteiro |
