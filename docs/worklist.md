# Worklist

Caminho: Guia para Solucionadores > Worklist

Assim como o Workspace, o Worklist também é utilizado para atendimento de Ordens de Serviço.

Porém, o Worklist possui um formato simplificado e maior facilidade no uso. É uma aplicação destinada a usuários com menor experiência em sistemas.

Ao acessar pela primeira vez, serão solicitados usuário e senha de acesso ao Supravizio. Preenchidos os dados, clique em **Acessar meu ambiente de trabalho **para acessar o Worklist:

Tela de Logon

Caso os dados estejam corretos, será carregada uma listagem contendo as Ordens de Serviço sob responsabilidade do usuário conectado.

Tela do Worklist
