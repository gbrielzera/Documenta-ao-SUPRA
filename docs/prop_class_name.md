# Name

Caminho: Customização > Modelo de objetos > Utilitários > Class > Name

Nome da Classe incluindo namespace

**Exemplo 1: modificação da propriedade Name**

```
# carrega objeto Class de identificador 1
class = Class.Carrega(1)
# modifica a propriedade Name
class.Name = "Nome";
# salva modificação da propriedade Name
Class.Salva(class)
```
