# Text

Caminho: Customização > Modelo de objetos > Utilitários > Class > Text

Descrição resumida da Classe. Este texto é muito usado para identificar objetos deste tipo.

**Exemplo 1: modificação da propriedade Text**

```
# carrega objeto Class de identificador 1
class = Class.Carrega(1)
# modifica a propriedade Text
class.Text = "Descrição resumida";
# salva modificação da propriedade Text
Class.Salva(class)
```
