# Migração para o Portal de Processos

Caminho: Guia para Administradores > Configurações do Sistema > Configurações do Autoatendimento e Portal de Processos > Migração para o Portal de Processos

Mesmo após a instalação do novo Portal de Processos, o Supravizio armazenará as configurações anteriores sobre o site do Autoatendimento, como por exemplo, na criação de links criados dinamicamente em scripts ou Modelos de Comunicado.

Para realizar esta operação, basta acessar caminho **Utilitários | Configurações**:

Caminho da tela de Configurações

Antes é importante conferirmos se o endereço do Supravizio Web está correto. Este deverá na opção **Endereço da aplicação Web **na aba **Utilitários.**

Aba Utilitários

Confirmada a configuração para o site do Supravizio Web, devemos ir para a aba **Processo**, seguindo o parâmetro **Endereço do site de Autoatendimento**, onde devemos deixá-lo **em branco**.

Aba Processo
