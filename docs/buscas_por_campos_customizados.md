# Buscas por Campos Customizados

Caminho: Guia para Administradores > Configurando Processos > Editor de Processos > Campos Customizados > Buscas por Campos Customizados

É muito comum investigarmos o uso de um determinando Campo Customizado procurando identificar seus pontos de uso. Queremos saber se um campo está em algum script, algum Data Object de Preenchimento de Campo, de Aprovação, etc. É comum também investigarmos o uso de um determinado campo que queremos eliminar.

Para procurar as referências de um Campo Customizado, no Editor de Processos, clique no comando Campos na barra de ferramentas:

Clique sobre o campo que deseja pesquisar com o botão direito do mouse selecionando "Buscar referências":

O Supravizio exibe uma listagem contendo os pontos onde este campo é utilizado:

Para conferir cada uma das configurações, basta dar um duplo clique no item que você será redirecionado para o local onde está sendo utilizado:
