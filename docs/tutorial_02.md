# Tutorial 2: Configuração de Serviços

Caminho: Guia para Administradores > Configurando Processos > Tutoriais > Tutorial 2: Configuração de Serviços

Durante a abertura de uma Ordem de Serviço do nosso fluxo exemplo foi possível observar no passo 4 do Portal a disponibilidade de diversos Serviços para a solicitação. o objetivo deste tutorial é relembrar este passo:

Seleção de Serviço para uma nova solicitação

Como podemos observar vários Serviços apresentados não fazem sentido para um processo de aquisição de suprimentos. Vamos então refinar esta configuração criando Serviços apropriados para este fluxo.
