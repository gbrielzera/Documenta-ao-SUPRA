# FonteDados

Caminho: Customização > Modelo de objetos > Ativos > Enumerações > FonteDados

Fonte de dados para Itens de Configuração do tipo Artefato

| **Valor** | **Descrição** |
|---|---|
| **SistemaArquivos** | O item representa um arquivo anexado em alguma ocorrência |
| **Nenhum** | O item é um simples registro |
