# AcaoGap

Caminho: Customização > Modelo de objetos > Processo > AcaoGap

Item do Plano de Ação relacionado com um Gap.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **GapOcorrenciaId** | Número sequencial gerado automaticamente pelo sistema para Identificar um Ocorrência | Inteiro |
| **GapSequencial** | Sequencial | Inteiro |
| **Ocorrencia** | Ocorrência de processo para relativa a Ação do Plano | [Ocorrencia](objetos_ocorrencia) |
| **OcorrenciaPlanoId** | Identificador da Ocorrencia associada | Inteiro |
