# Property

Caminho: Customização > Modelo de objetos > Utilitários > Property

Propriedades nativas de uma Classe de Negócio.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **CharCase** | Caixa baixa, caixa alta, normal ou entrada de senha | [CharCase](enum_charcase) |
| **ClassId** | Idenficador da Classe | Inteiro |
| **Description** | Descrição completa da Propriedade. Este descritivo é utilizado para documentação de telas de cadastro. | String |
| **Id** | Identificador da Propriedade | Inteiro |
| **IsPrimaryKey** | Indica que o campo faz parte da chave primária da tabela de banco de dados | Booleano |
| **IsTextualRepresentation** | Indica que a propriedade identifica textualmente uma classe | Booleano |
| **Length** | Tamanho de campos do tipo string. | Inteiro |
| **Name** | Nome da Propriedade | String |
| **OriginalDescription** | Descrição completa Original da Propriedade | String |
| **OriginalText** | Descrição resumida Original da Propriedade | String |
| **TableColumn** | Coluna de tabela que mantém a propriedade. Válido apenas para Classes de Entidade. | String |
| **Text** | Descrição resumida da Propriedade. Este texto é utilizado como rótulo para a propriedades em telas cadastro (CRUD) | String |
| **Type** | Tipo de dados da Propriedade conforme biblioteca de tipos da tecnologia Microsoft .NET | String |
