# Acordo de Interrupção de ANS

Caminho: Janelas > Recurso > Acordo de Nível de Serviço > Acordo de Interrupção de ANS

Motivos de interrupção habilitados para o Acordo de Nível de Serviço. Um motivo pode estar condicionado a uma aprovação.

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Motivo** | Motivo de interrupção da cronometragem de tempo de atendimento de uma ocorrência. Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
|---|---|

| **Aprovadores** | Aprovadores para a interrupção. Interrupções sem definição de aprovador são automaticamente aprovadas e consideradas no tempo restante de atendimento. Todos os registros desta coleção de dados são mantidos na tabela [APROV_INTER_SLA](dados_aprov_inter_sla). |
|---|---|
