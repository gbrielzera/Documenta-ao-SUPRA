# Fornecedor

Caminho: Customização > Modelo de objetos > Recurso > Fornecedor

Um Fornecedor é uma tipo especial de Empresa habilitada como prestador de serviços para a área.

Este tipo herda atributos e funcionalidades do ancestral [Empresa](objetos_empresa)

Operações:

| **Nome** | **Descrição** | **Assinatura** |
|---|---|---|
| **Carrega** | Recupera do banco de dados o objeto com o identificador fornecido como parâmetro. | Fornecedor Carrega(int i); |
| **Novo** | Cria um novo registro do tipo Fornecedor | Fornecedor Novo(); |
| **Carrega** | Recupera do banco de dados o objeto com a chave de busca fornecida como parâmetro. | Fornecedor Carrega(string nomePropriedade, object valorPropriedade); |
