# Módulos

Caminho: Guia para Administradores > Portal de Processos > Módulos

O Portal de Processos possui é formado por módulos, os quais possuem uma função específica.

Como citado anteriormente, estes módulos podem ser adicionados dinamicamente nas páginas do Portal.

Suas funcionalidades e permissões podem ser personalizadas pelo Administrador, através da definição de parâmetros.

Nos próximos tópicos, vamos introduzir os módulos existentes e parâmetros de cada um.

Inicialmente, utilizaremos como exemplo o Modo Clássico, pela maior abrangência de recursos. Porém, caso haja alguma limitação para outro Modo, citaremos no próprio capítulo.

Atualmente, estão disponíveis os seguintes Tipos de Módulos:

- [Módulo de Abertura](portal_modulo_abertura)
- [Módulo de Consulta](portal_modulo_consulta)
- [Módulo de Aprovação](portal_modulo_conhecimento)
- [Módulo de Conteúdo HTML](portal_modulo_html)
- [Módulo de Publicação de Relatórios](portal_modulo_relatorios)
- [Módulo de Base de Conhecimento](portal_modulo_conhecimento)

## Configuração de Parâmetros para o Módulo

Em modo de Edição de Layout ou Edição de Conteúdo, podemos realizar configurações de parâmetros para este módulo.

Para isso, basta selecionarmos a opção **Configurar Módulo** no canto superior esquerdo e em seguida, em **Editar Parâmetros**.

Localização da opção

Será aberto um novo popup com os parâmetros do módulo, como no exemplo a seguir:

Popup com parâmetros do módulo

Caso o módulo tenha sido reaproveitado de outro modo de visualização, estes parâmetros deverão ser editados apenas na Página Original do Módulo. Logo, no lugar da opção 'Editar Parâmetros', será exibido um link para a devida página.
