# Tipo de Apontamento de Contrato

Caminho: Janelas > Recurso > Contrato > Tipo de Apontamento de Contrato

Tipo de apontamento em um contrato.

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Tipo de Apontamento** | Um Tipo de Apontamento pode ser utilizado no cadastro de Contratos para definir um fator aplicado a um valor/recurso também registrado no contrato. Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
|---|---|
| **Variação** | Variação percentual em relação a valor contratado (de 0% a 100%) que é aplicado no relatório de apropriações. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório - Valida valor minimo da Variação Este campo é mantido na coluna VARIACAO da tabela [TIPO_APONT_CONT](dados_tipo_apont_cont). |

| **Restrições de horários** | Restrições de horários Todos os registros desta coleção de dados são mantidos na tabela [REST_HORA_APONT](dados_rest_hora_apont). |
|---|---|
