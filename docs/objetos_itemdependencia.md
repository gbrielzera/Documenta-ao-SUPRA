# ItemDependencia

Caminho: Customização > Modelo de objetos > Ativos > ItemDependencia

Itens de Configuração que possuem relação de Dependência.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **Comentario** | Comentário sobre a relação de Dependência. Para conhecimento do autor do Comentário utilize a ferramenta de Consulta de Trilha de Modificações do Item. | String |
| **Dependencia** | Item Dependente | [ItemConfiguracao](objetos_itemconfiguracao) |
| **ItemConfiguracaoId** | Número sequencial gerado automaticamente para Identificar um Item de Configuração | Inteiro |
| **ItemDependenciaId** | Identificador do Item de Configuração que do qual é dependente | Inteiro |
