# Como preencher campos

Caminho: Guia para Solucionadores > Worklist > Visualizando detalhes de Ordens de Serviço > Como preencher campos

Neste tópico explicaremos sobre o preenchimento e envio de formulários através do Worklist. Estes campos ficam localizados ao lado esquerdo da tela e estão disponíveis para o usuário.

Campos habilitados para preenchimento

Ao terminar o preenchimento do formulário, haverão três opções:

- **Enviar**: Realiza o envio do formulário e avança para a próxima tarefa
- **Salvar**: Salvas as informações fornecidas, porém, se mantém na atividade atual
- **Ocultar**: Descarta os dados inseridos e oculta os detalhes da Ordem de Serviço

Botões de ação

**Importante:** A fim de evitar possíveis perdas de dados durante o preenchimento, os dados inseridos nos campos são salvos automaticamente a cada 1 minuto.
