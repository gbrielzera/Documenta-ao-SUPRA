# PeriodoPlano

Caminho: Customização > Modelo de objetos > Processo > PeriodoPlano

Período de Plano de Gestão

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **Ano** | Ano | Inteiro |
| **AnotacaoCausa** | Anotação sobre causa | String |
| **AnotacaoGeral** | Anotação geral sobre dados apurados para o Indicador no Período. | String |
| **AnotacaoPerspectiva** | Perspectiva observada para valor apurado do Indicador no Período | String |
| **AnotacaoProvidencia** | Proviência tomada sobre apuração do Indicador no Período | String |
| **Desafio** | Valor acima da meta definido desafio no plano de metas da gestão. No painel de Indicadores do Executive Dashboard períodos que atingirem este valor são exibidos na cor azul. Assim como no campo Metas o Desafio pode ser redefinido nos diversos períodos do Plano de Gestão. | Decimal |
| **IndicadorPlanoIndicadorId** | Identificador do(a) Indicador associado(a) | Inteiro |
| **IndicadorPlanoPlanoGestaoId** | Identificador do Plano de Gestão | Inteiro |
| **Mes** | Mês | Inteiro |
| **Meta** | Meta estabelecida para o Indicador no mês e ano do período. Pode ser atualizado automaticamente quando for modificada a Meta geral do Indicador (atualizado somente se a Meta do período for igual a Meta anterior do Indicador). | Decimal |
| **ValorApurado** | Valor apurado para Indicadores de Desempenho cujo provedor de dados for igual a Lançamento Manual. | Decimal |
