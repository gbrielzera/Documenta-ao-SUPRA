# TipoFiguraDataObject

Caminho: Customização > Modelo de objetos > Processo > Enumerações > TipoFiguraDataObject

Tipo de Data Object

| **Valor** | **Descrição** |
|---|---|
| **PreenchimentoCampo** | Quando o Data Object corresponder a uma operação de preenchimento de campos |
| **Aprovacao** | Quando o Data Object corresponder a uma operação de aprovação |
| **AssociacaoItemConfiguracao** | Quando o Data Object corresponder a uma operação de associação ou geração de itens de configuração |
| **Generico** | Data Object genérico |
| **Controle** | Controle de Atividade para mitigar riscos |
