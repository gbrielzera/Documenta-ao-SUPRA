# Relação de Grupos de Trabalho

Caminho: Guia para Administradores > Configurando Processos > Editor de Processos > Papéis e responsabilidades > Tipos de Papéis > Relação de Grupos de Trabalho

Este tipo de papel permite obter atores baseado no cadastro de Grupos de Trabalho, obtendo seus solucionadores e/ou coordenadores. É possível determinar um ou mais grupos participantes, determinando também seus sub-níveis e indicando inclusive a prioridade dentre os grupos:

### Relação de Grupos de Trabalho

Veja que ao adicionar um Grupo de Trabalho é possível incluir os sub-níveis do grupo (grupos filhos).

Podemos determinar se serão considerados apenas membros que estiverem atuando dentro dos seus devidos [períodos úteis](periodoutil_sub) dos seus [calendários](calendario_sub) relacionados. Podemos definir também que a recuperação seja feita apenas baseada na lista de solucionadores da mesma [Unidade de Negócio](unidadenegocio_sub) do Cliente da Ordem de Serviço.

Para ambos os casos acima, ainda é possível também determinar uma regra de recuperação possibilitando recuperar:

- O Coordenador do grupo de trabalho.
- Todos os Solucionadores, exceto o Coordenador
- Todos os Solucionadores, inclusive o coordenador:
