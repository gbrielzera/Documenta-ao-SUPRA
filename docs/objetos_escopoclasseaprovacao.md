# EscopoClasseAprovacao

Caminho: Customização > Modelo de objetos > Processo > EscopoClasseAprovacao

Relação de Tipos de Itens de Configuração que podem ser aprovados na ocorrência.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **ClasseAprovacaoId** | Identificador da Classe de Aprovação que contém a regra de Escopo | Inteiro |
| **ClasseConfiguracao** | Tipo de Itens de Configuração que podem ser associados na solicitação de aprovação. Quando não preenchido o filtro é realizado apenas pelo Super tipo. | [ClasseConfiguracao](objetos_classeconfiguracao) |
| **ClasseConfiguracaoId** | Identificador do Tipo de Item de Configuração | Inteiro |
| **Id** | Número sequencial gerado automaticamente pelo sistema para Identificar um EscopoClasseAprovacao | Inteiro |
