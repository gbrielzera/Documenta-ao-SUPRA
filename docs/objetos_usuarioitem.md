# UsuarioItem

Caminho: Customização > Modelo de objetos > Ativos > UsuarioItem

Usuários do Item de Configuração

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **Comentario** | Comentário | String |
| **DataHoraAssociacao** | Data e hora de inclusão do Usuário | Data/hora |
| **ItemConfiguracaoId** | Número sequencial gerado automaticamente para Identificar um Item de Configuração | Inteiro |
| **OcorrenciaAssociacao** | Ocorrência que gerou a inclusão do Usuário | [Ocorrencia](objetos_ocorrencia) |
| **OcorrenciaDevolucao** | Ocorrência que gerou a devolução Item de Configuração associado ao Usuário | [Ocorrencia](objetos_ocorrencia) |
| **OcorrenciaDevolucaoId** | Identificador da Ocorrencia de devolução do Item de Configuração associado | Inteiro |
| **OcorrenciaId** | Identificador da Ocorrencia associada | Inteiro |
| **Pessoa** | Cliente | [Pessoa](objetos_pessoa) |
| **PessoaId** | Identificador da Pessoa associada | Inteiro |
