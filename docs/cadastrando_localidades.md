# Localidades

Caminho: Guia para Administradores > Roteiro de implantação > Realizando cadastros > Cadastros Adicionais > Localidades

Ainda dando continuidade ao item anterior, vimos que um calendário possui informações regionais. O Supravizio possui um cadastro organizado para determinar a localização de uma pessoa ou ativo. Esta informação pode ser importante também na criação de papeis de processo quando quisermos selecionar solucionadores que estejam na mesma localidade do solicitante.

Inicialmente cadastramos uma Unidade de Negócio (**Recurso | Unidades de Negócio**):

Cadastro de Unidades de Negócios

Selecionando ou incluindo um novo registro, repare que em seu cadastro indicamos o calendário:

Dados Principais de Unidades de Negócio

Após realizar o preenchimento dos campos da aba **Dados Principais**, você deve agora cadastrar Prédios:

Cadastro de Prédios das Unidades de Negócio

Dados Principais de cadastros de Prédios

Efetuado o cadastro de um Prédio, vamos agora inserir os Locais disponíveis nele através da aba "Locais":

Aba Locais de cadastros de Prédios

Dados Principais da tela Locais

Agora sim, podemos determinar por exemplo, no cadastro de pessoas, a localização de cada potencial solicitante/solucionador:

Localidade de trabalho de uma Pessoa

Caso o solicitante deseje abrir uma solicitação para um atendimento local, é possível no primeiro passo da abertura no Portal de Processos indicar sua localidade:

Local de Atendimento no Módulo de Abertura

Além disso, também é possível determinar a localidade de um determinado [Equipamento](hardware_sub) ou outros tipos de ativos:

Localidade em um Equipamento
