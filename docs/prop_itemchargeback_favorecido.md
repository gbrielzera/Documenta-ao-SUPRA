# Favorecido

Caminho: Customização > Modelo de objetos > Recurso > ItemChargeBack > Favorecido

Usuário favorecido pelo uso de um Ativo, atendimento de uma Ordem de Serviço ou Acordo de Nível de Serviço. No caso de Acordos de Nível de Serviço do com o critério 'Formula' ou 'Valor Fixo' o favorecido é o gestor da área atendida pelo acordo na ocasião da apuração de Charge-back. Nas demais situações onde existir uma Ordem de Serviço associada o favorecido é preenchido com o campo Favorecido da respectiva Ordem de Serviço.
