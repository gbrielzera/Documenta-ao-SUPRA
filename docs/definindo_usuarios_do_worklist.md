# Definindo Usuários do Worklist

Caminho: Guia para Administradores > Roteiro de implantação > Realizando cadastros > Definindo Usuários do Worklist

Caso seja desejado, podemos definir usuários para o Worklist do Supravizio. A regra básica de acesso é definida através da opção **Modo Worklist** no menu **Utilitários | Configurações**.

Aba Processo

Nesta opção, podersão ser selecionados os seguintes modos:

- **Desabilitado** - Worklist desativado para todos os usuários
- **Habilitado para todas as pessoas** - O modo estará disponível para todos as Pessoas que não tiverem um solucionador configurado para a mesma
- **Somente Pessoas autorizadas** - Somente terão acesso usuários que tiverem autorização no cadastro de Pessoas
