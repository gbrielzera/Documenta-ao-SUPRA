# Ano

Caminho: Customização > Modelo de objetos > Processo > ApuracaoIndicador > Ano

Ano

**Exemplo 1: modificação da propriedade Ano**

```
# carrega objeto ApuracaoIndicador de identificador 1
apuracaoIndicador = ApuracaoIndicador.Carrega(1)
# modifica a propriedade Ano
apuracaoIndicador.Ano = 2010;
# salva modificação da propriedade Ano
ApuracaoIndicador.Salva(apuracaoIndicador)
```
