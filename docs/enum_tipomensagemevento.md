# TipoMensagemEvento

Caminho: Customização > Modelo de objetos > Processo > Enumerações > TipoMensagemEvento

Tipo de mensagem em eventos de processo

| **Valor** | **Descrição** |
|---|---|
| **Email** | O evento intermediário utilizar emails para disparar uma ação. |
| **Mensagem** | O evento utilza o mecanismo de troca de mensagens Webservices. |
| **ImportacaoInventario** | Importação de hardware e software descobertos pela ferramenta de inventário |
