# Gatilho de Associação

Caminho: Janelas > Processo > Associação > Gatilho de Associação

Gatilhos disparados na ocorrência de um Evento

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Tipo de Evento** | Tipo de Evento que dispara o Gatilho Utilizando um clique no rótulo do campo podemos acessar o cadastro do registro selecionado no controle. Se o usuário conectado possui acesso ao cadastro deste registro então é possível sua edição. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório |
|---|---|

| **Script** | Script que é executado como resposta do Gatilho Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna SCRIPT da tabela [GATILHO_ASSOC](dados_gatilho_assoc). |
|---|---|
