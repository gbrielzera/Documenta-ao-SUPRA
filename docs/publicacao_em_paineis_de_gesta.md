# Montagem de Painéis de Gestão à Vista

Caminho: Guia para Administradores > Editor de Dashboard > Publicando Dashboards > Montagem de Painéis de Gestão à Vista

Utilizando a visualização de painéis de Dashboard, podemos disponibilizar as informações em um local de maior visibilidade aos colaboradores, divulgando para um maior número de pessoas simultaneamente e estabelecendo uma prática de compartilhamento do conhecimento.

Painel de Gestão a Vista

Para a montagem de um painel, podemos utilizar soluções simples e eficientes. Inicialmente, é necessário que a página seja atualizada automaticamente a fim de manter os dados sempre de acordo com as últimas alterações.

Para isso, basta adicionar o parâmetro **REFRESH **no endereço da página do painel de Dashboard, seguido da frequência (em minutos) com que este será executado, conforme segue o exemplo:

Endereço da página web

Em casos onde seja necessário exibir mais de painel na mesma tela, é possível utilizar complementos do próprio navegador que realizem a troca de abas abertas automaticamente.

Há plugins com esta função disponíveis para quase todos os navegadores, como por exemplo, o que utilizamos neste navegador:

Página de add-ons do navegador

Ao realizar a exibição, abra os painéis desejados em abas diferentes para que o plugin realize a troca delas.

Painéis abertos em abas diferentes

Enfim, alterando o modo de visualização do navegador para o modo de tela cheia do navegador e terá um resultado semelhante à ilustração a seguir:
