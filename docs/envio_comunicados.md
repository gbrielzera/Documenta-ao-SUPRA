# Acessando os comunicados da Ordem de Serviço

Caminho: Guia para Solucionadores > Workspace  > Workspace Ordens de Serviço > Comunicados em Ordens de Serviço > Acessando os comunicados da Ordem de Serviço

Todos os comunicados referentes a uma Ordem de Serviço, sejam eles enviadas pelo solucionador ou pelo próprio sistema, são listados por ordem de dada/hora de envio decrescente:

Lista de comunicados

Na lista de Comunicados da Ordem de Serviço podemos visualizar três situações:

- **Pendente** : A mensagem ainda não foi enviada pelo sistema, porém está na fila de envio.
- **Enviada com Sucesso** : A mensagem foi enviada com sucesso para o(s) destinatário(s).
- **Não Enviada** : Ocorreu algum erro.

Abaixo são apresentadas as funcionalidades dos botões que ficam a direita a lista de comunicados:

- **Enviar novamente** : ao selecionar uma mensagem e clicar no botão enviar novamente a mensagem será reencaminhada para o(s) destinatário(s):

Enviar novamente

- **Modificar opções: **ao selecionar uma mensagem e clicar no botão Modificar opções será exibida novamente a janela de Opções de envio da mensagem e permite modificações na Opções de comunicados:

Modificar opções

- Adicionar destinatários: ao selecionar uma mensagem e clicar no botão Adicionar destinatários será exibida a mensagem abaixo que permite adicionar destinatários a mensagem:

Adicionar destinatários
