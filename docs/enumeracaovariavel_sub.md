# Enumeração de Variável

Caminho: Janelas > Processo > Métodos de Priorização > Variável Priorização > Enumeração de Variável

Enumeração de valores para Variável. Quando não existir então o campo é numérico de livre digitação.

Na tabela abaixo temos os principais campos deste cadastro:

## Campos do cadastro

| **Sequencial** | Sequencia de apresentação da opção. Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna SEQUENCIAL da tabela [ENUM_VARIAVEL](dados_enum_variavel). |
|---|---|
| **Descrição** | Descritivo da opção Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna DESCRICAO da tabela [ENUM_VARIAVEL](dados_enum_variavel). |
| **Valor** | Valor para a opção Para este campo existem as seguintes regras: - Este campo possui preenchimento obrigatório Este campo é mantido na coluna VALOR da tabela [ENUM_VARIAVEL](dados_enum_variavel). |
