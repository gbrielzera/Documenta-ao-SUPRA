# Criando Diretivas de Senha

Caminho: Guia para Administradores > Roteiro de implantação > Realizando cadastros > Cadastro de Pessoas > Criando Diretivas de Senha

O Supravizio permite criar regras de senha para o cadastro de Pessoas para aumentar o nível de segurança de acesso de usuários.

Para acessar estas configurações, acesse a tela de Configurações através do caminho **Utilitários | Configurações.**
