# Propriedade ApuracaoIndicadorMes

Caminho: Propriedade ApuracaoIndicadorMes

Mês referência da apuração

**Exemplo 1: modificação da propriedade ApuracaoIndicadorMes**

```
# carrega objeto MemoriaCalculoApurada de identificador 1
memoriaCalculoApurada = MemoriaCalculoApurada.Carrega(1)
# modifica a propriedade ApuracaoIndicadorMes
memoriaCalculoApurada.ApuracaoIndicadorMes = 1;
# salva modificação da propriedade ApuracaoIndicadorMes
MemoriaCalculoApurada.Salva(memoriaCalculoApurada)
```
