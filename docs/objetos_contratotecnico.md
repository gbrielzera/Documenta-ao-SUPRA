# ContratoTecnico

Caminho: Customização > Modelo de objetos > Recurso > ContratoTecnico

Grupos de trabalho onde estão lotados os Solucionadores correspondentes ao tipo de recurso do contrato.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **GrupoTrabalho** | Grupos de trabalho onde estão lotados os Solucionadores correspondentes ao tipo de recurso do contrato. | [GrupoTrabalho](objetos_grupotrabalho) |
| **GrupoTrabalhoId** | Identificador do GrupoTrabalho associado | Inteiro |
| **RecursoAplicadoId** | Identificador do Recurso Aplicado | Inteiro |
