# Tutorial 6: Geração de Ordens de Serviço com temporizador

Caminho: Guia para Administradores > Configurando Processos > Tutoriais > Tutorial 6: Geração de Ordens de Serviço com temporizador

O objetivo deste tutorial é construir um fluxo que será iniciado automaticamente a partir de um temporizador:

Evento inicial por Timer

Neste tutorial vamos inicialmente gerar uma nova versão e em seguida criar um novo fluxo para Cálculo de folha de pagamento.

Ao término veremos como são geradas as Ordens de Serviço iniciadas por temporizadores.
