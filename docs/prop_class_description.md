# Description

Caminho: Customização > Modelo de objetos > Utilitários > Class > Description

Documentação sobre a Classe de Negócio utilizada como ajuda para usuário em telas de cadastro e outras funções do sistema.

**Exemplo 1: modificação da propriedade Description**

```
# carrega objeto Class de identificador 1
class = Class.Carrega(1)
# modifica a propriedade Description
class.Description = "Descrição";
# salva modificação da propriedade Description
Class.Salva(class)
```
