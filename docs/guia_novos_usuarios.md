# Guia para Administradores

Caminho: Guia para Administradores

Este guia apresenta as principais funcionalidades disponíveis para os Administradores e Analistas responsáveis pela manutenção em processos.

[Interface com o Usuário](interface_usuario) apresenta os principais recursos da interface gráfica disponível para o usuário. Destacamos também as funcionalidades de [Propriedades Customizadas](campos_customizados) e recursos para anexar arquivos em cadastros.

Um dos principais conteúdos deste guia é o tópico [Configuração de Processos](editor_de_processo), onde disponibilizamos informações gerais sobre o editor de processos e diversos tutoriais para elaboração de fluxos de trabalho.

O tópico [Acordos](acordos) apresenta os recursos [Acordos de Nível de Serviço](acordo_de_nivel_servico) e [Acordo de Nível Operacional](acordo_de_nivel_operacional), onde é possível configurar tempos de finalização acordados com o cliente de uma solicitação e equipe de solucionadores, respectivamente.

Todos os recursos disponíveis para solucionadores está documentado no tópico [Workspace](workspace). Nesta ferramenta podemos gerenciar Ordens de Serviço, realizar buscas na [Base de Conhecimento](cadastros_base_conhecimento), realizar a gestão por Indicadores e [gerenciar apontamentos](cadastros_apontamentos).

Para construção de relatórios customizados é possível utilizar a ferramenta [Editor de Relatórios](editor_de_relatorios). Os relatórios construídos neste editor podem ser publicados no menu como [relatórios de gestão](relatorios_no_menu_principal) ou inseridos em [etapas](relatorios_de_apoio_operaciona) e [aprovações](relatorios_para_aprovacao) de processos.

Para uso do produto como ferramenta de gerenciamento de serviços de TI é possível integrar e importar a [base de dados do OCS NG](ocs_introducao), ferramenta de discovery de hardware e instalação de software open source.
