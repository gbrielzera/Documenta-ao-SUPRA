# DisponivelAutoatendimento

Caminho: Customização > Modelo de objetos > Processo > RelatorioAtividade > DisponivelAutoatendimento

Indica que o relatório estará disponível na página de consulta de Ordens de Serviço do sistema de Autoatendimento. O relatório estará acessível por um link que exibirá o conteúdo em outra página web.
