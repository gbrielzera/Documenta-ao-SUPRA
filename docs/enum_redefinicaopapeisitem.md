# RedefinicaoPapeisItem

Caminho: Customização > Modelo de objetos > Processo > Enumerações > RedefinicaoPapeisItem

Redefinição de Papéis por Item de Configuração

| **Valor** | **Descrição** |
|---|---|
| **SobreposicaoPorItem** | Redefinições de Itens de Configuração sobrepõem se, e somente se, já existir uma redefinição do Serviço. |
| **AdicionaItem** | Atores redefinidos em Itens de Configuração são adicionados a lista geral computada até o nível de Serviço. |
| **Nenhum** | Não permite a redefinição de Papéis por Itens de Configuração se, e somente se, já existir uma redefinição do Serviço. |
