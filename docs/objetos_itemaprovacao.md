# ItemAprovacao

Caminho: Customização > Modelo de objetos > Processo > ItemAprovacao

Item de Configuração sujeito a Aprovação.

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **AssuntoAprovacaoId** | Número sequencial gerado automaticamente pelo sistema para Identificar um AssuntoAprovacao | Inteiro |
| **ItemConfiguracao** | Item de Configuração | [ItemConfiguracao](objetos_itemconfiguracao) |
| **ItemConfiguracaoId** | Identificador do ItemConfiguracao associado | Inteiro |
| **Versao** | Sequencial gerado automaticamente pelo sistema para cada Assunto de uma determinada Ordem de Serviço | Inteiro |
