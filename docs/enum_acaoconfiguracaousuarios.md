# AcaoConfiguracaoUsuarios

Caminho: Customização > Modelo de objetos > Processo > Enumerações > AcaoConfiguracaoUsuarios

Ação realizada nos Itens de Configuração na finalização de uma Ordem de Serviço ou atividade de processo.

| **Valor** | **Descrição** |
|---|---|
| **IncluirFavorecidoOcorrencia** | A pessoa informada como favorecida é incluída como usuário dos Itens de Configuração no instante em que a atividade onde está a regra é finalizada. |
| **IncluirFavorecidoAtividade** | A pessoa informada como favorecida é incluída na lista de usuários dos Itens de Configuração no instante em que a atividade onde está a regra é finalizada. |
| **RemoverFavorecidoOcorrencia** | A pessoa informada como favorecida é excluída da lista de usuários dos Itens de Configuração no instante em que a Ordem de Serviço é finalizada. |
| **RemoverFavorecidoAtividade** | A pessoa informada como favorecida é excluída da lista de usuários dos Itens de Configuração no instante em que a atividade onde está a regra é finalizada. |
| **Nenhuma** | Nenhuma ação é executada na finalização da ocorrência ou atividade de processo. |
