# ItemCopia

Caminho: Customização > Modelo de objetos > Ativos > ItemCopia

Itens que são cópias

Propriedades:

| **Nome** | **Descrição** | **Tipo** |
|---|---|---|
| **Comentario** | Comentário sobre a relação de Cópia. Para conhecimento do autor do Comentário utilize a ferramenta de Consulta de Trilha de Modificações do Item. | String |
| **Copia** | Classe abstrata para todos os Itens de Configuração do CMDB | [ItemConfiguracao](objetos_itemconfiguracao) |
| **ItemConfiguracaoId** | Número sequencial gerado automaticamente para Identificar um Item de Configuração | Inteiro |
| **ItemCopiaId** | Identificador do Item considerado Cópia | Inteiro |
