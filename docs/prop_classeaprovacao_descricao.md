# Descricao

Caminho: Customização > Modelo de objetos > Processo > ClasseAprovacao > Descricao

Descrição do Item de Configuração para associação com a solicitação de aprovação. Se não for especificado então o sistema assume como descritivo do objeto a listagem de descrições de todos os Tipos e Super tipos configurados na listagem 'Escopo de Tipos/Super tipos'
