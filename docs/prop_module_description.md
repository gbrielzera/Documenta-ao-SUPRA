# Description

Caminho: Customização > Modelo de objetos > Utilitários > Module > Description

Descrição detalhada do Módulo para documentação do Módulo.

**Exemplo 1: modificação da propriedade Description**

```
# carrega objeto Module de identificador 1
module = Module.Carrega(1)
# modifica a propriedade Description
module.Description = "Descrição";
# salva modificação da propriedade Description
Module.Salva(module)
```
