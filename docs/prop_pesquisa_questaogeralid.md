# QuestaoGeralId

Caminho: Customização > Modelo de objetos > Processo > Pesquisa > QuestaoGeralId

Identificador da QuestaoPesquisa associada

**Exemplo 1: modificação da propriedade QuestaoGeralId**

```
# carrega objeto Pesquisa de identificador 1
pesquisa = Pesquisa.Carrega(1)
# modifica a propriedade QuestaoGeralId
pesquisa.QuestaoGeralId = 1;
# salva modificação da propriedade QuestaoGeralId
Pesquisa.Salva(pesquisa)
```
